Metropolis-Hastings requires choosing and tuning a proposal distribution.
**Gibbs sampling** avoids this by sampling each variable from its **full conditional**:
the distribution of that variable given all others at their current values.
The full conditional is automatically a valid Markov chain proposal that always accepts.

## Gibbs as MH with acceptance rate 1

In MH, the acceptance ratio for a proposal that moves only $X_i$ while holding
all other variables $\mathbf{X}_{-i}$ fixed is:

$$
\alpha = \frac{P(\mathbf{X}_{-i}, X_i = x'_i) q(x_i \mid x'_i, \mathbf{X}_{-i})}
             {P(\mathbf{X}_{-i}, X_i = x_i) q(x'_i \mid x_i, \mathbf{X}_{-i})}.
$$

If the proposal is the full conditional $q(x'_i \mid x_i, \mathbf{X}_{-i}) = P(X_i = x'_i \mid \mathbf{X}_{-i})$,
then:

$$
\alpha = \frac{P(X_i = x'_i \mid \mathbf{X}_{-i}) P(X_i = x_i \mid \mathbf{X}_{-i})}
             {P(X_i = x_i \mid \mathbf{X}_{-i}) P(X_i = x'_i \mid \mathbf{X}_{-i})} = 1.
$$

Every Gibbs proposal is accepted.

## Gibbs algorithm

Iterate through the variables $X_1, \ldots, X_d$:

1. Sample $X_i^{(t+1)} \sim P(X_i \mid X_1^{(t+1)}, \ldots, X_{i-1}^{(t+1)}, X_{i+1}^{(t)}, \ldots, X_d^{(t)})$.

The full conditional for a variable in a graphical model depends only on its Markov blanket
(parents, children, and co-parents in the directed case; neighbors in the undirected case).
This is what makes Gibbs tractable for large models.

## Full conditionals for conjugate models

For a Gaussian model with unknown mean $\mu$ and precision $\tau$, and conjugate priors:

$$
\mu \sim \mathcal{N}(\mu_0, \tau_0^{-1}), \qquad \tau \sim \text{Gamma}(a, b),
$$

the full conditionals are:

$$
\mu \mid \tau, \mathbf{x} \sim \mathcal{N}\!\left(\frac{\tau_0 \mu_0 + \tau \sum x_i}{\tau_0 + n\tau},\, (\tau_0 + n\tau)^{-1}\right),
$$

$$
\tau \mid \mu, \mathbf{x} \sim \text{Gamma}\!\left(a + \frac{n}{2},\, b + \frac{1}{2}\sum(x_i - \mu)^2\right).
$$

Both are standard distributions, so sampling is exact.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(23)

# Bivariate Gaussian Gibbs sampler
# p(x1, x2) = N([0,0], [[1, rho],[rho,1]])
# Full conditionals: x1|x2 ~ N(rho*x2, 1-rho^2), x2|x1 ~ N(rho*x1, 1-rho^2)
rho = 0.85
cond_var = 1 - rho**2

N = 15_000
x = np.zeros((N, 2))
x[0] = [0.0, 0.0]

for t in range(1, N):
    # Sample x1 | x2
    mu1 = rho * x[t-1, 1]
    x[t, 0] = rng.normal(mu1, np.sqrt(cond_var))
    # Sample x2 | x1
    mu2 = rho * x[t, 0]
    x[t, 1] = rng.normal(mu2, np.sqrt(cond_var))

burnin = 1000
post = x[burnin:]
print(f"Sample mean: {post.mean(axis=0).round(4)}  (true: [0, 0])")
print(f"Sample Cov:\n{np.cov(post.T).round(4)}")
print(f"True Cov:\n[[1.0, {rho}], [{rho}, 1.0]]")

# Autocorrelation at lag 1 (shows slow mixing for high rho)
lag1_corr = np.corrcoef(post[:-1, 0], post[1:, 0])[0, 1]
print(f"Autocorrelation at lag 1 for x1: {lag1_corr:.3f}")
print(f"(High rho={rho} causes slow mixing: lag-1 autocorr is nonzero)")
```

The sampler recovers the true covariance, but high correlation $\rho$ induces high
autocorrelation between successive samples, reducing the effective sample size.
