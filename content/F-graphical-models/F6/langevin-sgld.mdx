Hamiltonian MC requires running a full trajectory to propose each sample.
**Langevin dynamics** is a simpler gradient-based approach that injects controlled
noise into gradient ascent on $\log \pi$, turning optimization into sampling.

## Overdamped Langevin diffusion

The **overdamped Langevin SDE** for a target $\pi(q) \propto e^{-U(q)}$ is:

$$
dq_t = -\nabla U(q_t) \, dt + \sqrt{2} \, dW_t,
$$

where $W_t$ is standard Brownian motion.

The Fokker-Planck equation shows that $\pi(q)$ is the unique stationary distribution
of this SDE: the drift $-\nabla U$ pushes toward high-probability regions, while the
noise $\sqrt{2} dW_t$ prevents the chain from collapsing to a mode<FN n="2" />.

## Unadjusted Langevin algorithm (ULA)

Discretize with step size $\varepsilon$ (Euler-Maruyama):

$$
q_{t+1} = q_t - \varepsilon \nabla U(q_t) + \sqrt{2\varepsilon} \, \xi_t,
\quad \xi_t \sim \mathcal{N}(0, I).
$$

This is called the **unadjusted Langevin algorithm (ULA)** because no MH correction step is applied.
The discretization introduces a bias: the stationary distribution of the discrete chain
is not exactly $\pi(q)$ but a perturbed version with error $O(\varepsilon)$ in TV distance.
Adding an MH correction gives the **Metropolis-adjusted Langevin algorithm (MALA)**,
which corrects the bias at the cost of an accept/reject step.

## Stochastic gradient Langevin dynamics (SGLD)

For a posterior $\pi(\theta) \propto p(\theta) \prod_n p(x_n \mid \theta)$ over $N$ datapoints,
the full gradient $\nabla \log \pi(\theta) = \nabla \log p(\theta) + \sum_n \nabla \log p(x_n \mid \theta)$
costs $O(N)$ per step.

SGLD replaces the full gradient with a mini-batch estimate and no MH correction<FN n="1" />:

$$
\theta_{t+1} = \theta_t + \frac{\varepsilon_t}{2}\!\left(\nabla \log p(\theta_t)
+ \frac{N}{M} \sum_{n \in \mathcal{B}_t} \nabla \log p(x_n \mid \theta_t)\right) + \xi_t,
$$

with $\xi_t \sim \mathcal{N}(0, \varepsilon_t I)$.

As $\varepsilon_t \to 0$ at an appropriate rate ($\sum_t \varepsilon_t = \infty$, $\sum_t \varepsilon_t^2 < \infty$),
the mini-batch noise is dominated by the injected noise and the chain converges to the posterior.
In practice, a fixed small $\varepsilon$ is used, accepting a bias similar to ULA.

## Connection to SGD

With $\xi_t = 0$, the update is stochastic gradient ascent on $\log \pi(\theta)$:
it converges to the MAP estimate.
Adding noise of order $\sqrt{\varepsilon}$ transforms MAP optimization into posterior sampling.
This single change turns a deep learning optimizer into a Bayesian sampler, at no additional
gradient cost.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(31)

# Bayesian linear regression with SGLD
# Prior: w ~ N(0, I),  Likelihood: y_n ~ N(w^T x_n, sigma^2)
N = 200
d = 3
true_w = np.array([1.0, -2.0, 0.5])
sigma2 = 0.5
X = rng.normal(0, 1, (N, d))
y = X @ true_w + rng.normal(0, np.sqrt(sigma2), N)

# Analytic posterior for comparison
prior_prec = np.eye(d)
post_prec  = prior_prec + X.T @ X / sigma2
post_cov   = np.linalg.inv(post_prec)
post_mean  = post_cov @ (X.T @ y / sigma2)

# SGLD
eps = 1e-3
M   = 20   # mini-batch size
n_steps = 50_000
burnin  = 10_000

w = np.zeros(d)
samples = []

for t in range(n_steps):
    idx = rng.choice(N, M, replace=False)
    X_b, y_b = X[idx], y[idx]
    grad_prior = -w
    grad_lik   = (N / M) * X_b.T @ (y_b - X_b @ w) / sigma2
    grad_log_pi = grad_prior + grad_lik
    noise = rng.normal(0, np.sqrt(eps), d)
    w = w + 0.5 * eps * grad_log_pi + noise
    if t >= burnin:
        samples.append(w.copy())

samples = np.array(samples)
print(f"SGLD posterior mean: {samples.mean(axis=0).round(3)}")
print(f"Exact posterior mean: {post_mean.round(3)}")
print(f"SGLD posterior std:   {samples.std(axis=0).round(3)}")
print(f"Exact posterior std:  {np.sqrt(np.diag(post_cov)).round(3)}")
```

SGLD recovers the posterior mean well; the standard deviation is typically overestimated
by a factor related to $\varepsilon$ (Langevin discretization bias), which is the expected
cost of skipping the MH correction step.
The lesson is still clear: a small noise injection transforms gradient optimization
into approximate Bayesian posterior sampling.

## Exercises

**Exercise 1.** Write the ULA update for a 1D Gaussian target
$\pi(q) \propto e^{-(q - \mu)^2 / (2 s^2)}$, i.e. give $\nabla U(q)$ and the full
Euler-Maruyama step. Then state the size of the injected noise relative to the
drift as $\varepsilon \to 0$.

<details>
<summary>Solution</summary>

**Step 1.** Here $U(q) = -\log \pi(q) = \frac{(q - \mu)^2}{2 s^2}$ up to a
constant, so $\nabla U(q) = \frac{q - \mu}{s^2}$.

**Step 2.** Substituting into
$q_{t+1} = q_t - \varepsilon \nabla U(q_t) + \sqrt{2\varepsilon}\, \xi_t$ with
$\xi_t \sim \mathcal{N}(0, 1)$ gives

$$
q_{t+1} = q_t - \varepsilon \frac{q_t - \mu}{s^2} + \sqrt{2\varepsilon}\, \xi_t.
$$

**Step 3.** The drift term scales as $\varepsilon$ while the noise term scales as
$\sqrt{2\varepsilon}$. As $\varepsilon \to 0$ the noise $\sqrt{\varepsilon}$
dominates the drift $\varepsilon$ (their ratio diverges), so the random kicks, not
the gradient, set the local step scale. This is why ULA keeps exploring instead of
collapsing onto the mode $\mu$.

</details>

**Exercise 2.** SGLD replaces the full log-likelihood gradient with the
mini-batch estimate $\frac{N}{M} \sum_{n \in \mathcal{B}} \nabla \log p(x_n \mid \theta)$
over a batch of size $M$. Show this estimate is unbiased for the full-data
gradient $\sum_{n=1}^N \nabla \log p(x_n \mid \theta)$ when the batch is sampled
uniformly without replacement.

<details>
<summary>Solution</summary>

**Step 1.** Let $g_n = \nabla \log p(x_n \mid \theta)$. The mini-batch estimate is
$\hat{g} = \frac{N}{M} \sum_{n \in \mathcal{B}} g_n$. Take its expectation over the
random batch $\mathcal{B}$.

**Step 2.** Under uniform sampling without replacement, each index $n$ is included
with probability $M/N$. Writing the sum with indicator $\mathbb{1}[n \in \mathcal{B}]$,

$$
\mathbb{E}[\hat{g}] = \frac{N}{M} \sum_{n=1}^N \mathbb{E}\big[\mathbb{1}[n \in \mathcal{B}]\big]\, g_n
= \frac{N}{M} \sum_{n=1}^N \frac{M}{N}\, g_n.
$$

**Step 3.** The factors $\frac{N}{M}$ and $\frac{M}{N}$ cancel:

$$
\mathbb{E}[\hat{g}] = \sum_{n=1}^N g_n,
$$

the full-data gradient. The $N/M$ rescaling is exactly what makes the cheap batch
estimate unbiased, so the only effect of subsampling is added variance, which the
$\sum_t \varepsilon_t^2 < \infty$ schedule controls.

</details>

**Exercise 3 (code).** Run ULA on a 1D Gaussian target $\mathcal{N}(2, 1.5)$ with
step size $\varepsilon = 0.05$. From a fixed seed, draw many samples and check
that the empirical mean recovers $2$ and the variance recovers $1.5$ within a
generous tolerance.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)

mu, s2 = 2.0, 1.5
def grad_U(q):                 # -grad log pi for N(mu, s2)
    return (q - mu) / s2

eps = 0.05
N = 200_000
q = 0.0
samples = np.empty(N)

for t in range(N):
    q = q - eps * grad_U(q) + np.sqrt(2 * eps) * rng.normal()
    samples[t] = q

post = samples[5000:]          # discard burn-in
print(f"mean {post.mean():.3f} (true {mu}), var {post.var():.3f} (true {s2})")

assert abs(post.mean() - mu) < 0.1    # drift centers the chain at mu
assert abs(post.var() - s2) < 0.2     # noise reproduces the target spread
```

The chain recovers mean $\approx 2.0$ and variance $\approx 1.5$. At this small
$\varepsilon$ the $O(\varepsilon)$ discretization bias stays inside the tolerance,
so the unadjusted chain samples the Gaussian without any accept/reject step.

</details>
