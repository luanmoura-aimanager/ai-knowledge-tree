Rejection sampling requires an envelope tight enough to accept a useful fraction of proposals.
In high dimensions, no fixed envelope is tight everywhere.
**Markov Chain Monte Carlo** (MCMC) sidesteps the envelope by constructing a Markov chain
whose stationary distribution is the target.
The **Metropolis-Hastings** (MH) algorithm is the general recipe<FN n="1" />.

## Detailed balance

A Markov chain with transition kernel $T(x' \mid x)$ has stationary distribution $\pi(x)$
if it satisfies **detailed balance**:

$$
\pi(x) T(x' \mid x) = \pi(x') T(x \mid x').
$$

Detailed balance is sufficient but not necessary for stationarity.
If it holds for every pair $(x, x')$, then summing over $x$ shows $\pi$ is invariant.

## Metropolis-Hastings algorithm

Given the current state $x$, the MH step is:

1. Propose $x' \sim q(x' \mid x)$ from a proposal distribution.
2. Compute the acceptance ratio<FN n="2" />:

$$
\alpha(x' \mid x) = \min\!\left(1,\, \frac{\pi(x') q(x \mid x')}{\pi(x) q(x' \mid x)}\right).
$$

3. Accept $x' $ with probability $\alpha$; otherwise stay at $x$.

**Why this satisfies detailed balance.** Define the transition kernel
$T(x' \mid x) = q(x' \mid x) \alpha(x' \mid x)$ for $x' \ne x$.
At any pair $(x, x')$ where $\alpha < 1$ (i.e., where $\pi(x') q(x \mid x') < \pi(x) q(x' \mid x)$):

$$
\pi(x) T(x' \mid x) = \pi(x) q(x' \mid x) \frac{\pi(x') q(x \mid x')}{\pi(x) q(x' \mid x)}
= \pi(x') q(x \mid x') = \pi(x') T(x \mid x').
$$

The normalizing constant of $\pi$ cancels in the acceptance ratio, so the algorithm
only needs the unnormalized target $\tilde{\pi}(x) \propto \pi(x)$.

To see what the ratio does, take a standard normal target $\pi(x) \propto e^{-x^2/2}$
with a symmetric random-walk proposal, so the $q$ factors cancel and
$\alpha = \min(1, e^{-(x'^2 - x^2)/2})$:

- **Uphill, toward the mode** (from $x = 1$ to $x' = 0$): the proposal lands at higher
  density, the ratio exceeds 1, and $\alpha = 1$. Moves that improve the target are
  taken with certainty.
- **A modest step downhill** (from $x = 0$ to $x' = 1$): $\alpha = e^{-1/2} \approx
  0.61$. Roughly three in five such proposals are accepted, so the chain wanders into
  the tail often enough to sample it.
- **A long step downhill** (from $x = 0$ to $x' = 3$): $\alpha = e^{-9/2} \approx
  0.011$. About one in ninety is accepted; the chain rarely jumps far into a
  low-probability region, which is what makes the time spent in each region track its
  probability.

The asymmetry is the whole mechanism: never refusing an uphill move and accepting
downhill moves in proportion to the density drop is what makes the stationary
distribution $\pi$ rather than something flatter.

## Proposal choice and mixing

The proposal $q(x' \mid x)$ controls the chain's mixing speed:

- **Too narrow:** many proposals accepted, but the chain moves slowly (high autocorrelation).
- **Too wide:** proposals land in low-probability regions, acceptance rate drops, chain is sticky.

For a random-walk proposal $q(x' \mid x) = \mathcal{N}(x, \sigma^2 I)$ in $d$ dimensions,
the rule of thumb is to tune $\sigma$ to achieve ~23% acceptance.

## Burn-in and autocorrelation

MCMC samples are correlated.
Discard early samples (burn-in) before the chain reaches stationarity.
Estimate the **effective sample size** by accounting for autocorrelation:

$$
N_\text{eff} \approx \frac{N}{1 + 2 \sum_{t=1}^\infty \rho_t},
$$

where $\rho_t$ is the autocorrelation at lag $t$.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(19)

# Target: bivariate Gaussian with correlation
mu_target = np.array([1.0, -2.0])
Sigma_target = np.array([[1.0, 0.8], [0.8, 1.0]])
L = np.linalg.cholesky(Sigma_target)

def log_target(x):
    diff = x - mu_target
    return -0.5 * diff @ np.linalg.solve(Sigma_target, diff)

# Random-walk MH
N = 20_000
step_size = 0.8
samples = np.zeros((N, 2))
samples[0] = np.zeros(2)
n_accept = 0

for t in range(1, N):
    x_curr = samples[t-1]
    x_prop = x_curr + rng.normal(0, step_size, 2)
    log_alpha = log_target(x_prop) - log_target(x_curr)
    if np.log(rng.random()) < log_alpha:
        samples[t] = x_prop
        n_accept += 1
    else:
        samples[t] = x_curr

burnin = 2000
posterior = samples[burnin:]
print(f"Acceptance rate: {n_accept/N:.2f}  (target ~0.23 for 2D)")
print(f"Sample mean:     {posterior.mean(axis=0).round(3)}  (true: {mu_target})")
print(f"Sample Sigma:\n{np.cov(posterior.T).round(3)}")
print(f"True Sigma:\n{Sigma_target}")
```

The chain recovers the true mean and covariance structure; acceptance near 0.23 is
consistent with the asymptotically optimal rate for the random-walk proposal in
moderate dimensions.

## Exercises

**Exercise 1.** A standard normal target $\pi(x) \propto e^{-x^2/2}$ is sampled
with a symmetric random-walk proposal. Compute the acceptance probability
$\alpha$ for a proposed move from $x = 0$ to $x' = 2$.

<details>
<summary>Solution</summary>

**Step 1.** The proposal is symmetric, so $q(x \mid x') = q(x' \mid x)$ and those
factors cancel from the ratio. What remains is
$\alpha = \min(1, \pi(x') / \pi(x))$.

**Step 2.** Substitute the unnormalized target $\tilde{\pi}(x) = e^{-x^2/2}$:

$$
\frac{\pi(x')}{\pi(x)} = \frac{e^{-x'^2/2}}{e^{-x^2/2}} = e^{-(x'^2 - x^2)/2}
= e^{-(4 - 0)/2} = e^{-2}.
$$

**Step 3.** Since $e^{-2} \approx 0.135 < 1$, the acceptance probability is
$\alpha = e^{-2} \approx 0.135$. The move steps downhill into the tail, so it is
accepted only about one time in seven.

</details>

**Exercise 2.** Show that the Metropolis-Hastings kernel
$T(x' \mid x) = q(x' \mid x)\,\alpha(x' \mid x)$ satisfies detailed balance in the
remaining case: a pair $(x, x')$ where the forward move has $\alpha = 1$, so the
reverse move has $\alpha < 1$.

<details>
<summary>Solution</summary>

**Step 1.** The forward direction has $\alpha(x' \mid x) = 1$, which means
$\pi(x') q(x \mid x') \ge \pi(x) q(x' \mid x)$. The reverse direction then has
ratio at most $1$, so

$$
\alpha(x \mid x') = \frac{\pi(x) q(x' \mid x)}{\pi(x') q(x \mid x')}.
$$

**Step 2.** Write both sides of detailed balance. The left side uses the forward
kernel with $\alpha(x' \mid x) = 1$:

$$
\pi(x) T(x' \mid x) = \pi(x) q(x' \mid x) \cdot 1 = \pi(x) q(x' \mid x).
$$

**Step 3.** The right side uses the reverse kernel; the $\pi(x') q(x \mid x')$
factors cancel:

$$
\pi(x') T(x \mid x') = \pi(x') q(x \mid x') \cdot
\frac{\pi(x) q(x' \mid x)}{\pi(x') q(x \mid x')} = \pi(x) q(x' \mid x).
$$

Both sides equal $\pi(x) q(x' \mid x)$, so detailed balance holds. By symmetry of
the argument this covers every pair, and $\pi$ is therefore stationary.

</details>

**Exercise 3 (code).** Implement random-walk Metropolis-Hastings for a 1D
standard normal target with proposal step $\sigma = 2.4$. Run $40{,}000$ steps
from a fixed seed and check that the sample mean is near $0$ and the sample
variance near $1$.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)

def log_target(x):           # standard normal, unnormalized
    return -0.5 * x**2

N = 40_000
step = 2.4
x = 0.0
samples = np.empty(N)
n_accept = 0

for t in range(N):
    x_prop = x + rng.normal(0, step)
    if np.log(rng.random()) < log_target(x_prop) - log_target(x):
        x = x_prop
        n_accept += 1
    samples[t] = x

post = samples[2000:]                  # discard burn-in
print(f"acceptance: {n_accept / N:.3f}")
print(f"mean {post.mean():.3f} (true 0), var {post.var():.3f} (true 1)")

assert abs(post.mean()) < 0.1          # converges to the target mean
assert abs(post.var() - 1.0) < 0.15    # and the target variance
```

The chain recovers mean $\approx 0$ and variance $\approx 1$ with an acceptance
rate near $0.44$, the range a moderate step size produces for a 1D Gaussian. The
asserts confirm convergence to the target moments rather than to a flatter or
narrower distribution.

</details>
