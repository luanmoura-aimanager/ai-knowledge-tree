CAVI processes the full dataset at each update step: its cost scales linearly with $N$.
**Stochastic variational inference** (SVI) makes VI practical at scale by estimating the
ELBO gradient on random mini-batches and applying stochastic gradient ascent<FN n="1" />.

## Mini-batch ELBO

For an i.i.d. likelihood $P(\mathbf{X} \mid \mathbf{Z}) = \prod_n P(x_n \mid z_n, \theta)$,
the ELBO decomposes as:

$$
\mathcal{L} = \sum_n \mathbb{E}_{q(z_n)}[\log P(x_n \mid z_n, \theta)]
- \mathrm{KL}(q(\theta) \| P(\theta))
- \sum_n \mathrm{KL}(q(z_n) \| P(z_n)).
$$

On a mini-batch $\mathcal{B}$ of size $M$, the likelihood terms are subsampled and rescaled:

$$
\mathcal{L}_\mathcal{B} = \frac{N}{M} \sum_{n \in \mathcal{B}} \mathbb{E}_{q(z_n)}[\log P(x_n \mid z_n, \theta)]
- \mathrm{KL}(q(\theta) \| P(\theta))
- \frac{N}{M} \sum_{n \in \mathcal{B}} \mathrm{KL}(q(z_n) \| P(z_n)).
$$

$\mathbb{E}[\mathcal{L}_\mathcal{B}] = \mathcal{L}$, so the mini-batch estimate is unbiased.

## Reparameterization trick

To backpropagate through a sample $z \sim q_\phi(z)$, rewrite the sample as a
deterministic function of the parameters plus a noise variable:

$$
z = g_\phi(\epsilon), \quad \epsilon \sim p(\epsilon),
$$

where $p(\epsilon)$ is a fixed distribution independent of $\phi$.

For $q_\phi(z) = \mathcal{N}(\mu_\phi, \sigma_\phi^2)$: set $z = \mu_\phi + \sigma_\phi \cdot \epsilon$,
$\epsilon \sim \mathcal{N}(0,1)$.

The gradient estimate then is:

$$
\nabla_\phi \mathbb{E}_{q_\phi}[f(z)]
= \mathbb{E}_{p(\epsilon)}[\nabla_\phi f(g_\phi(\epsilon))]
\approx \frac{1}{S} \sum_{s=1}^{S} \nabla_\phi f(g_\phi(\epsilon^{(s)})).
$$

This **pathwise estimator** has much lower variance than the score-function estimator
because the gradient passes through $f$ directly rather than through $\log q$<FN n="2" />.

## Score-function estimator (REINFORCE)

An alternative is:

$$
\nabla_\phi \mathbb{E}_{q_\phi}[f(z)]
= \mathbb{E}_{q_\phi}[f(z) \nabla_\phi \log q_\phi(z)].
$$

This holds for any $q_\phi$ (no reparameterizability required), but the variance is
typically much higher than the reparameterization trick.
Control variates (baselines) reduce variance at the cost of additional code complexity.

The gap is concrete. Take $q_\phi = \mathcal{N}(\mu, 1)$ at $\mu = 1$ and the simple
integrand $f(z) = z^2$, and estimate $\nabla_\mu \mathbb{E}_q[z^2]$ (whose true value
is $2\mu = 2$). The pathwise estimate is $2z$ with $z = \mu + \epsilon$, so its
per-sample variance is $\mathrm{Var}(2z) = 4$. The score-function estimate is
$z^2\,(z-\mu)$, whose per-sample variance is $30$: a $7.5\times$ heavier single-sample
estimate, both unbiased and both centered on $2$. The ratio is modest here only
because $f$ and $\mu$ are small; it grows quickly as the integrand takes larger
values or the proposal tightens, which is why reparameterization is the default
whenever $q_\phi$ admits it.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(18)

# Simple SVI: fit q(z) = N(mu, sigma^2) to minimize KL(q || target)
# Target: N(3.0, 0.5^2)
target_mu    = 3.0
target_sigma = 0.5

# Variational parameters
mu    = 0.0
log_sigma = 0.0   # sigma = exp(log_sigma)
lr = 0.05
n_steps = 300
S = 10   # samples per gradient estimate

def elbo_grad(mu, log_sigma):
    sigma = np.exp(log_sigma)
    eps   = rng.normal(0, 1, S)
    z     = mu + sigma * eps          # reparameterization

    # log p(z) - log q(z) for N(target_mu, target_sigma^2)
    log_p = -0.5 * ((z - target_mu) / target_sigma)**2 - np.log(target_sigma)
    log_q = -0.5 * eps**2 - log_sigma   # N(mu, sigma^2) at z = mu + sigma*eps

    f = log_p - log_q   # (log_p - log_q) = ELBO per sample

    # Gradients via reparameterization
    # d/dmu of (log_p - log_q): dz/dmu = 1, d(-log_q)/dmu = 0 (eps independent of mu)
    # d/d(log_sigma): dz/d(log_sigma) = sigma*eps; d(-log_q)/d(log_sigma) = +1
    dlog_p_dz = -(z - target_mu) / target_sigma**2
    grad_mu       = (dlog_p_dz * 1.0).mean()
    grad_log_sigma = (dlog_p_dz * sigma * eps + 1.0).mean()
    return grad_mu, grad_log_sigma

for step in range(n_steps):
    g_mu, g_ls = elbo_grad(mu, log_sigma)
    mu        += lr * g_mu
    log_sigma += lr * g_ls

print(f"Fitted mu: {mu:.3f} (target {target_mu})")
print(f"Fitted sigma: {np.exp(log_sigma):.3f} (target {target_sigma})")
```

The reparameterized gradient converges toward the target parameters because it provides
low-variance, unbiased gradient estimates through the stochastic node.

## Exercises

**Exercise 1.** Show that the mini-batch ELBO $\mathcal{L}_\mathcal{B}$ is an unbiased
estimator of the full ELBO $\mathcal{L}$, where $\mathcal{B}$ is a uniform random subset
of $M$ of the $N$ likelihood terms, rescaled by $N/M$.

<details>
<summary>Solution</summary>

**Step 1.** Write the per-datapoint likelihood contributions as $g_n = \mathbb{E}_{q(z_n)}[\log P(x_n \mid z_n, \theta)] - \mathrm{KL}(q(z_n) \| P(z_n))$, so the data-dependent part of $\mathcal{L}$ is $\sum_{n=1}^{N} g_n$. The mini-batch version is $\frac{N}{M}\sum_{n \in \mathcal{B}} g_n$.

**Step 2.** For a uniform subset of size $M$ drawn without replacement, each index $n$ is included with probability $M/N$. Let $\mathbb{1}_n$ indicate $n \in \mathcal{B}$, so $\mathbb{E}[\mathbb{1}_n] = M/N$. Then

$$
\mathbb{E}\!\left[\frac{N}{M}\sum_{n \in \mathcal{B}} g_n\right]
= \frac{N}{M}\sum_{n=1}^{N} \mathbb{E}[\mathbb{1}_n]\, g_n
= \frac{N}{M}\sum_{n=1}^{N} \frac{M}{N}\, g_n
= \sum_{n=1}^{N} g_n.
$$

**Step 3.** The $\mathrm{KL}(q(\theta) \| P(\theta))$ term carries no $n$ index and appears in both, so adding it back leaves $\mathbb{E}[\mathcal{L}_\mathcal{B}] = \mathcal{L}$. The estimator is unbiased; the $N/M$ factor corrects the subsampling.

</details>

**Exercise 2.** For $q_\phi = \mathcal{N}(\mu, 1)$ and $f(z) = z^2$, compute the
per-sample variance of both gradient estimators of $\nabla_\mu \mathbb{E}_q[z^2]$ at
$\mu = 1$: the pathwise estimate $2z$ and the score-function estimate $z^2(z - \mu)$.
Confirm both are unbiased with mean $2$.

<details>
<summary>Solution</summary>

**Step 1.** Write $z = \mu + \epsilon$ with $\epsilon \sim \mathcal{N}(0,1)$, so at $\mu = 1$ the moments of $z$ are $\mathbb{E}[z] = 1$, $\mathbb{E}[z^2] = 2$, $\mathbb{E}[z^3] = 4$, $\mathbb{E}[z^4] = 10$ (central moments of a unit Gaussian shifted to mean $1$).

**Step 2.** Pathwise estimator $2z$: mean $\mathbb{E}[2z] = 2$, and $\mathrm{Var}(2z) = 4\,\mathrm{Var}(z) = 4 \cdot 1 = 4$.

**Step 3.** Score-function estimator $z^2(z - \mu) = z^2\epsilon$: its mean is $\mathbb{E}[z^2\epsilon]$. Expanding $z^2 = (1+\epsilon)^2 = 1 + 2\epsilon + \epsilon^2$ gives $z^2\epsilon = \epsilon + 2\epsilon^2 + \epsilon^3$, whose expectation is $0 + 2 \cdot 1 + 0 = 2$. For the variance, expand $(\epsilon + 2\epsilon^2 + \epsilon^3)^2 = \epsilon^2 + 4\epsilon^3 + (4{+}2)\epsilon^4 + 4\epsilon^5 + \epsilon^6$, where the $\epsilon^4$ term collects $b^2 = 4\epsilon^4$ and the cross term $2ac = 2\epsilon^4$. Using $\mathbb{E}[\epsilon^2]=1, \mathbb{E}[\epsilon^4]=3, \mathbb{E}[\epsilon^6]=15$ and dropping the odd moments, $\mathbb{E}[(z^2\epsilon)^2] = 1 + 6 \cdot 3 + 15 = 34$, so $\mathrm{Var}(z^2\epsilon) = 34 - 2^2 = 30$.

**Step 4.** Both estimators average to $2$, but the score-function variance $30$ is $7.5\times$ the pathwise variance $4$. The pathwise gradient is the lower-noise choice whenever $q_\phi$ is reparameterizable.

</details>

**Exercise 3 (code).** Verify both estimators of $\nabla_\mu \mathbb{E}_q[z^2]$ at
$\mu = 1$ have mean $2$, and that the score-function variance ($30$) is about $7.5\times$
the pathwise variance ($4$).

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)
mu = 1.0
S = 2_000_000
eps = rng.normal(0, 1, S)
z = mu + eps

pathwise = 2 * z                 # d/dmu f(g(eps)) = 2z, since dz/dmu = 1
score    = z**2 * (z - mu)       # f(z) * d/dmu log q(z), with d log q/dmu = z - mu

print("pathwise mean:", round(pathwise.mean(), 3), "var:", round(pathwise.var(), 3))
print("score    mean:", round(score.mean(), 3), "var:", round(score.var(), 3))
print("variance ratio:", round(score.var() / pathwise.var(), 2))

assert abs(pathwise.mean() - 2.0) < 0.01 and abs(score.mean() - 2.0) < 0.02
assert abs(pathwise.var() - 4.0) < 0.05      # Var(2z) = 4
assert abs(score.var() - 30.0) < 0.3         # Var(z^2 eps) = 30
```

Both estimators center on $2$; the score-function variance lands near $30$ against the
pathwise $4$, the $7.5\times$ gap from Exercise 2.
