Mean-field VI and Gaussian encoders limit the variational family to simple, unimodal
distributions.
**Normalizing flows** compose a series of invertible transformations to map a simple
base distribution into a rich, complex posterior, while keeping the log-density tractable
via the change-of-variables formula<FN n="1" />.

## Change-of-variables formula

Let $z_0 \sim q_0(z_0)$ (e.g., $\mathcal{N}(0, I)$) and $z_K = f_K \circ \cdots \circ f_1(z_0)$
where each $f_k$ is invertible and differentiable.

The log-density of $z_K$ under the push-forward is:

$$
\log q_K(z_K)
= \log q_0(z_0) - \sum_{k=1}^{K} \log \left|\det \frac{\partial f_k}{\partial z_{k-1}}\right|.
$$

Computing this requires the log-determinant of the Jacobian at each step.
Flows are designed so that this determinant is cheap to compute.

## Planar flow

A **planar flow** applies a single rank-1 update:

$$
f(z) = z + u \cdot h(w^\top z + b),
$$

where $u, w \in \mathbb{R}^d$ and $b \in \mathbb{R}$ are learnable parameters,
and $h$ is a smooth nonlinearity such as $\tanh$.

The log-determinant of its Jacobian is:

$$
\log \left|\det \frac{\partial f}{\partial z}\right|
= \log \left|1 + u^\top h'(w^\top z + b) w\right|,
$$

which is $O(d)$ to compute rather than $O(d^3)$.

**Derivation.** The Jacobian is $I + u (h'(w^\top z + b) w)^\top$, a rank-1 update
of the identity. By the matrix determinant lemma:
$\det(I + uv^\top) = 1 + v^\top u$,
so $|\det J| = |1 + u^\top (h'(w^\top z + b) w)|$.

## ELBO with flow posterior

The ELBO using a $K$-step flow as variational posterior is<FN n="2" />:

$$
\mathcal{L} = \mathbb{E}_{q_0(z_0)}\!\left[
  \log p(\mathbf{x} \mid z_K)
  + \log p(z_K)
  - \log q_0(z_0)
  + \sum_{k=1}^{K} \log \left|\det J_k\right|
\right].
$$

All terms are differentiable with respect to the flow parameters via the reparameterization
trick ($z_0 = \mu + \sigma \epsilon$, $\epsilon \sim \mathcal{N}(0,I)$).

## Implementation

```python
import numpy as np

rng = np.random.default_rng(33)

def tanh(x):
    return np.tanh(x)

def dtanh(x):
    return 1.0 - np.tanh(x)**2

class PlanarFlow:
    def __init__(self, d):
        self.w = rng.normal(0, 0.1, d)
        self.u = rng.normal(0, 0.1, d)
        self.b = 0.0

    def forward(self, z):
        lin = z @ self.w + self.b           # shape (N,)
        h   = tanh(lin)                     # (N,)
        return z + np.outer(h, self.u), lin  # (N, d), (N,)

    def log_det_jacobian(self, lin):
        # psi = h'(w^T z + b) * w
        psi = np.outer(dtanh(lin), self.w)  # (N, d)
        return np.log(np.abs(1.0 + psi @ self.u))  # (N,)

# Test: 2D standard normal, push through 3 planar flows
d = 2
N = 2000
flows = [PlanarFlow(d) for _ in range(3)]

z0 = rng.normal(0, 1, (N, d))
log_q0 = -0.5 * (z0**2).sum(axis=1) - d/2 * np.log(2*np.pi)

z = z0.copy()
log_det_sum = np.zeros(N)
for flow in flows:
    z, lin = flow.forward(z)
    log_det_sum += flow.log_det_jacobian(lin)

# log q_K(z_K) = log q_0(z_0) - sum log|det J_k|
log_qK = log_q0 - log_det_sum

# Normalizing constant check: mean of exp(log q_0)/exp(log q_K) * vol should be 1
# For qualitative check: compare empirical moments
print(f"z_0 mean: {z0.mean(axis=0).round(3)}, std: {z0.std(axis=0).round(3)}")
print(f"z_K mean: {z.mean(axis=0).round(3)}, std: {z.std(axis=0).round(3)}")
print(f"Mean log|det J|: {log_det_sum.mean():.3f} (positive = volume expansion)")
print(f"Variance of log q_K: {log_qK.var():.3f}  (0 for uniform, larger = peaked)")
```

The flow transforms the Gaussian base into a distribution with different shape and
dispersion; the log-density at each transformed sample can be computed exactly,
making the ELBO gradient tractable.

## Exercises

**Exercise 1.** Derive the planar-flow log-determinant
$\log|\det J| = \log|1 + u^\top h'(w^\top z + b)\, w|$ from the matrix determinant lemma,
starting from the map $f(z) = z + u\, h(w^\top z + b)$.

<details>
<summary>Solution</summary>

**Step 1.** Differentiate $f$ with respect to $z$. The first term gives the identity $I$. For the second, $h(w^\top z + b)$ is a scalar function of $z$, so by the chain rule $\frac{\partial}{\partial z} h(w^\top z + b) = h'(w^\top z + b)\, w^\top$ (a row vector). Multiplying by the constant column $u$,

$$
J = \frac{\partial f}{\partial z} = I + u\,\big(h'(w^\top z + b)\, w\big)^\top.
$$

**Step 2.** This is a rank-1 update of the identity, $J = I + u v^\top$ with $v = h'(w^\top z + b)\, w$. The matrix determinant lemma gives $\det(I + u v^\top) = 1 + v^\top u$.

**Step 3.** Substitute $v$ back: $\det J = 1 + (h'(w^\top z + b)\, w)^\top u = 1 + u^\top h'(w^\top z + b)\, w$ (the scalar $h'$ commutes). Taking the log of the absolute value gives $\log|\det J| = \log|1 + u^\top h'(w^\top z + b)\, w|$, which costs $O(d)$ rather than the $O(d^3)$ of a general determinant.

</details>

**Exercise 2.** A single planar flow with $\tanh$ nonlinearity can become
non-invertible if $u$ is chosen freely. Using $h'(\cdot) = 1 - \tanh^2(\cdot) \in (0, 1]$,
find the condition on $u^\top w$ that guarantees $\det J > 0$ for all $z$, so the flow
stays invertible.

<details>
<summary>Solution</summary>

**Step 1.** From Exercise 1, $\det J = 1 + u^\top w\, h'(w^\top z + b)$, where the scalar $h'(w^\top z + b) = 1 - \tanh^2(w^\top z + b)$ ranges over $(0, 1]$ as $z$ varies. Write $s = h' \in (0, 1]$ and $\beta = u^\top w$, so $\det J = 1 + \beta s$.

**Step 2.** If $\beta \ge 0$, then $1 + \beta s \ge 1 > 0$ for all $s$, so invertibility is automatic. The binding case is $\beta < 0$, where $\det J$ is smallest at the largest $s = 1$: $\det J = 1 + \beta$.

**Step 3.** Requiring $1 + \beta > 0$ gives $\beta = u^\top w > -1$. So the flow is invertible for all $z$ whenever $u^\top w > -1$; the standard fix when this fails is to reparameterize $u$ so the constraint holds.

</details>

**Exercise 3 (code).** Verify the planar-flow log-determinant formula against a
numerical Jacobian determinant at a random point, and confirm the matrix determinant
lemma $\det(I + uv^\top) = 1 + v^\top u$ directly.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)
d = 4

# Matrix determinant lemma, checked against a full determinant
for _ in range(5):
    u = rng.normal(0, 1, d)
    v = rng.normal(0, 1, d)
    J = np.eye(d) + np.outer(u, v)
    assert np.isclose(np.linalg.det(J), 1 + v @ u)

# Planar flow: analytic log|det J| vs a central-difference Jacobian
def tanh(x):  return np.tanh(x)
def dtanh(x): return 1.0 - np.tanh(x)**2

w = rng.normal(0, 1, d)
u = rng.normal(0, 0.3, d)
b = 0.2
z = rng.normal(0, 1, d)

lin = w @ z + b
psi = dtanh(lin) * w                       # v = h'(w^T z + b) w
logdet_analytic = np.log(abs(1 + u @ psi))

def f(zz):
    return zz + u * tanh(w @ zz + b)

eps = 1e-6
Jn = np.zeros((d, d))
for j in range(d):
    dz = np.zeros(d); dz[j] = eps
    Jn[:, j] = (f(z + dz) - f(z - dz)) / (2 * eps)
logdet_numeric = np.log(abs(np.linalg.det(Jn)))

print("analytic:", round(logdet_analytic, 6), " numeric:", round(logdet_numeric, 6))
assert np.isclose(logdet_analytic, logdet_numeric, atol=1e-4)
```

The $O(d)$ closed form matches the full $O(d^3)$ determinant to numerical precision,
confirming the rank-1 structure the planar flow exploits.

</details>
