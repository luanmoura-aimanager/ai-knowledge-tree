Bayesian neural networks and ensembles provide uncertainty estimates, but they require
distributional assumptions and careful calibration.
**Conformal prediction** provides a finite-sample marginal coverage guarantee
under a single assumption: exchangeability<FN ns="1, 2" />.
It wraps any pre-trained model and produces prediction sets with provable coverage,
no matter how the underlying model was trained.

## Setup: split conformal prediction

Split the labeled data into a **training set** (used to fit the model) and a
**calibration set** $\{(x_i, y_i)\}_{i=1}^n$.

Define a **nonconformity score** $s(x, y)$ that measures how poorly $y$ fits the model
at input $x$.
For regression: $s(x, y) = |y - \hat{f}(x)|$ (absolute residual).
For classification: $s(x, y) = 1 - \hat{p}(y \mid x)$ (one minus the predicted probability).

Compute calibration scores $s_i = s(x_i, y_i)$ for all calibration points.

## Prediction interval construction

For a new test point $x_\text{test}$ and desired coverage $1 - \alpha$:

1. Compute the $(1 - \alpha)(1 + 1/n)$-th empirical quantile of $\{s_1, \ldots, s_n\}$:

$$
\hat{q} = \text{Quantile}\!\left(\{s_i\}_{i=1}^n;\; \frac{\lceil (1-\alpha)(n+1) \rceil}{n}\right).
$$

2. Predict the set $C(x_\text{test}) = \{y : s(x_\text{test}, y) \le \hat{q}\}$.

For regression, this gives the interval $[\hat{f}(x_\text{test}) - \hat{q},\; \hat{f}(x_\text{test}) + \hat{q}]$.

## Coverage guarantee

**Theorem.** Under exchangeability of $(x_1, y_1), \ldots, (x_n, y_n), (x_\text{test}, y_\text{test})$<FN n="2" />:

$$
P(y_\text{test} \in C(x_\text{test})) \ge 1 - \alpha.
$$

**Proof sketch.**
The test point's score $s_\text{test}$ is exchangeable with the calibration scores.
The interval covers $y_\text{test}$ iff $s_\text{test} \le \hat{q}$,
i.e., iff $s_\text{test}$ is not among the top $\lfloor \alpha (n+1) \rfloor$ scores.
By exchangeability, the rank of $s_\text{test}$ among $n+1$ values is uniform
on $\{1, \ldots, n+1\}$, so the probability of being in the top $\alpha (n+1)$
fraction is at most $\alpha$.

The guarantee is **marginal**: it holds over the randomness of both the calibration set
and the test point. It does not guarantee coverage for any specific $x_\text{test}$.

## Conditional coverage and class-conditional splits

Marginal coverage can be misleading: the interval might be narrow where the model
is confident and wide elsewhere, but on average achieves $1-\alpha$.
**Class-conditional conformal prediction** splits calibration by class label (for
classification) or by predicted-value quantile (for regression) to obtain more
homogeneous sets.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(51)

# Regression: y = 2x + sin(3x) + noise
N = 1500
x_all = rng.uniform(-3, 3, N)
y_all = 2*x_all + np.sin(3*x_all) + rng.normal(0, 0.8, N)

# Split: 700 train, 400 calibration, 400 test
idx = rng.permutation(N)
x_tr, y_tr   = x_all[idx[:700]], y_all[idx[:700]]
x_cal, y_cal = x_all[idx[700:1100]], y_all[idx[700:1100]]
x_te, y_te   = x_all[idx[1100:]], y_all[idx[1100:]]

# Polynomial features, standardized (raw powers on [-3,3] are badly scaled)
def poly(x):
    return np.column_stack([x**k for k in range(1, 5)])

feat_mean, feat_std = poly(x_tr).mean(0), poly(x_tr).std(0)
def featurize(x):
    return (poly(x) - feat_mean) / feat_std

# Ridge regression via the normal equations. Carry the intercept separately
# (it stays unpenalized) so it is fit by centering rather than a bias column.
def ridge_fit(x, y, alpha=1.0):
    Phi = featurize(x)
    y_bar = y.mean()
    d = Phi.shape[1]
    w = np.linalg.solve(Phi.T @ Phi + alpha * np.eye(d), Phi.T @ (y - y_bar))
    return y_bar, w

def predict(coef, x):
    y_bar, w = coef
    return y_bar + (featurize(x) * w).sum(axis=1)

coef = ridge_fit(x_tr, y_tr, alpha=1.0)

# Calibration scores: absolute residuals
cal_scores = np.abs(y_cal - predict(coef, x_cal))

# Construct interval at alpha=0.1 (target 90% coverage)
alpha = 0.1
n = len(cal_scores)
quantile_level = np.ceil((1 - alpha) * (n + 1)) / n
q_hat = np.quantile(cal_scores, min(quantile_level, 1.0))

# Evaluate on test set
y_pred_te = predict(coef, x_te)
lower = y_pred_te - q_hat
upper = y_pred_te + q_hat
coverage = np.mean((y_te >= lower) & (y_te <= upper))
avg_width = (upper - lower).mean()

print(f"Conformal quantile: {q_hat:.3f}")
print(f"Empirical coverage: {coverage:.3f}  (target >= {1-alpha:.2f})")
print(f"Average interval width: {avg_width:.3f}")

# Coverage for points in and out of training range
in_range  = np.abs(x_te) < 2.5
out_range = ~in_range
print(f"Coverage in range:  {np.mean((y_te[in_range] >= lower[in_range]) & (y_te[in_range] <= upper[in_range])):.3f}")
print(f"Coverage out of range: {np.mean((y_te[out_range] >= lower[out_range]) & (y_te[out_range] <= upper[out_range])):.3f}")
```

The marginal coverage meets the $1 - \alpha$ guarantee; the interval width is constant
across $x$ because the absolute-residual score is not adaptive to local uncertainty,
which is the limitation that conditional conformal methods address.
