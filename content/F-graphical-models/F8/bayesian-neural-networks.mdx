MC dropout and ensembles approximate Bayesian uncertainty without explicitly
maintaining a distribution over weights.
A **Bayesian neural network** (BNN) does maintain one: a prior $p(\theta)$ over
all network parameters, updated to a posterior $p(\theta \mid \mathcal{D})$ given data<FN n="1" />.

The core challenge is that the weight space has millions of dimensions, making
exact posterior inference impossible. Two tractable approximations are the Laplace
approximation and mean-field variational inference.

## The BNN objective

Prior: $p(\theta) = \mathcal{N}(0, \sigma_0^2 I)$.
Likelihood: $p(\mathcal{D} \mid \theta) = \prod_n p(y_n \mid f_\theta(x_n))$.

The posterior $p(\theta \mid \mathcal{D}) \propto p(\mathcal{D} \mid \theta) p(\theta)$
is intractable because the normalizing constant integrates over all weight configurations.

## Laplace approximation

The Laplace approximation fits a Gaussian to the posterior at the MAP estimate.

**Step 1.** Find the MAP: $\theta^* = \arg\max_\theta [\log p(\mathcal{D} \mid \theta) + \log p(\theta)]$.
This is equivalent to L2-regularized training.

**Step 2.** Compute the Hessian of the negative log-posterior at $\theta^*$:

$$
H = -\nabla^2_\theta \log p(\theta^* \mid \mathcal{D}).
$$

**Step 3.** Approximate $p(\theta \mid \mathcal{D}) \approx \mathcal{N}(\theta^*,\, H^{-1})$.

The full Hessian is $O(d^2)$ in storage and $O(d^2)$ or $O(d^3)$ to compute for a
network with $d$ parameters.
**Last-layer Laplace** (LL-LA) applies the approximation only to the final linear layer,
making it tractable at the cost of some approximation quality.

## Mean-field variational BNN

The mean-field ELBO for BNNs is:

$$
\mathcal{L}(\phi) = \mathbb{E}_{q_\phi(\theta)}[\log p(\mathcal{D} \mid \theta)]
- \mathrm{KL}(q_\phi(\theta) \| p(\theta)),
$$

where $q_\phi(\theta) = \prod_j \mathcal{N}(\mu_j, \sigma_j^2)$ factorizes over all weights.

**Bayes by Backprop** (Blundell et al., 2015) optimizes this ELBO using the
reparameterization trick: $\theta_j = \mu_j + \sigma_j \epsilon_j$ with $\epsilon_j \sim \mathcal{N}(0,1)$<FN n="2" />.
All gradients flow through the reparameterized samples.

The local reparameterization trick further reduces variance by perturbing activations
rather than weights, which is more memory-efficient for wide networks.

## Predictive distribution

Given the posterior approximation, the predictive distribution is:

$$
p(y^* \mid x^*, \mathcal{D}) = \int p(y^* \mid f_\theta(x^*)) q_\phi(\theta) d\theta
\approx \frac{1}{S} \sum_{s=1}^S p(y^* \mid f_{\theta^{(s)}}(x^*)),
$$

where $\theta^{(s)} \sim q_\phi(\theta)$.
This Monte Carlo average provides both a point estimate and a measure of predictive uncertainty.

The predictive standard deviation is the quantity to build a feel for, and the cleanest
read is a contrasting pair: two inputs differing only in how far they sit from the
training cloud. On the logistic-regression BNN in the code below (Laplace posterior,
2000 weight samples), the training inputs have norm $\approx 1.2$ on average, so:

- **A point inside the data**, $x^* = (0.3, 0.3)$: predictive mean $0.543$, predictive
  std $0.025$. The sampled weights all map this point to nearly the same probability,
  so the prediction is tight.
- **A point far outside the data**, $x^* = (4, 4)$: predictive mean $0.853$, predictive
  std $0.151$, six times wider. The posterior is barely constrained in that direction,
  so the weight samples disagree, and the disagreement surfaces as uncertainty.

A non-Bayesian network would report a single number at both points and look equally
confident at $(4,4)$ as at $(0.3,0.3)$. The widening std is what the prior-over-weights
buys: the model reports that it has not seen data out there.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(47)

# Laplace approximation on a logistic regression (1-layer BNN)
# Data: 2D binary classification
N = 100
theta_true = np.array([2.0, -1.5])
x_data = rng.normal(0, 1, (N, 2))
logits = x_data @ theta_true
y_data = (rng.random(N) < 1 / (1 + np.exp(-logits))).astype(float)

def sigmoid(z):
    return 1 / (1 + np.exp(-np.clip(z, -30, 30)))

def neg_log_posterior(theta, lam=1.0):
    logp = -(y_data * np.log(sigmoid(x_data @ theta) + 1e-10)
             + (1 - y_data) * np.log(1 - sigmoid(x_data @ theta) + 1e-10)).sum()
    logp += 0.5 * lam * (theta**2).sum()   # prior N(0, 1/lam)
    return logp

# MAP via gradient descent
theta = np.zeros(2)
lr = 0.05
for _ in range(500):
    s  = sigmoid(x_data @ theta)
    g  = x_data.T @ (s - y_data) + theta   # grad of neg log posterior
    theta -= lr * g

# Laplace: Hessian of neg log posterior
s = sigmoid(x_data @ theta)
H = x_data.T @ np.diag(s * (1 - s)) @ x_data + np.eye(2)   # + prior precision
Sigma_laplace = np.linalg.inv(H)

# MC predictive variance
x_test = np.array([[1.0, 0.5], [-1.0, 1.0]])
S = 2000
theta_samples = rng.multivariate_normal(theta, Sigma_laplace, S)
preds = sigmoid(x_test @ theta_samples.T)   # (n_test, S)
pred_mean = preds.mean(axis=1)
pred_std  = preds.std(axis=1)

print(f"MAP estimate:      {theta.round(3)}  (true: {theta_true})")
print(f"Laplace covariance:\n{Sigma_laplace.round(4)}")
print(f"\nPredictive mean:   {pred_mean.round(3)}")
print(f"Predictive std:    {pred_std.round(3)}")

# Inside the data vs far outside it: predictive std widens
print(f"\nMean training-input norm: {np.linalg.norm(x_data, axis=1).mean():.2f}")
x_cal = np.array([[0.3, 0.3], [4.0, 4.0]])    # inside the cloud vs far outside
preds_cal = sigmoid(x_cal @ theta_samples.T)
print(f"Mean (in / far): {preds_cal.mean(axis=1).round(3)}")
print(f"Std  (in / far): {preds_cal.std(axis=1).round(3)}  (far is ~6x wider)")
```

The Laplace posterior gives calibrated predictive uncertainty for points near the
decision boundary; the posterior covariance reflects both data noise and limited
sample size.

## Exercises

**Exercise 1.** Derive the Laplace approximation by second-order Taylor-expanding the
log-posterior $\log p(\theta \mid \mathcal{D})$ around the MAP estimate $\theta^*$, and
show why the linear term vanishes.

<details>
<summary>Solution</summary>

**Step 1.** Let $g(\theta) = \log p(\theta \mid \mathcal{D})$. Expand to second order
about $\theta^*$:

$$
g(\theta) \approx g(\theta^*) + \nabla g(\theta^*)^\top (\theta - \theta^*)
+ \tfrac12 (\theta - \theta^*)^\top \nabla^2 g(\theta^*) (\theta - \theta^*).
$$

**Step 2.** $\theta^*$ is the MAP, a maximizer of $g$, so its gradient is zero:
$\nabla g(\theta^*) = 0$. The linear term drops, leaving a pure quadratic in
$\theta - \theta^*$.

**Step 3.** Write $H = -\nabla^2 g(\theta^*)$ (the negative Hessian, positive definite at
a maximum). Then $g(\theta) \approx g(\theta^*) - \tfrac12 (\theta - \theta^*)^\top H (\theta - \theta^*)$.
Exponentiating, $p(\theta \mid \mathcal{D}) \propto \exp(-\tfrac12 (\theta - \theta^*)^\top H (\theta - \theta^*))$,
which is the unnormalized density of $\mathcal{N}(\theta^*, H^{-1})$. The approximation
is exact when $g$ is itself quadratic, i.e. for a Gaussian prior with a Gaussian
likelihood.

</details>

**Exercise 2.** A scalar parameter $\theta$ has prior $\mathcal{N}(0, 1/\lambda_0)$ and a
Gaussian likelihood $y_n = \theta + \varepsilon_n$ with $\varepsilon_n \sim \mathcal{N}(0, 1/\tau)$
over $N$ observations. Compute the Laplace precision (Hessian of the negative
log-posterior) and explain why Laplace is exact here.

<details>
<summary>Solution</summary>

**Step 1.** The negative log-posterior, up to a constant, is
$\tfrac12 \lambda_0 \theta^2 + \tfrac12 \tau \sum_n (y_n - \theta)^2$.

**Step 2.** Differentiate twice with respect to $\theta$. The first derivative is
$\lambda_0 \theta - \tau \sum_n (y_n - \theta)$; the second derivative is

$$
H = \lambda_0 + N\tau,
$$

a constant independent of $\theta$. The Laplace covariance is $1/H = 1/(\lambda_0 + N\tau)$.

**Step 3.** Because the Hessian is constant, the negative log-posterior is exactly
quadratic, so the second-order Taylor expansion has no truncation error and the Gaussian
fit is the true posterior. More data ($N$ larger) raises the precision linearly and
shrinks the posterior variance, the limited-sample effect the lesson describes.

</details>

**Exercise 3 (code).** For the conjugate Gaussian model of Exercise 2, find the MAP by
gradient descent, form the Laplace covariance from the Hessian, and verify both match the
analytic conjugate posterior mean and variance.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(11)
lam0, tau, N = 1.0, 2.0, 50
theta_true = 1.5
y = theta_true + rng.normal(0, 1 / np.sqrt(tau), N)

# Analytic conjugate posterior
post_prec = lam0 + N * tau
post_mean = tau * y.sum() / post_prec
post_var  = 1.0 / post_prec

# MAP by gradient descent on the negative log-posterior
theta, lr = 0.0, 1e-3
for _ in range(2000):
    grad = lam0 * theta - tau * (y - theta).sum()
    theta -= lr * grad

# Laplace covariance from the (constant) Hessian
H = lam0 + N * tau
laplace_var = 1.0 / H

assert np.isclose(theta, post_mean, atol=1e-3)
assert np.isclose(laplace_var, post_var)
print("MAP:", round(theta, 4), " posterior mean:", round(post_mean, 4))
print("Laplace var:", round(laplace_var, 6), " posterior var:", round(post_var, 6))
```

The MAP equals the conjugate posterior mean and the Laplace variance equals the posterior
variance to machine precision, confirming that Laplace is exact when the log-posterior is
quadratic.

</details>
