Standard PCA is a deterministic procedure.
**Probabilistic PCA** (PPCA) places PCA inside a latent variable model, giving it a
likelihood function, a clear noise model, and an EM algorithm for fitting.
The MLE recovers the principal components exactly; the probabilistic framing enables
Bayesian extensions and handles missing data naturally.

## The PPCA model

PPCA posits that each observation $x \in \mathbb{R}^D$ is generated by a latent code
$z \in \mathbb{R}^q$ ($q \ll D$) through:

$$
z \sim \mathcal{N}(0, I_q), \qquad x \mid z \sim \mathcal{N}(Wz + \mu, \sigma^2 I_D),
$$

where $W \in \mathbb{R}^{D \times q}$ is the **loading matrix** and $\mu$ is the mean.

The marginal distribution of $x$ is Gaussian:

$$
x \sim \mathcal{N}(\mu,\, WW^\top + \sigma^2 I_D).
$$

## Maximum likelihood solution

The MLE of $W$ has a closed form.
Let $S = \frac{1}{N}\sum_n (x_n - \bar{x})(x_n - \bar{x})^\top$ be the sample covariance.
Let $U_q \Lambda_q U_q^\top$ be its top-$q$ eigendecomposition.

The MLE of $W$ is:

$$
W_\text{MLE} = U_q (\Lambda_q - \sigma^2 I_q)^{1/2} R,
$$

where $R$ is any $q \times q$ orthogonal matrix (rotation ambiguity).
In the limit $\sigma^2 \to 0$, the columns of $W_\text{MLE}$ span the same subspace
as the top $q$ principal components of $S$.

The MLE of $\sigma^2$ is the mean residual variance:

$$
\sigma^2_\text{MLE} = \frac{1}{D - q} \sum_{j=q+1}^{D} \lambda_j,
$$

where $\lambda_{q+1}, \ldots, \lambda_D$ are the discarded eigenvalues.

## EM algorithm for PPCA

**E-step.** Compute posterior statistics:

$$
\langle z_n \rangle = M^{-1} W^\top (x_n - \mu), \qquad M = W^\top W + \sigma^2 I_q,
$$

$$
\langle z_n z_n^\top \rangle = \sigma^2 M^{-1} + \langle z_n \rangle \langle z_n \rangle^\top.
$$

**M-step.** Update parameters:

$$
W_\text{new} = \left(\sum_n (x_n - \mu) \langle z_n \rangle^\top\right)
\left(\sum_n \langle z_n z_n^\top \rangle\right)^{-1},
$$

$$
\sigma^2_\text{new} = \frac{1}{ND} \sum_n \!\left(\|x_n - \mu\|^2
- 2 \langle z_n \rangle^\top W_\text{new}^\top (x_n - \mu)
+ \mathrm{tr}(\langle z_n z_n^\top \rangle W_\text{new}^\top W_\text{new})\right).
$$

## Factor analysis

**Factor analysis** (FA) is PPCA with a diagonal but non-isotropic noise covariance:

$$
x \mid z \sim \mathcal{N}(Wz + \mu,\, \Psi),
$$

where $\Psi = \text{diag}(\psi_1, \ldots, \psi_D)$.
Each observed dimension has its own noise level, making FA suitable when features are
on different scales. The EM updates have the same structure as PPCA with $\Psi$
replacing $\sigma^2 I$.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(39)

# Generate PPCA data
D, q, N = 4, 2, 200
W_true  = rng.normal(0, 1, (D, q))
sigma2_true = 0.5
z_latent = rng.normal(0, 1, (N, q))
x_data   = z_latent @ W_true.T + rng.normal(0, np.sqrt(sigma2_true), (N, D))

# PPCA via closed-form MLE
x_mean = x_data.mean(axis=0)
x_c    = x_data - x_mean
S      = x_c.T @ x_c / N
eigvals, eigvecs = np.linalg.eigh(S)
idx    = np.argsort(eigvals)[::-1]
eigvals, eigvecs = eigvals[idx], eigvecs[:, idx]

sigma2_mle = eigvals[q:].mean()
W_mle      = eigvecs[:, :q] @ np.diag(np.sqrt(np.maximum(eigvals[:q] - sigma2_mle, 0)))

# PPCA EM
W = rng.normal(0, 0.1, (D, q))
sigma2 = 1.0
for it in range(100):
    M = W.T @ W + sigma2 * np.eye(q)
    M_inv = np.linalg.inv(M)
    Ez  = x_c @ W @ M_inv.T                   # (N, q)
    Ezz = sigma2 * M_inv + np.einsum("ni,nj->ij", Ez, Ez) / N  # (q, q)
    W_new = x_c.T @ Ez @ np.linalg.inv(N * Ezz)
    term1 = np.sum(x_c**2) / N
    term2 = -2 * np.trace(Ez.T @ x_c @ W_new) / N
    term3 = np.trace(Ezz @ W_new.T @ W_new)
    sigma2_new = (term1 + term2 + term3) / D
    W, sigma2 = W_new, sigma2_new

# Compare subspaces: canonical angles
U_mle, _ = np.linalg.qr(W_mle)
U_em,  _ = np.linalg.qr(W)
cos_angles = np.linalg.svd(U_mle.T @ U_em, compute_uv=False)
print(f"Canonical cosines (MLE vs EM subspace): {cos_angles.round(4)}")
print(f"Sigma2 MLE: {sigma2_mle:.4f}, EM: {sigma2:.4f}, True: {sigma2_true}")
```

Both MLE and EM recover the same two-dimensional subspace (canonical cosines near 1),
and both correctly estimate the noise variance.
