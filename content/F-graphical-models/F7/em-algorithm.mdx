Many models contain latent variables $\mathbf{Z}$ that explain the observations $\mathbf{X}$
but are never directly observed.
The **EM algorithm** maximizes the marginal log-likelihood $\log P(\mathbf{X} \mid \theta)$
by alternating between computing the posterior over latents and updating parameters to
maximize the expected complete-data log-likelihood<FN ns="1, 2" />.

## Derivation from the ELBO

For any distribution $q(\mathbf{Z})$, the ELBO (from the VI lesson) gives:

$$
\log P(\mathbf{X} \mid \theta) \ge \mathbb{E}_q[\log P(\mathbf{X}, \mathbf{Z} \mid \theta)] - \mathbb{E}_q[\log q(\mathbf{Z})].
$$

Equality holds when $q(\mathbf{Z}) = P(\mathbf{Z} \mid \mathbf{X}, \theta)$ (the true posterior),
at which point the KL divergence is zero.

**E-step.** Fix $\theta$. Set $q(\mathbf{Z}) = P(\mathbf{Z} \mid \mathbf{X}, \theta)$.
This maximizes the ELBO with respect to $q$ and makes it tight.

Compute:
$$
Q(\theta, \theta_\text{old}) = \mathbb{E}_{P(\mathbf{Z} \mid \mathbf{X}, \theta_\text{old})}[\log P(\mathbf{X}, \mathbf{Z} \mid \theta)].
$$

**M-step.** Fix $q$. Maximize the ELBO with respect to $\theta$:
$$
\theta_\text{new} = \arg\max_\theta Q(\theta, \theta_\text{old}).
$$

## Monotone increase property

At each EM iteration:

$$
\log P(\mathbf{X} \mid \theta_\text{new}) \ge \log P(\mathbf{X} \mid \theta_\text{old}).
$$

**Proof.** After the E-step at $\theta_\text{old}$, the ELBO equals $\log P(\mathbf{X} \mid \theta_\text{old})$.
The M-step can only increase the ELBO (since it maximizes over $\theta$).
Because the ELBO is a lower bound on $\log P(\mathbf{X} \mid \theta_\text{new})$,
the marginal likelihood is at least as large after the update.

## Gaussian mixture model EM

For a $K$-component GMM with parameters $\theta = \{\pi_k, \mu_k, \Sigma_k\}_{k=1}^K$<FN n="2" />:

**E-step.** Compute soft assignments (responsibilities):

$$
r_{nk} = P(Z_n = k \mid x_n, \theta) = \frac{\pi_k \mathcal{N}(x_n; \mu_k, \Sigma_k)}{\sum_j \pi_j \mathcal{N}(x_n; \mu_j, \Sigma_j)}.
$$

The word "soft" earns its place only when the responsibilities are between $0$ and $1$,
which depends on where the point sits. Take the three components used in the code below
($\pi = (0.3, 0.5, 0.2)$, means $-2, 1, 4$, standard deviations $0.7, 0.9, 0.5$) and read
off $r_n$ for a few positions:

- **On a center**, $x = -2$: $r = (0.995,\, 0.005,\, 0)$. The point is claimed almost
  entirely by component 1; the assignment is effectively hard.
- **On another center**, $x = 1$: $r = (0,\, 1.0,\, 0)$, hard again.
- **Between two centers**, $x = -0.5$: $r = (0.237,\, 0.763,\, 0)$. Now the assignment
  is genuinely soft, split between the two flanking components in proportion to how well
  each explains the point.
- **Between the far pair**, $x = 2.5$: $r = (0,\, 0.969,\, 0.031)$, mostly component 2
  with a sliver of component 3.

This is the contrast hard $k$-means cannot make: a point near a mode is assigned with
near-certainty, but a point in the overlap region contributes fractionally to several
components, and those fractions are what weight the M-step averages below.

**M-step.** Compute effective counts $N_k = \sum_n r_{nk}$ and update:

$$
\pi_k^{\text{new}} = \frac{N_k}{N}, \qquad
\mu_k^{\text{new}} = \frac{\sum_n r_{nk} x_n}{N_k}, \qquad
\Sigma_k^{\text{new}} = \frac{\sum_n r_{nk} (x_n - \mu_k^{\text{new}})(x_n - \mu_k^{\text{new}})^\top}{N_k}.
$$

## Implementation

```python
import numpy as np

rng = np.random.default_rng(35)

def norm_pdf(x, mu=0.0, sigma=1.0):
    return np.exp(-0.5 * ((x - mu) / sigma)**2) / (sigma * np.sqrt(2 * np.pi))

# Generate GMM data
K = 3
N = 300
true_pi  = np.array([0.3, 0.5, 0.2])
true_mu  = np.array([[-2.0], [1.0], [4.0]])
true_sig = np.array([0.7, 0.9, 0.5])
z_true = rng.choice(K, N, p=true_pi)
x = rng.normal(true_mu[z_true, 0], true_sig[z_true]).reshape(-1, 1)

# EM initialization
pi  = np.ones(K) / K
mu  = rng.uniform(x.min(), x.max(), (K, 1))
sig = np.ones(K)

def log_likelihood(x, pi, mu, sig):
    liks = np.array([pi[k] * norm_pdf(x[:, 0], mu[k, 0], sig[k]) for k in range(K)])
    return np.log(liks.sum(axis=0)).sum()

for iteration in range(100):
    # E-step
    r = np.zeros((N, K))
    for k in range(K):
        r[:, k] = pi[k] * norm_pdf(x[:, 0], mu[k, 0], sig[k])
    r /= r.sum(axis=1, keepdims=True)

    # M-step
    Nk = r.sum(axis=0)
    pi = Nk / N
    for k in range(K):
        mu[k]  = (r[:, k:k+1] * x).sum(axis=0) / Nk[k]
        diff   = x - mu[k]
        sig[k] = np.sqrt((r[:, k] * diff[:, 0]**2).sum() / Nk[k])

    if (iteration + 1) % 20 == 0:
        ll = log_likelihood(x, pi, mu, sig)
        print(f"Iter {iteration+1:3d}  log-lik = {ll:.2f}")

sort_idx = np.argsort(mu[:, 0])
print(f"\nFitted means:  {mu[sort_idx, 0].round(3)}")
print(f"True means:    {np.sort(true_mu[:, 0]).round(3)}")
```

The log-likelihood increases monotonically across iterations, confirming the theoretical
guarantee.

## Exercises

**Exercise 1.** A two-component GMM has equal weights $\pi = (0.5, 0.5)$, means
$\mu = (0, 2)$, and unit variances $\sigma_1 = \sigma_2 = 1$. Compute the E-step
responsibilities $r_{n1}, r_{n2}$ for the point $x_n = 1.5$ by hand.

<details>
<summary>Solution</summary>

**Step 1.** The responsibility is the posterior $r_{nk} \propto \pi_k \mathcal{N}(x_n; \mu_k, \sigma_k^2)$.
With equal weights and equal variances the $\pi_k$ and the normalizing constant
$1/(\sigma\sqrt{2\pi})$ cancel in the ratio, leaving only the exponentials.

**Step 2.** Evaluate the squared distances at $x_n = 1.5$:
$(1.5 - 0)^2 = 2.25$ and $(1.5 - 2)^2 = 0.25$. The unnormalized weights are
$e^{-2.25/2}$ and $e^{-0.25/2}$, so

$$
r_{n2} = \frac{e^{-0.125}}{e^{-1.125} + e^{-0.125}}
       = \frac{1}{1 + e^{-1.125 + 0.125}}
       = \frac{1}{1 + e^{-1}} = 0.7311.
$$

**Step 3.** The other responsibility is the complement, $r_{n1} = 1 - 0.7311 = 0.2689$.

The point sits closer to the second mean, so it is claimed mostly (but not entirely)
by component 2. With two equal-variance Gaussians the responsibility reduces to a
logistic of the squared-distance gap, which is why the answer is $\sigma(1)$.

</details>

**Exercise 2.** Derive the M-step update for a component mean $\mu_k$ by maximizing
the expected complete-data log-likelihood $Q$, holding the responsibilities fixed.

<details>
<summary>Solution</summary>

**Step 1.** With responsibilities $r_{nk}$ fixed, the part of $Q$ that depends on
$\mu_k$ comes from the Gaussian log-density $\log \mathcal{N}(x_n; \mu_k, \Sigma_k)$,
weighted by $r_{nk}$:

$$
Q(\mu_k) = -\frac{1}{2} \sum_n r_{nk} (x_n - \mu_k)^\top \Sigma_k^{-1} (x_n - \mu_k) + \text{const}.
$$

**Step 2.** Differentiate with respect to $\mu_k$ and set to zero. The gradient of
the quadratic is $\Sigma_k^{-1}(x_n - \mu_k)$, so

$$
\nabla_{\mu_k} Q = \sum_n r_{nk}\, \Sigma_k^{-1} (x_n - \mu_k) = 0.
$$

**Step 3.** $\Sigma_k^{-1}$ is invertible, so the bracket must vanish:
$\sum_n r_{nk}(x_n - \mu_k) = 0$. Solving for $\mu_k$ gives the responsibility-weighted
mean,

$$
\mu_k^{\text{new}} = \frac{\sum_n r_{nk} x_n}{\sum_n r_{nk}} = \frac{\sum_n r_{nk} x_n}{N_k},
$$

with effective count $N_k = \sum_n r_{nk}$. This is the soft analogue of the $k$-means
centroid update: a hard assignment ($r_{nk} \in \{0, 1\}$) recovers the ordinary mean
of each cluster.

</details>

**Exercise 3 (code).** Run EM on a two-component 1D mixture and verify numerically
that the data log-likelihood is non-decreasing at every iteration (the monotone
increase property), within floating-point tolerance.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)

def norm_pdf(x, mu, sigma):
    return np.exp(-0.5 * ((x - mu) / sigma)**2) / (sigma * np.sqrt(2 * np.pi))

K, N = 2, 200
x = np.concatenate([rng.normal(-2, 1, N // 2), rng.normal(2, 1, N // 2)])

pi  = np.ones(K) / K
mu  = np.array([-0.5, 0.5])
sig = np.ones(K)

def log_lik(x, pi, mu, sig):
    L = np.array([pi[k] * norm_pdf(x, mu[k], sig[k]) for k in range(K)])
    return np.log(L.sum(axis=0)).sum()

lls = []
for _ in range(50):
    r = np.array([pi[k] * norm_pdf(x, mu[k], sig[k]) for k in range(K)]).T
    r /= r.sum(axis=1, keepdims=True)             # E-step
    Nk = r.sum(axis=0)                            # M-step
    pi = Nk / N
    for k in range(K):
        mu[k]  = (r[:, k] * x).sum() / Nk[k]
        sig[k] = np.sqrt((r[:, k] * (x - mu[k])**2).sum() / Nk[k])
    lls.append(log_lik(x, pi, mu, sig))

lls = np.array(lls)
assert np.all(np.diff(lls) >= -1e-9)              # never decreases
print("log-lik first three:", lls[:3].round(3))
print("log-lik final:      ", round(lls[-1], 3))
```

The differences between consecutive log-likelihoods are all nonnegative, matching
the proof: the E-step makes the ELBO tight, and the M-step can only raise it.

</details>
