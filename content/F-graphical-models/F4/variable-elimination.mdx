Given a joint distribution expressed as a product of factors, computing the marginal
of a single variable requires summing out all others.
Naively, this sum is exponential in the number of variables.
**Variable elimination** (VE) performs that sum in the most efficient order:
eliminate one variable at a time, each time fusing only the factors that mention it<FN n="1" />.

## The elimination operation

Let the joint factor over variables $\{X_1, \ldots, X_n\}$ be:

$$
P(\mathbf{X}) \propto \prod_j f_j(\mathbf{X}_j).
$$

To marginalize out $X_i$, collect all factors that mention $X_i$, multiply them,
and sum over $X_i$:

$$
\tau(\mathbf{X}_j \setminus \{X_i\}) = \sum_{x_i} \prod_{j : X_i \in \mathbf{X}_j} f_j(\mathbf{X}_j).
$$

Replace the collected factors with the new intermediate factor $\tau$.
The remaining product no longer involves $X_i$.

## Complexity and elimination order

The cost of eliminating $X_i$ is proportional to $k^{|S_i|}$, where $k$ is the
variable cardinality and $S_i$ is the set of variables in $\tau$
(all variables that appear in any factor containing $X_i$, minus $X_i$ itself).

Different elimination orders produce different sets $S_i$.
The optimal order minimizes the maximum $|S_i|$, and that maximum minus one is the
**induced width** (an upper bound on the treewidth of the graph)<FN n="2" />.

On a tree-structured graph, the optimal width is 1: each elimination fuses at most
two variables, giving $O(n k^2)$ total cost.
On a grid graph, the width grows as $O(\sqrt{n})$ and exact inference becomes
exponential in $\sqrt{n}$.

## Worked example: a three-variable chain

Graph: $X_1 - X_2 - X_3$, factors $f_{12}(X_1, X_2)$ and $f_{23}(X_2, X_3)$.
Goal: compute $P(X_3)$.

**Step 1.** Eliminate $X_1$: only $f_{12}$ mentions $X_1$.
$$
\tau_2(X_2) = \sum_{x_1} f_{12}(x_1, X_2).
$$

**Step 2.** Eliminate $X_2$: remaining factors are $\tau_2(X_2)$ and $f_{23}(X_2, X_3)$.
$$
\tau_3(X_3) = \sum_{x_2} \tau_2(x_2) \cdot f_{23}(x_2, X_3).
$$

**Result:** $P(X_3) \propto \tau_3(X_3)$, normalized.

Both steps each require $O(k^2)$ operations; the full sum-out is $O(n k^2)$ on the chain.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(4)
k = 3   # states per variable

# Four-variable chain: X1 - X2 - X3 - X4
# Factors f12, f23, f34
f12 = np.abs(rng.normal(1, 0.5, (k, k)))
f23 = np.abs(rng.normal(1, 0.5, (k, k)))
f34 = np.abs(rng.normal(1, 0.5, (k, k)))

def variable_elimination_chain(factors):
    """Eliminate all but the last variable in a chain of pairwise factors."""
    # Marginalize out the first variable: sum over its rows
    result = factors[0].sum(axis=0)   # (k,k) -> (k,): sum over X1
    for f in factors[1:]:
        # result[x_prev] * f[x_prev, x_next], summed over x_prev
        result = result @ f   # (k,) @ (k,k) -> (k,)
    return result

# Compute P(X4) by eliminating X1, X2, X3
p_x4 = variable_elimination_chain([f12, f23, f34])
p_x4 /= p_x4.sum()
print("P(X4) via VE:", p_x4.round(4))

# Verify by brute force: compute full joint and marginalize
joint = np.einsum("ij,jk,kl->ijkl", f12, f23, f34)
joint /= joint.sum()
p_x4_brute = joint.sum(axis=(0, 1, 2))
print("P(X4) brute force:", p_x4_brute.round(4))

# Complexity demonstration: cost grows with state space
for k_test in [2, 4, 8, 16]:
    f = np.ones((k_test, k_test))
    ops = k_test**2 * 3   # 3 eliminations each O(k^2)
    print(f"k={k_test:2d}: ~{ops} ops for chain of 4")
```

Variable elimination is exact on any graph but becomes exponential in the treewidth.

## Exercises

**Exercise 1.** A three-variable chain $X_1 - X_2 - X_3$ over binary states has factors
$f_{12} = \begin{pmatrix} 1 & 2 \\ 3 & 1 \end{pmatrix}$ (rows $x_1$, columns $x_2$) and
$f_{23} = \begin{pmatrix} 2 & 1 \\ 1 & 4 \end{pmatrix}$ (rows $x_2$, columns $x_3$).
Eliminate $X_1$ then $X_2$ by hand to compute the unnormalized $\tau_3(X_3)$, then
normalize to get $P(X_3)$.

<details>
<summary>Solution</summary>

**Step 1.** Eliminate $X_1$. Only $f_{12}$ mentions $X_1$, so
$\tau_2(X_2) = \sum_{x_1} f_{12}(x_1, X_2)$ sums the columns:

$$
\tau_2(X_2 = 1) = 1 + 3 = 4, \qquad \tau_2(X_2 = 2) = 2 + 1 = 3.
$$

So $\tau_2 = (4, 3)$.

**Step 2.** Eliminate $X_2$:
$\tau_3(X_3) = \sum_{x_2} \tau_2(x_2)\, f_{23}(x_2, X_3)$.

$$
\tau_3(X_3 = 1) = 4 \cdot 2 + 3 \cdot 1 = 11, \qquad
\tau_3(X_3 = 2) = 4 \cdot 1 + 3 \cdot 4 = 16.
$$

So $\tau_3 = (11, 16)$.

**Step 3.** Normalize: the sum is $11 + 16 = 27$, so

$$
P(X_3) = \left(\tfrac{11}{27}, \tfrac{16}{27}\right) \approx (0.4074, 0.5926).
$$

</details>

**Exercise 2.** Two elimination orders on the same graph can have very different costs.
Take a "star" factor graph: a center variable $C$ tied to four leaves
$L_1, \ldots, L_4$ by pairwise factors $f(C, L_i)$, all variables of cardinality $k$.
Compare eliminating $C$ first versus eliminating the leaves first, and give the induced
width of each order.

<details>
<summary>Solution</summary>

**Step 1.** Eliminate $C$ first. Every factor mentions $C$, so summing out $C$ fuses all
four leaves into one factor over $\{L_1, L_2, L_3, L_4\}$. The intermediate factor has
four variables, so $|S_C| = 4$ and the step costs $k^{5}$ (the four leaves plus $C$ in
the sum). The induced width is $|S_C| = 4$.

**Step 2.** Eliminate the leaves first. Each leaf $L_i$ appears in only one factor
$f(C, L_i)$, so $\sum_{L_i} f(C, L_i)$ produces a factor over the single variable $C$.
Each such step touches $\{C, L_i\}$, so $|S_{L_i}| = 1$ and costs $k^2$. After all four
leaves are gone, $C$ stands alone. The maximum intermediate set has size 1, so the
induced width is 1.

**Step 3.** The leaf-first order has induced width 1 versus 4 for center-first, a cost
of $O(k^2)$ per step instead of $O(k^5)$. Eliminating low-degree variables before
high-degree hubs is the intuition behind the minimum-degree heuristic.

</details>

**Exercise 3 (code).** Implement variable elimination on the chain of Exercise 1 and
confirm $\tau_3 = (11, 16)$ before normalization and $P(X_3) \approx (0.4074, 0.5926)$
after. Cross-check against a brute-force marginal of the full joint.

<details>
<summary>Solution</summary>

```python
import numpy as np

f12 = np.array([[1.0, 2.0],
                [3.0, 1.0]])   # [x1, x2]
f23 = np.array([[2.0, 1.0],
                [1.0, 4.0]])   # [x2, x3]

# Eliminate X1 (sum over rows), then X2
tau2 = f12.sum(axis=0)         # sum over x1 -> over x2: (4, 3)
tau3 = tau2 @ f23              # sum over x2 -> over x3: (11, 16)
assert np.allclose(tau3, [11.0, 16.0])

p_x3 = tau3 / tau3.sum()
assert np.allclose(p_x3, [11/27, 16/27])

# Brute force: full joint over (x1, x2, x3), then marginalize
joint = np.einsum("ij,jk->ijk", f12, f23)
joint /= joint.sum()
p_x3_brute = joint.sum(axis=(0, 1))
assert np.allclose(p_x3, p_x3_brute)
print("P(X3) via VE:   ", p_x3.round(4))
print("P(X3) brute:    ", p_x3_brute.round(4))
```

The eliminated factor matches the hand computation and the brute-force marginal,
confirming variable elimination is exact.
