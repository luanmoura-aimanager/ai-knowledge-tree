Speech recognition, genomics, and financial regime detection all share a structure:
an underlying latent process evolves over time, and we observe noisy emissions.
The **Hidden Markov Model** (HMM) is the simplest formal treatment of this situation<FN n="1" />.

## HMM structure

An HMM has three components:

- **Transition matrix** $A \in \mathbb{R}^{K \times K}$: $A_{ij} = P(Z_t = j \mid Z_{t-1} = i)$.
- **Emission distribution** $P(X_t \mid Z_t = k)$ for each state $k$.
- **Initial state distribution** $\pi_k = P(Z_1 = k)$.

The joint distribution over a sequence of length $T$ is:

$$
P(Z_{1:T}, X_{1:T}) = P(Z_1) \prod_{t=2}^{T} P(Z_t \mid Z_{t-1}) \prod_{t=1}^{T} P(X_t \mid Z_t).
$$

## The forward algorithm

The **forward variable** $\alpha_t(k) = P(X_{1:t}, Z_t = k)$ collects all evidence
up to time $t$ along with state $k$ at time $t$.

**Initialization:** $\alpha_1(k) = \pi_k \cdot P(X_1 \mid Z_1 = k)$.

**Recursion (Step 1 through $T-1$):**

$$
\alpha_{t+1}(j) = P(X_{t+1} \mid Z_{t+1} = j) \sum_{k=1}^{K} \alpha_t(k) A_{kj}.
$$

**Marginal likelihood:** $P(X_{1:T}) = \sum_k \alpha_T(k)$.

## The backward algorithm

The **backward variable** $\beta_t(k) = P(X_{t+1:T} \mid Z_t = k)$ collects all
future evidence.

**Initialization:** $\beta_T(k) = 1$ for all $k$.

**Recursion (from $T-1$ down to 1):**

$$
\beta_t(k) = \sum_{j=1}^{K} A_{kj} \cdot P(X_{t+1} \mid Z_{t+1} = j) \cdot \beta_{t+1}(j).
$$

**State marginal:**

$$
P(Z_t = k \mid X_{1:T}) = \frac{\alpha_t(k) \cdot \beta_t(k)}{P(X_{1:T})}.
$$

The joint two-step marginal needed for the Baum-Welch parameter update is:

$$
P(Z_{t-1} = i, Z_t = j \mid X_{1:T})
= \frac{\alpha_{t-1}(i) \cdot A_{ij} \cdot P(X_t \mid Z_t = j) \cdot \beta_t(j)}{P(X_{1:T})}.
$$

## Viterbi decoding

The Viterbi algorithm finds the single most probable state sequence<FN n="2" />:

$$
Z^*_{1:T} = \arg\max_{Z_{1:T}} P(Z_{1:T} \mid X_{1:T}).
$$

Replace $\sum$ with $\max$ in the forward recursion and store the argmax for backtracking:

$$
\delta_t(j) = \max_k \bigl[\delta_{t-1}(k) \cdot A_{kj}\bigr] \cdot P(X_t \mid Z_t = j),
\qquad
\psi_t(j) = \arg\max_k \bigl[\delta_{t-1}(k) \cdot A_{kj}\bigr].
$$

Backtrack from $\arg\max_k \delta_T(k)$ using $\psi$.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(2)

K = 2    # hidden states
T = 20   # sequence length

# Random but valid HMM parameters
def row_normalize(M):
    return M / M.sum(axis=1, keepdims=True)

pi = np.array([0.6, 0.4])
A  = row_normalize(np.abs(rng.normal(1, 0.5, (K, K))))
# Emission: Gaussian with different means per state
means  = np.array([0.0, 3.0])
sigmas = np.array([1.0, 1.0])

# Sample a sequence
z_true = np.empty(T, dtype=int)
z_true[0] = rng.choice(K, p=pi)
for t in range(1, T):
    z_true[t] = rng.choice(K, p=A[z_true[t-1]])
x = rng.normal(means[z_true], sigmas[z_true])

def log_emit(obs, k):
    return -0.5 * ((obs - means[k]) / sigmas[k])**2 - np.log(sigmas[k])

# Forward pass (log-space for numerical stability)
log_alpha = np.zeros((T, K))
log_alpha[0] = np.log(pi) + np.array([log_emit(x[0], k) for k in range(K)])
for t in range(1, T):
    for j in range(K):
        log_alpha[t, j] = (np.logaddexp.reduce(log_alpha[t-1] + np.log(A[:, j]))
                           + log_emit(x[t], j))

log_px = np.logaddexp(log_alpha[T-1, 0], log_alpha[T-1, 1])

# Backward pass
log_beta = np.zeros((T, K))
for t in range(T-2, -1, -1):
    for i in range(K):
        log_beta[t, i] = np.logaddexp.reduce(
            np.log(A[i]) + np.array([log_emit(x[t+1], j) for j in range(K)])
            + log_beta[t+1]
        )

gamma = np.exp(log_alpha + log_beta - log_px)  # P(Z_t | X)

# Viterbi
log_delta = log_alpha[0].copy()
psi = np.zeros((T, K), dtype=int)
for t in range(1, T):
    log_delta_new = np.zeros(K)
    for j in range(K):
        scores = log_delta + np.log(A[:, j])
        psi[t, j] = np.argmax(scores)
        log_delta_new[j] = np.max(scores) + log_emit(x[t], j)
    log_delta = log_delta_new

z_viterbi = np.empty(T, dtype=int)
z_viterbi[T-1] = np.argmax(log_delta)
for t in range(T-2, -1, -1):
    z_viterbi[t] = psi[t+1, z_viterbi[t+1]]

acc = (z_viterbi == z_true).mean()
print(f"Viterbi accuracy: {acc:.2f}")
print(f"True states:    {z_true}")
print(f"Viterbi states: {z_viterbi}")
```

Viterbi is often more interpretable than the marginal posteriors: it gives a single consistent sequence rather than per-step mode estimates, which can be inconsistent across time steps.

## Exercises

**Exercise 1.** A two-state HMM has $\pi = (0.6, 0.4)$, transition
$A = \begin{pmatrix} 0.7 & 0.3 \\ 0.4 & 0.6 \end{pmatrix}$, and discrete emissions
with $P(X = a \mid Z = 1) = 0.9$, $P(X = a \mid Z = 2) = 0.2$. The first observation
is $X_1 = a$. Compute the forward variables $\alpha_1(1)$ and $\alpha_1(2)$ by hand,
then run one recursion step to get $\alpha_2(1)$ and $\alpha_2(2)$ assuming
$X_2 = a$ as well.

<details>
<summary>Solution</summary>

**Step 1.** Initialization is $\alpha_1(k) = \pi_k \cdot P(X_1 = a \mid Z_1 = k)$:

$$
\alpha_1(1) = 0.6 \cdot 0.9 = 0.54, \qquad \alpha_1(2) = 0.4 \cdot 0.2 = 0.08.
$$

**Step 2.** The recursion is $\alpha_2(j) = P(X_2 = a \mid Z_2 = j) \sum_k \alpha_1(k) A_{kj}$.
First the inner sums, with $A_{kj}$ read column-wise:

$$
\sum_k \alpha_1(k) A_{k1} = 0.54 \cdot 0.7 + 0.08 \cdot 0.4 = 0.378 + 0.032 = 0.410,
$$
$$
\sum_k \alpha_1(k) A_{k2} = 0.54 \cdot 0.3 + 0.08 \cdot 0.6 = 0.162 + 0.048 = 0.210.
$$

**Step 3.** Multiply by the emission for $X_2 = a$:

$$
\alpha_2(1) = 0.9 \cdot 0.410 = 0.369, \qquad \alpha_2(2) = 0.2 \cdot 0.210 = 0.042.
$$

The marginal likelihood of the two-symbol prefix is $P(X_{1:2}) = 0.369 + 0.042 = 0.411$.

</details>

**Exercise 2.** Show that the state marginal formula is consistent: prove that
$\sum_k \alpha_t(k) \beta_t(k) = P(X_{1:T})$ for every fixed $t$, so dividing by
$P(X_{1:T})$ in $P(Z_t = k \mid X_{1:T}) = \alpha_t(k)\beta_t(k) / P(X_{1:T})$ yields a
normalized distribution over $k$.

<details>
<summary>Solution</summary>

**Step 1.** Use the definitions. The forward variable is the joint
$\alpha_t(k) = P(X_{1:t}, Z_t = k)$ and the backward variable is the conditional
$\beta_t(k) = P(X_{t+1:T} \mid Z_t = k)$. Their product is

$$
\alpha_t(k)\beta_t(k) = P(X_{1:t}, Z_t = k) \cdot P(X_{t+1:T} \mid Z_t = k).
$$

**Step 2.** By the Markov property, conditional on $Z_t = k$ the past evidence
$X_{1:t}$ and future evidence $X_{t+1:T}$ are independent, so the product is the joint
$P(X_{1:T}, Z_t = k)$.

**Step 3.** Sum over the states $k$ to marginalize out $Z_t$:

$$
\sum_k \alpha_t(k)\beta_t(k) = \sum_k P(X_{1:T}, Z_t = k) = P(X_{1:T}).
$$

This holds for every $t$, which is why $P(X_{1:T})$ can be recovered from $\alpha_T$
alone (with $\beta_T \equiv 1$) or from any intermediate column.

</details>

**Exercise 3 (code).** Implement the forward algorithm in linear (not log) space for
the discrete HMM of Exercise 1 with the observation sequence $(a, a, b)$, where
$P(X = b \mid Z = k) = 1 - P(X = a \mid Z = k)$. Verify that $\alpha_2$ matches the
hand computation and that the total likelihood $\sum_k \alpha_3(k)$ equals the sum
over all $K^3$ state paths computed by brute force.

<details>
<summary>Solution</summary>

```python
import numpy as np

pi = np.array([0.6, 0.4])
A  = np.array([[0.7, 0.3],
               [0.4, 0.6]])
# emission[k, symbol]: symbol 0 = 'a', symbol 1 = 'b'
emit = np.array([[0.9, 0.1],
                 [0.2, 0.8]])
obs = [0, 0, 1]   # a, a, b
K = 2

# Forward recursion in linear space
alpha = np.zeros((len(obs), K))
alpha[0] = pi * emit[:, obs[0]]
for t in range(1, len(obs)):
    for j in range(K):
        alpha[t, j] = emit[j, obs[t]] * (alpha[t-1] @ A[:, j])

assert np.allclose(alpha[1], [0.369, 0.042])   # matches Exercise 1
fwd_likelihood = alpha[-1].sum()

# Brute force: sum over all K**3 state paths
from itertools import product
brute = 0.0
for path in product(range(K), repeat=len(obs)):
    p = pi[path[0]] * emit[path[0], obs[0]]
    for t in range(1, len(obs)):
        p *= A[path[t-1], path[t]] * emit[path[t], obs[t]]
    brute += p

assert np.isclose(fwd_likelihood, brute)
print("forward likelihood:", round(fwd_likelihood, 6))
```

The forward sum collapses the exponential path enumeration into $O(T K^2)$ work while
returning the identical likelihood.

</details>
