A product team wants to know whether a new button color increases click-through rate.
Half the users see the old design (control), half see the new design (treatment).
After collecting data, they need to decide: is the observed difference real, or
plausibly noise? This is the A/B test, the workhorse of online controlled
experimentation<FN n="1" />.

## The two-sample proportion test

Let $p_A$ and $p_B$ be the true conversion rates for control and treatment.

**Null:** $H_0: p_A = p_B$.

**Alternative:** $H_1: p_A \ne p_B$ (two-sided).

With $n_A$ and $n_B$ observations, the sample proportions are $\hat p_A = k_A / n_A$
and $\hat p_B = k_B / n_B$.

The test statistic uses the **pooled proportion** $\hat p = (k_A + k_B)/(n_A + n_B)$:

$$
Z = \frac{\hat p_B - \hat p_A}{\sqrt{\hat p(1-\hat p)(1/n_A + 1/n_B)}} \sim \mathcal{N}(0,1) \text{ under } H_0.
$$

Reject $H_0$ when $|Z| > z_{\alpha/2}$.

## Power and sample size

**Power** is the probability of detecting a true effect of size $\delta = p_B - p_A$.

Under $H_1$, the test statistic is approximately $\mathcal{N}(\delta / \mathrm{SE}, 1)$.
Power is $1 - \beta$ where $\beta$ is the Type II error rate.

Inverting for the required sample size (equal groups, $n_A = n_B = n$):

$$
n = \frac{(z_{\alpha/2} + z_\beta)^2 \left[p_A(1-p_A) + p_B(1-p_B)\right]}{\delta^2}.
$$

For $\alpha = 0.05$ ($z_{\alpha/2} = 1.96$), power $= 0.80$ ($z_\beta = 0.84$), the
factor $(z_{\alpha/2} + z_\beta)^2 \approx 7.85$.

A **minimum detectable effect** (MDE) is the smallest $\delta$ the test is powered
to detect. Choosing a smaller MDE requires a larger sample<FN n="2" />.

## Multiple comparisons in A/B testing

Running multiple A/B tests simultaneously, or testing multiple metrics, inflates
the false positive rate. Solutions:

- **Bonferroni correction** (conservative): divide $\alpha$ by the number of tests.
- **FDR control** (less conservative): use BH when many metrics are tested.
- **Pre-register primary metrics** to avoid post-hoc inflation.

## Stopping early (sequential testing)

Peeking at results during data collection and stopping when $p < 0.05$ inflates
Type I error. **Sequential tests** (covered in the CUPED lesson) allow valid early
stopping by adjusting the significance boundary.

## Implementation

```python-static
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)

p_A, p_B = 0.10, 0.12   # true rates
n = 2000                 # per group

# Simulate
k_A = rng.binomial(n, p_A)
k_B = rng.binomial(n, p_B)
p_hat_A = k_A / n
p_hat_B = k_B / n
p_pool  = (k_A + k_B) / (2 * n)
z = (p_hat_B - p_hat_A) / np.sqrt(p_pool * (1 - p_pool) * 2 / n)
p_val = 2 * (1 - stats.norm.cdf(abs(z)))
print(f"k_A={k_A}, k_B={k_B}")
print(f"z={z:.4f}, p={p_val:.4f}")

# Sample size calculation
def sample_size(p_a, delta, alpha=0.05, power=0.80):
    p_b = p_a + delta
    z_a = stats.norm.ppf(1 - alpha/2)
    z_b = stats.norm.ppf(power)
    num = (z_a + z_b)**2 * (p_a*(1-p_a) + p_b*(1-p_b))
    return int(np.ceil(num / delta**2))

for delta in [0.01, 0.02, 0.05, 0.10]:
    print(f"MDE={delta:.2f}: n_per_group = {sample_size(p_A, delta)}")
```

Detecting a 1pp lift on a 10% baseline requires tens of thousands of observations;
detecting a 10pp lift requires only a few hundred.

## Exercises

**Exercise 1.** A baseline conversion rate is $p_A = 0.10$. You want to detect a
lift to $p_B = 0.12$ at $\alpha = 0.05$ (two-sided) with power $0.80$. Use the
sample-size formula to compute the required $n$ per group by hand.

<details>
<summary>Solution</summary>

**Step 1.** Read off the critical values: $z_{\alpha/2} = z_{0.025} = 1.96$ and
$z_\beta = z_{0.20} = 0.84$, so $(z_{\alpha/2} + z_\beta)^2 = 2.80^2 = 7.84$.

**Step 2.** Compute the variance factor with $\delta = 0.02$:

$$
p_A(1-p_A) + p_B(1-p_B) = 0.10 \cdot 0.90 + 0.12 \cdot 0.88 = 0.09 + 0.1056 = 0.1956.
$$

**Step 3.** Plug into the formula:

$$
n = \frac{7.84 \cdot 0.1956}{0.02^2} = \frac{1.5335}{0.0004} \approx 3834.
$$

About $3834$ users per group, so roughly $7700$ in total. Halving the MDE to
$0.01$ would quadruple $n$, since $n \propto 1/\delta^2$.

</details>

**Exercise 2.** The pooled-variance denominator uses $\hat p(1-\hat p)(1/n_A + 1/n_B)$.
Show that for fixed total sample size $N = n_A + n_B$, the variance term
$1/n_A + 1/n_B$ is minimized by the equal split $n_A = n_B = N/2$.

<details>
<summary>Solution</summary>

**Step 1.** Write $n_B = N - n_A$ and minimize $g(n_A) = 1/n_A + 1/(N - n_A)$ over
$0 < n_A < N$.

**Step 2.** Differentiate and set to zero:

$$
g'(n_A) = -\frac{1}{n_A^2} + \frac{1}{(N - n_A)^2} = 0
\implies (N - n_A)^2 = n_A^2.
$$

**Step 3.** The positive root gives $N - n_A = n_A$, so $n_A = N/2$. The second
derivative $g''(n_A) = 2/n_A^3 + 2/(N-n_A)^3 > 0$ confirms a minimum. An equal
split gives the tightest confidence interval, which is why balanced A/B tests are
the default when both arms cost the same to serve.

</details>

**Exercise 3 (code).** The runnable environment has no `scipy`, so write a numpy
normal CDF from the Abramowitz-Stegun approximation, check it against the known
value $\Phi(1.96) \approx 0.975$, then simulate $20{,}000$ A/B tests under the null
($p_A = p_B = 0.10$, $n = 4000$) and confirm the empirical Type I error is close to
$\alpha = 0.05$.

<details>
<summary>Solution</summary>

```python
import numpy as np

def norm_cdf(x):
    x = np.asarray(x, float)
    t = 1.0 / (1.0 + 0.2316419 * np.abs(x))
    d = 0.3989422804014327 * np.exp(-x * x / 2.0)
    poly = t * (0.319381530 + t * (-0.356563782 + t * (1.781477937
              + t * (-1.821255978 + t * 1.330274429))))
    cdf = 1.0 - d * poly
    return np.where(x >= 0, cdf, 1.0 - cdf)

assert np.isclose(norm_cdf(0.0), 0.5, atol=1e-6)
assert abs(norm_cdf(1.96) - 0.975) < 1e-3

rng = np.random.default_rng(0)
n, p, n_sim, z_crit = 4000, 0.10, 20_000, 1.96
kA = rng.binomial(n, p, n_sim)
kB = rng.binomial(n, p, n_sim)
ppool = (kA + kB) / (2 * n)
se = np.sqrt(ppool * (1 - ppool) * 2 / n)
z = (kB / n - kA / n) / se
type_I = np.mean(np.abs(z) > z_crit)

assert abs(type_I - 0.05) < 0.01      # null rejection rate tracks alpha
print("empirical Type I error:", round(type_I, 4))
```

The rejection rate lands near $0.05$, confirming the test holds its nominal size
when the null is true.

</details>
