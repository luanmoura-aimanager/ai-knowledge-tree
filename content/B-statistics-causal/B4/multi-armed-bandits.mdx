In a traditional A/B test, traffic is split equally between arms throughout the
experiment: exploration and exploitation are kept separate. A **multi-armed bandit**
treats them simultaneously: each round, the algorithm observes which arms have
performed well and allocates more traffic to them, while still occasionally trying
others. The goal is to maximize cumulative reward, not just estimate arm means.

## The bandit problem

A slot machine has $K$ arms. Arm $k$ pays reward $r \sim \mathcal{D}_k$ with unknown
mean $\mu_k$. At each round $t = 1, \ldots, T$:

1. Choose arm $A_t \in \{1, \ldots, K\}$.
2. Observe reward $R_t \sim \mathcal{D}_{A_t}$.

**Regret** measures the cumulative gap to the optimal arm:

$$
\mathcal{R}_T = T\mu^* - \sum_{t=1}^T E[R_t],
$$

where $\mu^* = \max_k \mu_k$.

## UCB1

The **upper confidence bound** (UCB1; Auer et al., 2002) selects the arm with the
highest upper confidence bound on its mean<FN n="1" />:

$$
A_t = \arg\max_k \left(\hat\mu_k + \sqrt{\frac{2\ln t}{n_k}}\right),
$$

where $\hat\mu_k$ is the sample mean for arm $k$ and $n_k$ is its pull count.

**Intuition.** The bound $\sqrt{2\ln t / n_k}$ is large for rarely pulled arms
(optimism forces exploration) and small for frequently pulled arms (exploitation
wins when the evidence is strong).

**Regret bound.** UCB1 achieves:

$$
\mathcal{R}_T \le \sum_{k: \mu_k < \mu^*} \frac{8\ln T}{\Delta_k} + \left(1 + \frac{\pi^2}{3}\right)\sum_{k: \mu_k < \mu^*} \Delta_k,
$$

where $\Delta_k = \mu^* - \mu_k$. This is $O(\ln T)$, and the bound is tight: no
algorithm can achieve $o(\ln T)$ regret for all bandit instances<FN n="3" />.

## Thompson sampling

**Thompson sampling** is a Bayesian alternative. Maintain a posterior over each
arm's mean; at each round, sample one value from each posterior and pull the arm
with the highest sampled value<FN n="2" />.

For Bernoulli rewards with Beta priors:

1. Initialize $\alpha_k = \beta_k = 1$ (uniform prior) for all $k$.
2. At round $t$: sample $\tilde\mu_k \sim \mathrm{Beta}(\alpha_k, \beta_k)$ for each $k$.
3. Pull $A_t = \arg\max_k \tilde\mu_k$.
4. Observe $R_t \in \{0, 1\}$ and update: $\alpha_{A_t} \mathrel{+}= R_t$, $\beta_{A_t} \mathrel{+}= 1-R_t$.

Thompson sampling achieves the same $O(\ln T)$ regret as UCB1 and often performs
better empirically.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(0)
K = 5
mu_true = np.array([0.1, 0.3, 0.5, 0.4, 0.2])  # arm means
T = 2000

def run_ucb1(T, mu, rng):
    K = len(mu)
    n  = np.zeros(K)
    mu_hat = np.zeros(K)
    rewards = []
    # Pull each arm once
    for k in range(K):
        r = (rng.random() < mu[k])
        n[k] += 1; mu_hat[k] = r
        rewards.append(r)
    for t in range(K, T):
        ucb = mu_hat + np.sqrt(2 * np.log(t + 1) / (n + 1e-9))
        k = ucb.argmax()
        r = (rng.random() < mu[k])
        n[k] += 1
        mu_hat[k] += (r - mu_hat[k]) / n[k]
        rewards.append(r)
    return np.array(rewards)

def run_thompson(T, mu, rng):
    K = len(mu)
    alpha = np.ones(K)
    beta  = np.ones(K)
    rewards = []
    for _ in range(T):
        samples = rng.beta(alpha, beta)
        k = samples.argmax()
        r = (rng.random() < mu[k])
        alpha[k] += r
        beta[k]  += 1 - r
        rewards.append(r)
    return np.array(rewards)

mu_star = mu_true.max()
r_ucb  = run_ucb1(T, mu_true, rng)
r_ts   = run_thompson(T, mu_true, rng)
r_rand = np.array([rng.random() < mu_true[rng.integers(K)] for _ in range(T)])

cum_regret_ucb  = (mu_star - r_ucb).cumsum()
cum_regret_ts   = (mu_star - r_ts).cumsum()
cum_regret_rand = (mu_star - r_rand).cumsum()
print(f"Cumulative regret at T={T}:")
print(f"  UCB1:   {cum_regret_ucb[-1]:.1f}")
print(f"  Thompson: {cum_regret_ts[-1]:.1f}")
print(f"  Random: {cum_regret_rand[-1]:.1f}")
```

Both UCB1 and Thompson sampling accumulate far less regret than random arm selection,
growing logarithmically while random grows linearly.

## Exercises

**Exercise 1.** At round $t = 100$, arm $k$ has sample mean $\hat\mu_k = 0.60$ and
has been pulled $n_k = 10$ times. Compute its UCB1 index, then explain what happens
to the index of an arm pulled only once.

<details>
<summary>Solution</summary>

**Step 1.** The UCB1 index is $\hat\mu_k + \sqrt{2\ln t / n_k}$. Compute the bonus
with $t = 100$, $n_k = 10$:

$$
\sqrt{\frac{2\ln 100}{10}} = \sqrt{\frac{2 \cdot 4.605}{10}} = \sqrt{0.921} \approx 0.96.
$$

**Step 2.** Add the mean: index $= 0.60 + 0.96 = 1.56$. The bound sits well above
$1$, the largest possible Bernoulli mean, so the optimism is loose this early.

**Step 3.** An arm with $n_k = 1$ has bonus $\sqrt{2\ln 100 / 1} \approx 3.03$, far
larger. UCB1 inflates the index of barely-tried arms, which forces at least one more
pull before they can be dismissed. This is how the algorithm guarantees every arm is
explored enough.

</details>

**Exercise 2.** The UCB1 regret bound is $O(\ln T)$, summed over suboptimal arms as
$\sum_{k:\mu_k < \mu^*} 8\ln T / \Delta_k$. Consider a two-arm instance with
$\mu^* = 0.5$ and a suboptimal arm at $\mu = 0.5 - \Delta$. Explain why the bound
blows up as $\Delta \to 0$, yet the actual regret stays bounded, and reconcile the
two.

<details>
<summary>Solution</summary>

**Step 1.** The leading term is $8\ln T / \Delta$, which diverges as $\Delta \to 0$
because the $1/\Delta$ factor grows without bound.

**Step 2.** The actual cumulative regret is the number of suboptimal pulls times the
per-pull cost $\Delta$. Even if the algorithm pulls the wrong arm every round, total
regret is at most $T\Delta$, which goes to $0$ as $\Delta \to 0$.

**Step 3.** Reconcile by taking the minimum of the two bounds. The
distribution-dependent bound $8\ln T / \Delta$ is tight when $\Delta$ is moderate;
for tiny $\Delta$ the trivial bound $T\Delta$ is smaller. The worst case over
$\Delta$ balances them at $\Delta \sim \sqrt{\ln T / T}$, giving the
distribution-free rate $O(\sqrt{T\ln T})$. Hard instances are the ones where the
gap is neither large nor vanishing.

</details>

**Exercise 3 (code).** Run Thompson sampling on five Bernoulli arms with means
$(0.1, 0.3, 0.5, 0.4, 0.2)$ for $T = 2000$. Track the arm pulled each round and
confirm two structural properties: the expected regret is far below a random
policy's, and the fraction of optimal-arm pulls rises sharply from the first half to
the second.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)
mu = np.array([0.1, 0.3, 0.5, 0.4, 0.2])
K, T = len(mu), 2000

def thompson_pulls(T, mu, rng):
    K = len(mu)
    a = np.ones(K); b = np.ones(K)
    pulls = []
    for _ in range(T):
        k = rng.beta(a, b).argmax()
        r = rng.random() < mu[k]
        a[k] += r; b[k] += 1 - r
        pulls.append(k)
    return np.array(pulls)

pulls = thompson_pulls(T, mu, rng)
best = mu.argmax()

# Expected regret given the chosen arms (averages out reward noise)
exp_regret = (mu.max() - mu[pulls]).sum()
rand_regret = T * (mu.max() - mu.mean())

frac_first = np.mean(pulls[:T // 2] == best)
frac_second = np.mean(pulls[T // 2:] == best)

assert exp_regret < 0.3 * rand_regret    # learns far faster than random
assert frac_second > frac_first          # concentrates on the best arm
assert frac_second > 0.9                  # nearly always optimal late
print("expected regret:", round(exp_regret, 1),
      "optimal-pull frac (late):", round(frac_second, 3))
```

By the second half Thompson sampling pulls the best arm more than $95\%$ of the
time, so its accumulated regret is a small fraction of the random policy's.

</details>
