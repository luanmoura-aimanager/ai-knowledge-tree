Frequentist inference asks: what does the data say about $\theta$, treating $\theta$
as fixed and unknown? Bayesian inference asks: after seeing the data, what is the
probability distribution over $\theta$? The prior encodes belief before seeing data;
the likelihood encodes what the data says; the posterior combines them.

## Bayes' rule for parameters

Let $\theta$ be a parameter and $x$ the observed data. Bayes' rule (A2/bayes-rule) applied
to this setting is:

$$
p(\theta \mid x) = \frac{p(x \mid \theta)\, p(\theta)}{p(x)}.
$$

- $p(\theta)$: the **prior** distribution over parameters.
- $p(x \mid \theta)$: the **likelihood** (same object as in MLE; now read as a
  function of $\theta$ for fixed $x$).
- $p(\theta \mid x)$: the **posterior** distribution over parameters given the data.
- $p(x) = \int p(x \mid \theta) p(\theta)\, d\theta$: the **marginal likelihood** or
  **evidence**, a normalizing constant.

The posterior is proportional to likelihood times prior<FN n="1" />:

$$
p(\theta \mid x) \propto p(x \mid \theta)\, p(\theta).
$$

## Beta-Binomial example

**Model.** A coin has unknown bias $\theta \in [0,1]$. Observe $n$ flips and $k$ heads.

**Likelihood.** The number of heads is binomial:

$$
p(k \mid \theta, n) = \binom{n}{k} \theta^k (1-\theta)^{n-k}.
$$

**Prior.** Choose a Beta distribution: $\theta \sim \mathrm{Beta}(\alpha, \beta)$,

$$
p(\theta) = \frac{1}{B(\alpha,\beta)} \theta^{\alpha-1}(1-\theta)^{\beta-1},
$$

where $B(\alpha,\beta) = \Gamma(\alpha)\Gamma(\beta)/\Gamma(\alpha+\beta)$ is the Beta function.

**Posterior.** Multiplying:

$$
p(\theta \mid k) \propto \theta^k(1-\theta)^{n-k} \cdot \theta^{\alpha-1}(1-\theta)^{\beta-1}
= \theta^{\alpha+k-1}(1-\theta)^{\beta+(n-k)-1}.
$$

This is the kernel of $\mathrm{Beta}(\alpha + k,\; \beta + n - k)$.

The posterior mean is:

$$
E[\theta \mid k] = \frac{\alpha + k}{\alpha + \beta + n}.
$$

For large $n$, this converges to $k/n$ (the MLE). The prior parameters $\alpha, \beta$
act as pseudo-counts: $\alpha$ pseudo-heads and $\beta$ pseudo-tails observed before
the experiment.

The pseudo-count reading makes the prior's grip concrete. Observe $k = 3$ heads in
$n = 5$ flips, so the data alone says $k/n = 0.6$. Feed it through three priors and the
posterior mean $\frac{\alpha+k}{\alpha+\beta+n}$ lands in three places:

- Uniform, $\mathrm{Beta}(1,1)$ (2 pseudo-flips): $\frac{1+3}{2+5} \approx 0.571$,
  almost the raw $0.6$, since two pseudo-flips barely register against five real ones.
- Weak, $\mathrm{Beta}(2,2)$ (4 pseudo-flips): $\frac{2+3}{4+5} \approx 0.556$.
- Informative, $\mathrm{Beta}(10,10)$ (20 pseudo-flips): $\frac{10+3}{20+5} = 0.52$,
  still pinned near the prior mean $0.5$, because twenty pseudo-flips outweigh the
  five real ones four to one.

The data is identical in all three; only the prior's pseudo-count mass differs, and
that mass alone decides how far the posterior moves off $0.5$ toward $0.6$. Pour in
more real data and the pseudo-counts are swamped: at $n = 500$ with $k = 300$ (still
$k/n = 0.6$), even $\mathrm{Beta}(10,10)$ gives $\frac{310}{520} \approx 0.596$.

## Sequential updating

Bayesian inference updates online. If a first dataset gives posterior
$\mathrm{Beta}(\alpha', \beta')$, using that posterior as the prior for a second
dataset gives the same result as using the original prior on all data at once.
The order in which data arrives does not affect the final posterior<FN n="2" />.

## Choosing a prior

**Informative priors** encode domain knowledge ($\alpha = \beta = 10$ for a near-fair
coin). **Weakly informative priors** regularize without strong assumptions. **Uniform
priors** ($\alpha = \beta = 1$) assert equal probability for all $\theta$, but
"uniform" is parameterization-dependent (uniform in $\theta$ is not uniform in $\log\theta$).

![Bayesian updating: a Beta(2,2) prior plus Binomial data yields a Beta posterior that concentrates on the truth θ = 0.3 as n grows.](/figures/B2/prior-likelihood-posterior.svg)

## Implementation

```python-static
import numpy as np
from scipy.stats import beta as beta_dist

rng = np.random.default_rng(0)
theta_true = 0.3          # true bias
alpha0, beta0 = 2.0, 2.0  # prior pseudo-counts
ns = [5, 20, 100, 500]    # cumulative sample sizes

data = rng.binomial(1, theta_true, max(ns))

theta_grid = np.linspace(0, 1, 500)
print(f"{'n':>6} {'posterior_mean':>16} {'post_std':>10} {'95%_CI':>20}")
for n in ns:
    k = data[:n].sum()
    a_post = alpha0 + k
    b_post = beta0 + n - k
    post = beta_dist(a_post, b_post)
    pmean = post.mean()
    pstd  = post.std()
    lo, hi = post.ppf(0.025), post.ppf(0.975)
    print(f"{n:6d} {pmean:16.4f} {pstd:10.4f} [{lo:.3f}, {hi:.3f}]")
print(f"True theta: {theta_true}")
```

The posterior mean starts near the prior mean $\alpha_0/(\alpha_0+\beta_0) = 0.5$
and converges toward the true $\theta = 0.3$ as $n$ grows; the posterior standard
deviation shrinks like $1/\sqrt{n}$.

## Exercises

**Exercise 1.** A coin is flipped $n = 8$ times and lands heads $k = 6$ times. Using
the prior $\theta \sim \mathrm{Beta}(2, 2)$, write down the posterior distribution and
compute its mean by hand.

<details>
<summary>Solution</summary>

**Step 1.** The Beta-Binomial update adds the counts to the prior parameters:
$\theta \mid k \sim \mathrm{Beta}(\alpha + k,\; \beta + n - k)$. With
$\alpha = \beta = 2$, $k = 6$, $n - k = 2$:

$$
\theta \mid k \sim \mathrm{Beta}(2 + 6,\; 2 + 2) = \mathrm{Beta}(8, 4).
$$

**Step 2.** The posterior mean is $\frac{\alpha + k}{\alpha + \beta + n}$:

$$
E[\theta \mid k] = \frac{8}{8 + 4} = \frac{8}{12} = \frac{2}{3} \approx 0.667.
$$

It sits between the prior mean $0.5$ and the data ratio $k/n = 0.75$, closer to the
data because eight real flips outweigh the four pseudo-flips of the prior.

</details>

**Exercise 2.** Show that splitting the data and updating sequentially gives the same
posterior as a single batch update. Start from $\mathrm{Beta}(\alpha, \beta)$, observe
$k_1$ heads in $n_1$ flips, then $k_2$ heads in $n_2$ flips.

<details>
<summary>Solution</summary>

**Step 1.** Update on the first batch. The posterior after $(k_1, n_1)$ is
$\mathrm{Beta}(\alpha + k_1,\; \beta + n_1 - k_1)$.

**Step 2.** Use that posterior as the prior for the second batch. Adding $(k_2, n_2)$
gives

$$
\mathrm{Beta}\big(\alpha + k_1 + k_2,\; \beta + (n_1 - k_1) + (n_2 - k_2)\big).
$$

**Step 3.** Update on the pooled data in one step. Total heads $k_1 + k_2$, total flips
$n_1 + n_2$, so the single-batch posterior is

$$
\mathrm{Beta}\big(\alpha + k_1 + k_2,\; \beta + (n_1 + n_2) - (k_1 + k_2)\big),
$$

which matches Step 2 term by term. The update only ever adds total head and tail
counts, so any grouping of the same flips yields the same posterior.

</details>

**Exercise 3 (code).** Verify sequential updating numerically without relying on a
Beta library. Represent the posterior as an unnormalized density on a grid of
$\theta$ values, update it once on all data and again in two sequential batches, and
confirm the two normalized posteriors agree.

<details>
<summary>Solution</summary>

```python
import numpy as np

grid = np.linspace(0, 1, 2001)
alpha0, beta0 = 2.0, 2.0
prior = grid**(alpha0 - 1) * (1 - grid)**(beta0 - 1)

def update(dens, k, n):
    # multiply by the binomial likelihood kernel theta^k (1-theta)^(n-k)
    return dens * grid**k * (1 - grid)**(n - k)

def normalize(dens):
    return dens / np.trapz(dens, grid)

# Batch 1: all 12 flips at once (k=7, n=12)
batch = normalize(update(prior, 7, 12))

# Sequential: (k1=3, n1=5) then (k2=4, n2=7)
seq = update(prior, 3, 5)
seq = update(seq, 4, 7)
seq = normalize(seq)

assert np.allclose(batch, seq, atol=1e-9)
print("max abs diff:", np.max(np.abs(batch - seq)))
```

The two posteriors are identical to numerical precision because both reduce to the
same total counts $k = 7$, $n = 12$.

</details>

The next lesson shows that for many distributions a carefully chosen prior keeps the
posterior in the same family as the prior, making the update a one-line formula.
