The sampling distribution of the sample mean has a known formula ($\sigma/\sqrt{n}$).
For the median, the trimmed mean, or a regression coefficient, no such formula
exists in closed form. The **bootstrap** solves this by approximating the sampling
distribution empirically: treat the observed data as a stand-in for the population
and resample from it repeatedly<FN n="1" />.

## The bootstrap principle

Let $\hat\theta = T(X_1, \ldots, X_n)$ be any statistic. The sampling distribution
of $\hat\theta$ is determined by the unknown population $F$. The bootstrap replaces
$F$ with the **empirical distribution** $\hat F_n$, which places mass $1/n$ on each
observed $X_i$.

**Algorithm (nonparametric bootstrap):**

1. Draw $B$ bootstrap samples $X^{*b} = (X_1^{*b}, \ldots, X_n^{*b})$ by sampling
   with replacement from $\{X_1, \ldots, X_n\}$.
2. Compute $\hat\theta^{*b} = T(X^{*b})$ for each bootstrap sample.
3. The distribution of $\{\hat\theta^{*b}\}_{b=1}^B$ approximates the sampling
   distribution of $\hat\theta$.

The bootstrap standard error is $\widehat{\mathrm{SE}} = \mathrm{std}(\hat\theta^{*1}, \ldots, \hat\theta^{*B})$.

## Bootstrap confidence intervals

**Percentile interval.** Use the $\alpha/2$ and $1-\alpha/2$ quantiles of the
bootstrap distribution:

$$
[Q_{\alpha/2}(\hat\theta^*), Q_{1-\alpha/2}(\hat\theta^*)].
$$

Simple but can be biased when $\hat\theta$ is biased.

**Pivotal (basic) interval.** Uses the distribution of $\hat\theta^* - \hat\theta$:

$$
[2\hat\theta - Q_{1-\alpha/2}(\hat\theta^*),\; 2\hat\theta - Q_{\alpha/2}(\hat\theta^*)].
$$

**BCa (bias-corrected and accelerated).** Adjusts both the center and the acceleration
(the rate of change of SE with the parameter). Better coverage than the percentile
interval at the cost of computing the acceleration via a jackknife<FN n="2" />.

For most purposes, the pivotal interval is a solid default with minimal overhead.

## When to use which type

- **Nonparametric bootstrap:** when the data distribution is unknown or non-Gaussian.
- **Parametric bootstrap:** resample from the fitted parametric model (e.g., fit a
  Gaussian, bootstrap from it). Better than nonparametric when the model is correct.
- **Residual bootstrap (regression):** resample residuals, not raw observations<FN n="3" />.

## Implementation

```python
import numpy as np

rng = np.random.default_rng(0)
n = 60
data = rng.exponential(scale=2.0, size=n)  # true median = 2*log(2) ~ 1.386
B = 5000

# Bootstrap distribution of the median
boot_medians = np.array([
    np.median(rng.choice(data, n, replace=True))
    for _ in range(B)
])

theta_hat = np.median(data)
se_boot   = boot_medians.std()
true_median = 2 * np.log(2)

# Percentile CI
lo_pct, hi_pct = np.percentile(boot_medians, [2.5, 97.5])

# Pivotal CI
lo_piv = 2*theta_hat - hi_pct
hi_piv = 2*theta_hat - lo_pct

print(f"True median:    {true_median:.4f}")
print(f"Sample median:  {theta_hat:.4f}")
print(f"Bootstrap SE:   {se_boot:.4f}")
print(f"Percentile 95%: [{lo_pct:.4f}, {hi_pct:.4f}]")
print(f"Pivotal 95%:    [{lo_piv:.4f}, {hi_piv:.4f}]")

# Coverage simulation
covers_pct = covers_piv = 0
for _ in range(1000):
    d = rng.exponential(2.0, n)
    th = np.median(d)
    bs = np.array([np.median(rng.choice(d, n, replace=True)) for _ in range(500)])
    lo_p, hi_p = np.percentile(bs, [2.5, 97.5])
    if lo_p <= true_median <= hi_p: covers_pct += 1
    if 2*th-hi_p <= true_median <= 2*th-lo_p: covers_piv += 1
print(f"\nPercentile coverage: {covers_pct/1000:.3f}")
print(f"Pivotal coverage:    {covers_piv/1000:.3f}  (closer to 0.95)")
```

The pivotal interval has coverage closer to 0.95 than the percentile interval for
this skewed distribution.

## Exercises

**Exercise 1.** A bootstrap sample is drawn by sampling $n$ observations with
replacement from a dataset of size $n$. Compute, by hand, the probability that a
fixed observation $X_1$ is left out of a single bootstrap sample, and evaluate its
limit as $n \to \infty$.

<details>
<summary>Solution</summary>

**Step 1.** Each of the $n$ draws picks $X_1$ with probability $1/n$, so it misses
$X_1$ with probability $1 - 1/n$. The draws are independent (sampling with
replacement), so the probability $X_1$ is missed on all $n$ draws is

$$
\left(1 - \frac{1}{n}\right)^n.
$$

**Step 2.** Take the limit using $\left(1 - \tfrac{1}{n}\right)^n \to e^{-1}$:

$$
\lim_{n \to \infty} \left(1 - \frac{1}{n}\right)^n = e^{-1} \approx 0.368.
$$

About $36.8\%$ of observations are absent from any given bootstrap sample, which is
the $0.368$ weight in the $.632$ estimator and the reason a bootstrap sample
contains roughly $63.2\%$ distinct observations.

</details>

**Exercise 2.** The percentile interval reports
$[Q_{\alpha/2}(\hat\theta^*), Q_{1-\alpha/2}(\hat\theta^*)]$ and the pivotal interval
reports $[2\hat\theta - Q_{1-\alpha/2}(\hat\theta^*), 2\hat\theta - Q_{\alpha/2}(\hat\theta^*)]$.
Show that the two intervals have the same width, and explain when they coincide.

<details>
<summary>Solution</summary>

**Step 1.** Write the lower quantile as $L = Q_{\alpha/2}(\hat\theta^*)$ and the upper
as $U = Q_{1-\alpha/2}(\hat\theta^*)$. The percentile width is $U - L$.

**Step 2.** The pivotal endpoints are $2\hat\theta - U$ (lower) and $2\hat\theta - L$
(upper). Its width is

$$
(2\hat\theta - L) - (2\hat\theta - U) = U - L,
$$

identical to the percentile width.

**Step 3.** The pivotal interval is the percentile interval reflected about
$\hat\theta$: its center is $2\hat\theta - \tfrac{L+U}{2}$ versus the percentile
center $\tfrac{L+U}{2}$. The two coincide when the bootstrap distribution is
symmetric about $\hat\theta$, that is $\tfrac{L+U}{2} = \hat\theta$. When the
bootstrap distribution is skewed the intervals shift in opposite directions, which
is why the pivotal interval corrects coverage for the skewed median above.

</details>

**Exercise 3 (code).** With `np.random.default_rng(0)`, draw $n = 200$ points from a
standard normal and bootstrap the sample mean with $B = 4000$ resamples. Verify that
the bootstrap standard error is close to the analytic $\sigma/\sqrt{n} = 1/\sqrt{200}$,
and that the percentile and pivotal $95\%$ intervals have equal width.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)
n = 200
data = rng.standard_normal(n)
B = 4000

theta_hat = data.mean()
boot_means = np.array([rng.choice(data, n, replace=True).mean() for _ in range(B)])

se_boot = boot_means.std()
se_analytic = 1 / np.sqrt(n)          # sigma = 1 for standard normal

lo, hi = np.percentile(boot_means, [2.5, 97.5])
width_pct = hi - lo
width_piv = (2*theta_hat - lo) - (2*theta_hat - hi)

# Bootstrap SE tracks the analytic SE within ~10%
assert abs(se_boot - se_analytic) < 0.1 * se_analytic
# Percentile and pivotal intervals share a width (Exercise 2)
assert np.isclose(width_pct, width_piv)
print(round(se_boot, 4), round(se_analytic, 4), round(width_pct, 4))
```

The bootstrap SE reproduces $1/\sqrt{200} \approx 0.0707$ without ever using the
formula, and the two interval widths match exactly because each is $U - L$.

</details>
