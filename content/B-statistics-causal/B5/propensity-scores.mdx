The backdoor adjustment requires conditioning on all confounders simultaneously,
which is difficult in high dimensions. The **propensity score** collapses the
confounder vector into a single scalar while preserving the balancing property.

## The propensity score

The propensity score is the probability of receiving treatment given observed
covariates:

$$
e(X) = P(W = 1 \mid X).
$$

**Rosenbaum-Rubin theorem (1983).** Under strong ignorability
$(Y(0), Y(1)) \perp W \mid X$, it also holds that $(Y(0), Y(1)) \perp W \mid e(X)$<FN n="1" />.

Conditioning on the propensity score is sufficient to remove confounding, even
though $e(X)$ is a scalar rather than the full vector $X$. This is the balancing
property: among units with the same $e(x)$, treatment assignment is as-if random.

## Estimating the propensity score

$e(X)$ is unknown and must be estimated, typically with logistic regression:

$$
\hat e(X) = \sigma(X^\top\hat\beta), \quad \sigma(z) = 1/(1+e^{-z}).
$$

For flexible confounders, gradient boosted trees or regularized regression are used.
Calibration (the estimated probability is accurate) matters more than discrimination
(the AUROC) for propensity-score methods.

## Propensity-score matching

Match each treated unit to one (or several) control units with similar $\hat e(X)$,
then compare outcomes within matched pairs.

**Nearest-neighbor matching:** for each treated unit $i$, find the control unit
$j^* = \arg\min_{j: W_j=0} |\hat e(X_i) - \hat e(X_j)|$.

**ATT estimator:**

$$
\hat\tau_{\mathrm{ATT}} = \frac{1}{n_1} \sum_{i: W_i=1} \left(Y_i - Y_{j^*(i)}\right).
$$

Matching reduces variance (only treated units contribute) but can lose efficiency
if the control group is large and many controls are discarded.

## Inverse-probability weighting (IPW)

IPW reweights each unit so that the weighted sample looks like a randomized experiment.

**Horvitz-Thompson estimator for ATE:**

$$
\hat\tau_{\mathrm{IPW}} = \frac{1}{n}\sum_{i=1}^n \frac{W_i Y_i}{\hat e(X_i)} - \frac{(1-W_i) Y_i}{1-\hat e(X_i)}.
$$

**Intuition.** A treated unit with $\hat e(X) = 0.2$ (unlikely to be treated) is
upweighted by $1/0.2 = 5$ to represent the population of similar units in the
counterfactual. The weighting creates pseudo-populations where treatment is
independent of covariates<FN n="3" />.

IPW is unbiased when the propensity model is correct. **Normalized IPW** divides
by the sum of weights to reduce variance (Hajek estimator). **Doubly robust**
estimators combine IPW with an outcome model; they are consistent if either model
is correctly specified<FN n="2" />.

## Implementation

```python-static
import numpy as np
from sklearn.linear_model import LogisticRegression

rng = np.random.default_rng(0)
n = 2000

# Generate confounded data
X1 = rng.normal(0, 1, n)
X2 = rng.normal(0, 1, n)
W  = (0.5*X1 + 0.3*X2 + rng.normal(0, 1, n) > 0).astype(int)
Y0 = 0.5*X1 + 0.2*X2 + rng.normal(0, 1, n)
Y1 = Y0 + 1.0              # true ATE = 1.0
Y  = W * Y1 + (1-W) * Y0

X = np.column_stack([X1, X2])

# Estimate propensity score
lr = LogisticRegression()
lr.fit(X, W)
e_hat = lr.predict_proba(X)[:, 1]

# IPW (Hajek)
w_treat = W / e_hat
w_ctrl  = (1 - W) / (1 - e_hat)
ipw_ate = (Y * w_treat / w_treat[W==1].sum() -
           Y * w_ctrl  / w_ctrl[W==0].sum()).sum()

# Nearest-neighbor matching (1:1, ATT)
from sklearn.neighbors import NearestNeighbors
nn = NearestNeighbors(n_neighbors=1)
nn.fit(e_hat[W==0].reshape(-1,1))
_, idx = nn.kneighbors(e_hat[W==1].reshape(-1,1))
match_ates = Y[W==1] - Y[W==0][idx.flatten()]
att_match = match_ates.mean()

# Naive
naive = Y[W==1].mean() - Y[W==0].mean()

print(f"True ATE:   1.000")
print(f"Naive:      {naive:.4f}")
print(f"IPW ATE:    {ipw_ate:.4f}")
print(f"Matching ATT: {att_match:.4f}")

# Covariate balance before/after matching
print(f"\nBalance check (mean X1):")
print(f"  Treated: {X1[W==1].mean():.3f}, Control: {X1[W==0].mean():.3f} (before)")
matched_ctrl_idx = np.where(W==0)[0][idx.flatten()]
print(f"  Treated: {X1[W==1].mean():.3f}, Matched ctrl: {X1[matched_ctrl_idx].mean():.3f} (after)")
```

After matching, the mean of $X_1$ in the matched control group is close to the
treated group, confirming that the propensity score successfully balanced the covariate.

## Exercises

**Exercise 1.** Four units have estimated propensity scores and observed outcomes:
a treated unit with $\hat e = 0.25$, $Y = 8$; a treated unit with $\hat e = 0.5$,
$Y = 6$; a control unit with $\hat e = 0.4$, $Y = 3$; a control unit with
$\hat e = 0.8$, $Y = 5$. Compute the Horvitz-Thompson IPW estimate of the ATE by
hand.

<details>
<summary>Solution</summary>

**Step 1.** The Horvitz-Thompson estimator is
$\hat\tau_{\mathrm{IPW}} = \frac{1}{n}\sum_i \big(\frac{W_i Y_i}{\hat e_i} - \frac{(1-W_i)Y_i}{1-\hat e_i}\big)$,
with $n = 4$. Treated units contribute only the first term, control units only the
second.

**Step 2.** Treated terms: $8 / 0.25 = 32$ and $6 / 0.5 = 12$. Control terms:
$3 / (1 - 0.4) = 3 / 0.6 = 5$ and $5 / (1 - 0.8) = 5 / 0.2 = 25$.

**Step 3.** Sum with the signs and divide by $n$:

$$
\hat\tau_{\mathrm{IPW}} = \frac{(32 + 12) - (5 + 25)}{4} = \frac{44 - 30}{4} = \frac{14}{4} = 3.5.
$$

The control unit with $\hat e = 0.8$ is upweighted heavily ($1/0.2 = 5$) because a
control unit that looks likely to be treated is rare and must stand in for many
similar units.

</details>

**Exercise 2.** Show that the IPW estimator is unbiased for $E[Y(1)]$ in its
treated arm, $E\big[\frac{W Y}{e(X)}\big] = E[Y(1)]$, using strong ignorability
and the definition $e(X) = P(W=1\mid X)$.

<details>
<summary>Solution</summary>

**Step 1.** Condition on $X$ and use the tower rule:
$E\big[\frac{W Y}{e(X)}\big] = E\Big[\frac{1}{e(X)} E[W Y \mid X]\Big]$, since
$e(X)$ is a function of $X$.

**Step 2.** On the treated arm the observed $Y$ equals $Y(1)$, so
$W Y = W Y(1)$. By strong ignorability $W \perp Y(1) \mid X$, so the inner
expectation factors:

$$
E[W Y(1)\mid X] = E[W\mid X]\, E[Y(1)\mid X] = e(X)\, E[Y(1)\mid X].
$$

**Step 3.** The $e(X)$ cancels, leaving
$E\big[\frac{W Y}{e(X)}\big] = E\big[E[Y(1)\mid X]\big] = E[Y(1)]$ by the tower
rule. The symmetric argument with $1-W$ and $1-e(X)$ gives $E[Y(0)]$, so the
difference identifies the ATE.

</details>

**Exercise 3 (code).** Generate confounded data from a known logistic propensity
$e(X) = \sigma(0.5 X_1 + 0.3 X_2)$ with true ATE $1.0$. Fit the propensity by
plain-numpy logistic-regression gradient descent (no library), then verify with a
fixed seed that the naive contrast is biased high and that normalized (Hajek) IPW
recovers the ATE within tolerance.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)
n = 50_000
X1 = rng.normal(0, 1, n)
X2 = rng.normal(0, 1, n)

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

e_true = sigmoid(0.5 * X1 + 0.3 * X2)
W = (rng.random(n) < e_true).astype(float)
Y0 = 0.5 * X1 + 0.2 * X2 + rng.normal(0, 1, n)
Y = W * (Y0 + 1.0) + (1 - W) * Y0          # true ATE = 1.0

# logistic regression by gradient descent (intercept + X1 + X2)
Xd = np.column_stack([np.ones(n), X1, X2])
beta = np.zeros(3)
for _ in range(500):
    grad = Xd.T @ (sigmoid(Xd @ beta) - W) / n
    beta -= 1.0 * grad
e_hat = sigmoid(Xd @ beta)

# normalized (Hajek) IPW
wt = W / e_hat
wc = (1 - W) / (1 - e_hat)
ipw = (Y * wt).sum() / wt.sum() - (Y * wc).sum() / wc.sum()
naive = Y[W == 1].mean() - Y[W == 0].mean()

assert naive > 1.0 + 0.05          # confounding biases the naive contrast high
assert abs(ipw - 1.0) < 0.05       # IPW recovers the true ATE
print(f"naive {naive:.3f}, IPW {ipw:.3f}")
```

The hand-rolled logistic fit reproduces the propensity well enough that Hajek IPW
lands within tolerance of the true $1.0$, while the naive contrast stays biased
high by the confounding through $X_1$ and $X_2$.

</details>
