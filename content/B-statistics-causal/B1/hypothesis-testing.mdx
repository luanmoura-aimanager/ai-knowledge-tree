An experiment produces data and you want to decide: is the effect real, or could it
have arisen by chance under a null assumption? **Hypothesis testing** formalizes this
decision. The framework is: specify a null hypothesis, compute how surprising the
data would be if that null were true, and reject the null when the data are
sufficiently surprising.

## The framework

A **null hypothesis** $H_0$ is the default: no effect, no difference. The **alternative**
$H_1$ is what you are trying to detect.

A **test statistic** $T$ is a function of the data whose sampling distribution is
known under $H_0$.

The **p-value** is the probability of seeing a test statistic as extreme as (or more
extreme than) the observed $t_{\text{obs}}$, computed under $H_0$:

$$
p = P_{H_0}(|T| \ge |t_{\text{obs}}|).
$$
<FN n="1" />

A small p-value ($p < \alpha$) is evidence against $H_0$. The significance level
$\alpha$ (typically 0.05) is the tolerated Type I error rate: the probability of
rejecting a true null.

To calibrate what small means, take a two-sided z-test and read the p-value off the
observed standardized statistic $z = (\bar X_n - \mu_0)/(\sigma/\sqrt n)$:

- $z = 1$ (one standard error off): $p = 0.317$. A third of true nulls land at least
  this far out; the data are unremarkable.
- $z = 1.96$: $p = 0.05$. The conventional boundary, where $1$ in $20$ true nulls
  reaches.
- $z = 2.58$: $p = 0.0099$. Roughly $1$ in $100$.
- $z = 3$: $p = 0.0027$. About $1$ in $370$, the territory particle physics calls a
  "$3\sigma$" hint.

A confusion worth naming: the p-value is **not** the probability that $H_0$ is true.
$p = 0.05$ does not mean $H_0$ has a $5\%$ chance of holding; it means data this
extreme occur $5\%$ of the time *when $H_0$ is true*. The two diverge sharply when
$H_0$ is rarely true to begin with: testing many no-effect hypotheses at $\alpha =
0.05$, a $p = 0.04$ "discovery" can still be a false positive most of the time,
because most of the nulls were true and produced their share of small p-values by
chance. The p-value scores surprise under $H_0$; it does not, on its own, give the
posterior on $H_0$.

Two types of error<FN n="2" />:
- **Type I (false positive):** reject $H_0$ when it is true. Rate $\le \alpha$.
- **Type II (false negative):** fail to reject $H_0$ when it is false. Rate $\beta$; power $= 1-\beta$.

## The z-test (known variance)

Test $H_0: \mu = \mu_0$ against $H_1: \mu \ne \mu_0$ for a sample of size $n$ from
$\mathcal{N}(\mu, \sigma^2)$ with $\sigma^2$ known.

The test statistic is:

$$
Z = \frac{\bar X_n - \mu_0}{\sigma/\sqrt{n}} \sim \mathcal{N}(0,1) \text{ under } H_0.
$$

Reject $H_0$ when $|Z| > z_{\alpha/2}$, the $1 - \alpha/2$ quantile of $\mathcal{N}(0,1)$.

## The t-test (unknown variance)

When $\sigma^2$ is unknown, substitute $s$ (sample std, ddof=1):

$$
T = \frac{\bar X_n - \mu_0}{s/\sqrt{n}} \sim t_{n-1} \text{ under } H_0.
$$

The $t_{n-1}$ distribution has heavier tails than normal; for small $n$ this matters.
As $n \to \infty$, $t_{n-1} \to \mathcal{N}(0,1)$.

**Two-sample t-test.** For two independent groups with means $\mu_1, \mu_2$ and equal
variances (pooled variance $s_p^2$):

$$
T = \frac{\bar X_1 - \bar X_2}{s_p\sqrt{1/n_1 + 1/n_2}} \sim t_{n_1+n_2-2}.
$$

The pooled variance is $s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}$.

## The chi-squared test for variance

Test $H_0: \sigma^2 = \sigma_0^2$. Under $H_0$:

$$
\chi^2 = \frac{(n-1)s^2}{\sigma_0^2} \sim \chi^2_{n-1}.
$$

The $\chi^2$ distribution is right-skewed; for a two-sided test, compare the
statistic to the $\alpha/2$ and $1-\alpha/2$ quantiles.

## Implementation

```python-static
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)

# One-sample t-test: does this sample come from mean=0?
data = rng.normal(loc=0.3, scale=1.0, size=40)  # true mean slightly > 0
t_stat, p_value = stats.ttest_1samp(data, popmean=0)
print(f"One-sample t-test: t={t_stat:.4f}, p={p_value:.4f}")

# Two-sample t-test: are two groups different?
group_a = rng.normal(5.0, 1.0, 30)
group_b = rng.normal(5.5, 1.0, 30)
t2, p2 = stats.ttest_ind(group_a, group_b, equal_var=True)
print(f"Two-sample t-test: t={t2:.4f}, p={p2:.4f}")

# Chi-squared test: does variance match null?
sigma0_sq = 1.0
sample = rng.normal(0, 1.2, 50)  # true sigma slightly > 1
n = len(sample)
chi2_stat = (n - 1) * sample.var(ddof=1) / sigma0_sq
p_chi2 = 2 * min(stats.chi2.cdf(chi2_stat, n-1),
                  1 - stats.chi2.cdf(chi2_stat, n-1))
print(f"Chi-squared variance test: chi2={chi2_stat:.4f}, p={p_chi2:.4f}")

# Empirical Type I error at alpha=0.05 (should be ~0.05)
n_trials = 10_000
rejects = sum(stats.ttest_1samp(rng.normal(0,1,30), 0).pvalue < 0.05
              for _ in range(n_trials))
print(f"Empirical Type I error: {rejects/n_trials:.3f}")
```

The empirical Type I error near 0.05 confirms that the test is calibrated.

## Exercises

**Exercise 1.** A sample of $n = 64$ has mean $\bar X = 52$. Test
$H_0: \mu = 50$ against $H_1: \mu \ne 50$ with known $\sigma = 8$. Compute the
$z$-statistic and decide at $\alpha = 0.05$ (critical value $z_{0.025} = 1.96$).

<details>
<summary>Solution</summary>

**Step 1.** The standard error is $\sigma/\sqrt n = 8/\sqrt{64} = 8/8 = 1$.

**Step 2.** The statistic is

$$
z = \frac{\bar X - \mu_0}{\sigma/\sqrt n} = \frac{52 - 50}{1} = 2.
$$

**Step 3.** Since $|z| = 2 > 1.96$, reject $H_0$ at $\alpha = 0.05$. The
observed mean sits two standard errors above the null, just past the conventional
boundary.

</details>

**Exercise 2.** Show that for two independent groups of equal size
$n_1 = n_2 = n$ and equal sample variances $s_1^2 = s_2^2 = s^2$, the two-sample
$t$-statistic reduces to $T = (\bar X_1 - \bar X_2)/(s\sqrt{2/n})$.

<details>
<summary>Solution</summary>

**Step 1.** The pooled variance with $n_1 = n_2 = n$ and $s_1^2 = s_2^2 = s^2$ is

$$
s_p^2 = \frac{(n-1)s^2 + (n-1)s^2}{2n - 2} = \frac{2(n-1)s^2}{2(n-1)} = s^2,
$$

so $s_p = s$.

**Step 2.** Substitute into the two-sample statistic with $1/n_1 + 1/n_2 = 2/n$:

$$
T = \frac{\bar X_1 - \bar X_2}{s_p\sqrt{1/n_1 + 1/n_2}} = \frac{\bar X_1 - \bar X_2}{s\sqrt{2/n}}.
$$

With balanced groups the pooled standard deviation is the common $s$ and the
standard error of the difference is $s\sqrt{2/n}$.

</details>

**Exercise 3 (code).** Implement the two-sided $z$-test of Exercise 1 in numpy,
computing the $p$-value with an erf-based normal CDF (no scipy). Confirm the
$z$-statistic is $2$ and the $p$-value is about $0.0455$.

<details>
<summary>Solution</summary>

```python
import numpy as np
from math import erf, sqrt

def norm_cdf(z):
    # Standard normal CDF via the error function.
    return 0.5 * (1.0 + erf(z / sqrt(2.0)))

xbar, mu0, sigma, n = 52.0, 50.0, 8.0, 64
z = (xbar - mu0) / (sigma / np.sqrt(n))
p = 2.0 * (1.0 - norm_cdf(abs(z)))   # two-sided

print("z:", round(z, 4), " p:", round(p, 4))
assert np.isclose(z, 2.0)
assert np.isclose(p, 0.0455, atol=1e-3)
```

The statistic is $z = 2$ and the two-sided $p$-value is $0.0455$, below
$\alpha = 0.05$, so the null is rejected.

</details>
