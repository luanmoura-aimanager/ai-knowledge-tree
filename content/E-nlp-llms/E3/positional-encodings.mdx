Attention is **permutation-equivariant**: if you shuffle the input tokens, the output is
shuffled by the same permutation. The model has no intrinsic notion of "this token comes
before that one." Yet order is fundamental to language -- "dog bites man" and "man bites
dog" must have different meanings.

Positional encodings inject order information into the representations.

## Sinusoidal absolute encodings (Vaswani et al., 2017)

Add a fixed, deterministic vector $\mathbf{p}_t$ to each token embedding at position $t$<FN n="1" />:

$$
PE(t, 2i)   = \sin\!\left(\frac{t}{10000^{2i/d}}\right), \quad
PE(t, 2i+1) = \cos\!\left(\frac{t}{10000^{2i/d}}\right),
$$

for feature index $i = 0, 1, \dots, d/2 - 1$.

**Why this form?**
- Different frequencies mean positions are distinguishable.
- Linearity: $\mathbf{p}_{t+k}$ can be written as a linear function of $\mathbf{p}_t$
  for any offset $k$ (rotation in 2D planes). The model can potentially learn to attend
  based on relative offset, the idea made explicit by encoding relative positions directly
  in the attention scores<FN n="2" />.
- Unbounded: can generate encodings for any sequence length.

**Limitation:** position information is added to the embedding, not the attention scores.
As sequences grow beyond the training length, the embeddings become out-of-distribution.

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')

def sinusoidal_pe(T, d):
    """Returns (T, d) sinusoidal positional encoding matrix. d must be even."""
    assert d % 2 == 0, "d must be even for sinusoidal PE"
    pe = np.zeros((T, d))
    pos = np.arange(T)[:, None]          # (T, 1)
    dim = np.arange(0, d, 2)[None, :]   # (1, d/2)
    angles = pos / 10000 ** (dim / d)   # (T, d/2)
    pe[:, 0::2] = np.sin(angles)        # (T, d/2) -> even columns
    pe[:, 1::2] = np.cos(angles)        # (T, d/2) -> odd columns
    return pe

pe = sinusoidal_pe(T=64, d=128)
print("PE shape:", pe.shape)
print("PE[0, :4]:", pe[0, :4].round(4))
print("PE[1, :4]:", pe[1, :4].round(4))
# Verify: columns 0,1 are sin/cos of position / 1.0 = position
# columns d-2,d-1 are nearly constant (very long wavelength)
```

## Rotary Position Encoding (RoPE)

RoPE (Su et al., 2022; used by LLaMA, Mistral, Qwen) encodes position in the **attention
score** rather than the embedding<FN n="3" />. The key insight: rotate the query and key vectors by
an angle proportional to their position, so that the attention score between positions
$t$ and $s$ depends only on the **relative offset** $t - s$.

For a 2D slice of query $\mathbf{q}$ at position $t$:

$$
\mathbf{q}_t^{(i)} \leftarrow \begin{pmatrix} q_{2i} \cos(t \theta_i) - q_{2i+1} \sin(t \theta_i) \\ q_{2i} \sin(t \theta_i) + q_{2i+1} \cos(t \theta_i) \end{pmatrix}, \quad \theta_i = 10000^{-2i/d}.
$$

Apply the same rotation to keys with angle $s \theta_i$. The dot product
$\mathbf{q}_t \cdot \mathbf{k}_s$ then equals the dot product of the unrotated vectors
premultiplied by a rotation of angle $(t - s)\theta_i$ -- a function of the relative offset only.

**Key properties:**
- Relative position: attention scores depend on $t - s$, not on $t$ and $s$ independently.
- Extrapolation: works well at lengths somewhat beyond training (unlike sinusoidal absolute).
- Zero overhead: applied to Q and K before attention, not to the residual stream.

```python
def apply_rope(x, positions):
    """x: (T, d), positions: (T,). Returns RoPE-rotated x."""
    T, d = x.shape
    assert d % 2 == 0
    half = d // 2
    thetas = 10000 ** (-2 * np.arange(half) / d)      # (half,)
    angles = positions[:, None] * thetas[None, :]     # (T, half)
    cos_a, sin_a = np.cos(angles), np.sin(angles)

    x_even = x[:, 0::2]   # (T, half)
    x_odd  = x[:, 1::2]

    x_rotated = np.empty_like(x)
    x_rotated[:, 0::2] = x_even * cos_a - x_odd * sin_a
    x_rotated[:, 1::2] = x_even * sin_a + x_odd * cos_a
    return x_rotated

T, d = 8, 16
Q = np.random.randn(T, d)
Q_rope = apply_rope(Q, positions=np.arange(T))
print("RoPE output shape:", Q_rope.shape)
```

## ALiBi: Attention with Linear Biases

ALiBi (Press et al., 2022; used by MPT, BLOOM) adds a **fixed linear bias** to the
pre-softmax attention scores, proportional to the distance between positions:

$$
\text{score}_{tj} \leftarrow \text{score}_{tj} - m_i \cdot |t - j|,
$$

where $m_i$ is a head-specific slope (a geometric sequence across heads, not learned).

**Key properties:**
- No modification to embeddings or projections.
- Distance penalty grows linearly, so distant tokens are explicitly penalized.
- Excellent length extrapolation: models trained on length 2048 often maintain performance
  at 4096+ without any fine-tuning. The linear penalty is monotonically stronger for
  larger offsets, which is a natural inductive bias.

```python
def alibi_bias(T, n_heads):
    """Returns (n_heads, T, T) ALiBi bias matrix."""
    # Slopes: geometric sequence 2^{-8/h}, 2^{-16/h}, ...
    slopes = 2 ** (-8 * np.arange(1, n_heads + 1) / n_heads)   # (h,)
    # Relative distances: |t - j| for each (t, j) pair
    distances = np.abs(np.arange(T)[:, None] - np.arange(T)[None, :])  # (T, T)
    # bias: (h, T, T)
    return -slopes[:, None, None] * distances[None, :, :]

bias = alibi_bias(T=8, n_heads=4)
print("ALiBi bias[0]:\n", bias[0].round(3))  # head 0: steepest penalty
```

## Comparison

| Method | Position in | Relative? | Extrapolates? | Used by |
|--------|------------|-----------|--------------|---------|
| Sinusoidal | Embeddings | No | Poorly | Original Transformer |
| Learned absolute | Embeddings | No | No | BERT, GPT-2 |
| RoPE | Attention scores | Yes | Somewhat | LLaMA, Mistral, Qwen |
| ALiBi | Attention scores | Yes | Well | BLOOM, MPT |

Modern LLMs (LLaMA 3, Qwen, Mistral) universally use RoPE. ALiBi is preferred when
extrapolation is a hard requirement without fine-tuning.
