The MLE bigram assigns probability zero to any pair never seen in training. One unseen bigram
in a test sentence collapses the entire sentence probability to zero and the perplexity to
$+\infty$. **Smoothing** redistributes a portion of the probability mass from seen n-grams
to unseen ones, so that every grammatical sentence receives a positive score<FN ns="2, 3" />.

## Laplace add-one smoothing

The simplest fix: pretend each n-gram was seen one extra time.

$$
\hat{p}_{\text{add-1}}(b \mid a) = \frac{c(a, b) + 1}{c(a) + V},
$$

where $V$ is the vocabulary size (the $+V$ in the denominator ensures each row still sums to 1).

Every unseen bigram now gets probability $1 / (c(a) + V)$. The cost is heavy over-assignment:
for a rare context $a$ with $c(a) = 2$ and $V = 50{,}000$, the pseudocount of 1 inflates the mass
on unseen events to $50{,}000 / 50{,}002 \approx 99.9\%$ of the row's probability.

Add-one is useful as a pedagogical baseline but too aggressive for any practical use.

## Discounting and redistribution

A better approach: reduce the counts of seen events by a small amount $d$, and pool the
recovered mass into a "leftover" budget distributed to unseen events. This is the principle
behind all practical smoothing methods.

Define the **discounted count** $c^*(a, b) = c(a, b) - d$ for some $0 < d < 1$. The discounted
probability is:

$$
\hat{p}_{\text{disc}}(b \mid a) = \frac{c^*(a, b)}{c(a)} \quad \text{for } c(a,b) > 0.
$$

The total mass removed from row $a$ is:

$$
\lambda(a) = 1 - \sum_{b: c(a,b)>0} \hat{p}_{\text{disc}}(b \mid a) = \frac{d \cdot N_1(a)}{c(a)},
$$

where $N_1(a)$ is the number of distinct words $b$ with $c(a,b) \ge 1$. This leftover mass
$\lambda(a)$ is redistributed to unseen bigrams by a **back-off** distribution.

## Kneser-Ney smoothing

Kneser-Ney (KN) is the best-performing classical smoother; it was the standard for over a decade<FN n="1" />.
The key innovation is the back-off distribution $p_{\text{KN}}(b)$: instead of using the unigram
frequency of $b$, use the **continuation probability**, the number of distinct contexts in which
$b$ appears.

$$
p_{\text{KN}}(b) = \frac{|\{a : c(a,b) > 0\}|}{|\{(a,b) : c(a,b) > 0\}|}.
$$

Words like "York" have high unigram frequency but only appear after "New", so their continuation
count is low. Words like "the" appear in many different contexts, so their continuation count is
high. The continuation probability is a much better estimate of "how useful is $b$ as a completion
when we have never seen the context."

The full interpolated KN bigram:

$$
\hat{p}_{\text{KN}}(b \mid a) = \frac{\max(c(a,b) - d, 0)}{c(a)} + \lambda(a)\, p_{\text{KN}}(b).
$$

For higher-order n-grams, the interpolation recurses: the trigram backs off to the KN bigram,
which backs off to the KN unigram.

## Back-off vs interpolation

Two redistribution strategies:

**Back-off (Katz 1987):** use the discounted n-gram probability when the count is nonzero; fall
back to the $(n-1)$-gram otherwise, weighted by a normalizing factor.

**Interpolation:** always take a weighted sum of all orders $1, \dots, n$, regardless of whether
the n-gram was seen. Interpolation consistently outperforms pure back-off; KN uses interpolation.

## Implementing Laplace and measuring perplexity

```python
import numpy as np
from collections import Counter, defaultdict

corpus = [
    ["<bos>", "I", "am", "Sam", "<eos>"],
    ["<bos>", "Sam", "I", "am", "<eos>"],
    ["<bos>", "I", "do", "not", "like", "green", "eggs", "<eos>"],
]
unigrams = Counter(w for sent in corpus for w in sent)
bigrams  = Counter((a, b) for sent in corpus for a, b in zip(sent, sent[1:]))
V = len(unigrams)

def p_mle(a, b):
    return bigrams[(a, b)] / unigrams[a] if unigrams[a] else 0.0

def p_add1(a, b):
    return (bigrams[(a, b)] + 1) / (unigrams[a] + V)

def perplexity(model_p, test_sentences):
    log_prob, n = 0.0, 0
    for sent in test_sentences:
        for a, b in zip(sent, sent[1:]):
            log_prob += np.log(model_p(a, b) + 1e-300)
            n += 1
    return np.exp(-log_prob / n)

test = [
    ["<bos>", "I", "like", "ham", "<eos>"],   # contains unseen "I like"
    ["<bos>", "Sam", "I", "am", "<eos>"],
]

print(f"MLE perplexity:   {perplexity(p_mle,  test):.1f}")   # inf due to "I like"
print(f"Add-1 perplexity: {perplexity(p_add1, test):.1f}")   # finite
```

The MLE model returns $+\infty$ because "I like" was unseen. Add-one fixes this at the cost
of significant probability distortion: each seen bigram has its probability shrunk to allocate
mass to the vast space of unseen events.

## What smoothing cannot fix

No smoothing method overcomes the **fixed-range** structural limit. Redistributing mass among
unseen bigrams says nothing about *which* unseen bigrams are more likely; that requires
generalizing through the geometry of word representations, which is exactly what embedding-based
neural models provide.

## Exercises

**Exercise 1.** A context $a$ has $c(a) = 4$ and a vocabulary of $V = 6$. The only bigram seen with this context is $(a, b)$ with $c(a, b) = 4$. Compute $\hat{p}_{\text{add-1}}(b \mid a)$ and $\hat{p}_{\text{add-1}}(b' \mid a)$ for any unseen $b'$, and check that the row sums to 1.

<details>
<summary>Solution</summary>

**Step 1.** Apply the add-one formula $\hat{p}_{\text{add-1}}(b \mid a) = \frac{c(a,b) + 1}{c(a) + V}$ to the seen pair:

$$
\hat{p}_{\text{add-1}}(b \mid a) = \frac{4 + 1}{4 + 6} = \frac{5}{10} = 0.5.
$$

**Step 2.** For any of the $V - 1 = 5$ unseen next-tokens $b'$, $c(a, b') = 0$:

$$
\hat{p}_{\text{add-1}}(b' \mid a) = \frac{0 + 1}{4 + 6} = \frac{1}{10} = 0.1.
$$

**Step 3.** Sum over the whole vocabulary: one seen token at $0.5$ plus five unseen at $0.1$:

$$
0.5 + 5 \cdot 0.1 = 0.5 + 0.5 = 1.
$$

The row normalizes. Note the distortion: the MLE gave $b$ probability $4/4 = 1$, but add-one shrinks it to $0.5$ to fund the unseen mass, even though $b$ was the only thing ever observed here.

</details>

**Exercise 2.** Kneser-Ney replaces the unigram back-off with the continuation probability $p_{\text{KN}}(b) \propto |\{a : c(a, b) > 0\}|$. Take a corpus where "York" appears 100 times but always after "New", and "city" appears 40 times after 12 distinct words. Which word has the larger continuation probability, and why is that the behavior KN wants?

<details>
<summary>Solution</summary>

**Step 1.** Continuation probability counts *distinct preceding contexts*, not raw frequency. "York" appears in exactly one context ("New"), so its continuation count is $|\{a : c(a, \text{York}) > 0\}| = 1$.

**Step 2.** "city" appears after 12 distinct words, so its continuation count is $12$.

**Step 3.** The unnormalized continuation scores are $1$ for "York" and $12$ for "city", so "city" has the larger continuation probability despite "York" having higher raw frequency ($100$ versus $40$).

**Step 4.** This is the behavior KN wants. When the model backs off because a context was never seen, the question is "how plausible is this word as a generic continuation?" "York" is frequent only because of one fixed collocation; outside "New", seeing "York" is unlikely. "city" genuinely follows many words, so it is a safer back-off bet. Penalizing words trapped in a single collocation is the central KN idea.

</details>

**Exercise 3 (code).** On the toy corpus, build add-one and MLE bigram models. Verify that the MLE assigns probability 0 to the unseen bigram ("I", "like") while add-one assigns it a positive probability, and that the add-one row for context "I" still sums to 1.

<details>
<summary>Solution</summary>

```python
import numpy as np
from collections import Counter

corpus = [
    ["<bos>", "I", "am", "Sam", "<eos>"],
    ["<bos>", "Sam", "I", "am", "<eos>"],
    ["<bos>", "I", "do", "not", "like", "green", "eggs", "<eos>"],
]
unigrams = Counter(w for sent in corpus for w in sent)
bigrams = Counter((a, b) for sent in corpus for a, b in zip(sent, sent[1:]))
V = len(unigrams)
vocab = list(unigrams)

def p_mle(a, b):
    return bigrams[(a, b)] / unigrams[a] if unigrams[a] else 0.0

def p_add1(a, b):
    return (bigrams[(a, b)] + 1) / (unigrams[a] + V)

# "I like" never occurs in training
assert p_mle("I", "like") == 0.0
assert p_add1("I", "like") > 0.0

# Add-one row for context "I" sums to 1 over the full vocabulary
row_sum = sum(p_add1("I", w) for w in vocab)
assert np.isclose(row_sum, 1.0)
print("p_mle(I->like) =", p_mle("I", "like"),
      " p_add1(I->like) =", round(p_add1("I", "like"), 4),
      " row sum =", round(row_sum, 4))
```

The MLE gives the unseen bigram exactly 0; add-one lifts it to $1 / (c(\text{I}) + V)$ and the smoothed row still normalizes over the whole vocabulary.

</details>
