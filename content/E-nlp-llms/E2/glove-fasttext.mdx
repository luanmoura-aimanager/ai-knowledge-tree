Skip-gram trains on individual (center, context) pairs sampled sequentially. The same
co-occurrence information is already summarized in the word-word **co-occurrence matrix** --
if we could fit directly to that matrix, we could exploit global statistics in one shot.
**GloVe** (Global Vectors) does exactly this.

## GloVe: global co-occurrence

### The co-occurrence matrix

Let $X_{ij}$ be the number of times word $j$ appears in the context of word $i$ (within a
window), and $X_i = \sum_j X_{ij}$. The ratio

$$
\frac{p(k \mid i)}{p(k \mid j)} = \frac{X_{ik}/X_i}{X_{jk}/X_j}
$$

encodes the relative affinity of probe word $k$ for context $i$ vs $j$. This ratio is the
key quantity: it equals approximately 1 for words equally associated with both $i$ and $j$,
very large for words specifically associated with $i$, and very small for words specifically
associated with $j$.

### Deriving the objective

We want embeddings $\mathbf{v}_i, \mathbf{u}_k$ such that some function
$F(\mathbf{v}_i, \mathbf{v}_j, \mathbf{u}_k)$ captures the co-occurrence ratio. Requiring
$F$ to be linear in the embedding differences and compatible with the ratio form forces:

$$
\mathbf{v}_i \cdot \mathbf{u}_k + b_i + b_k = \log X_{ik}.
$$

This is the **GloVe log-bilinear model**: the inner product of center and context embeddings,
plus per-word biases, should approximate the log co-occurrence count.

The **GloVe objective** is a weighted least-squares fit to this:

$$
\mathcal{L} = \sum_{i,k} f(X_{ik}) \left( \mathbf{v}_i \cdot \mathbf{u}_k + b_i + b_k - \log X_{ik} \right)^2,
$$

where the weighting function $f(X_{ik}) = \min\!\left(\!(X_{ik}/X_{\max})^{0.75},\, 1\right)$
down-weights rare pairs (which have noisier counts) and caps the weight of very frequent pairs.

```python
import numpy as np
from collections import defaultdict, Counter

# Build co-occurrence matrix from a tiny corpus
sentences = [
    "the cat sat on the mat".split(),
    "the dog sat on the floor".split(),
    "the cat and the dog are animals".split(),
    "animals live on the floor".split(),
]
vocab = list(set(w for s in sentences for w in s))
w2i = {w: i for i, w in enumerate(vocab)}
V = len(vocab)
window = 2

X = np.zeros((V, V))
for sent in sentences:
    for i, center in enumerate(sent):
        for j in range(max(0, i - window), min(len(sent), i + window + 1)):
            if j != i:
                X[w2i[center], w2i[sent[j]]] += 1

# GloVe training
d = 8
x_max = 100.0
rng = np.random.default_rng(0)
V_emb = rng.normal(0, 0.1, (V, d))
U_emb = rng.normal(0, 0.1, (V, d))
b_v   = np.zeros(V)
b_u   = np.zeros(V)
lr    = 0.05

for epoch in range(200):
    loss = 0.0
    for i in range(V):
        for k in range(V):
            if X[i, k] == 0:
                continue
            w = min((X[i, k] / x_max) ** 0.75, 1.0)
            diff = V_emb[i] @ U_emb[k] + b_v[i] + b_u[k] - np.log(X[i, k])
            loss += w * diff ** 2
            grad = 2 * w * diff
            V_emb[i] -= lr * grad * U_emb[k]
            U_emb[k] -= lr * grad * V_emb[i]
            b_v[i]   -= lr * grad
            b_u[k]   -= lr * grad
    if (epoch + 1) % 100 == 0:
        print(f"Epoch {epoch + 1}: loss = {loss:.3f}")

# Combine center and context embeddings (GloVe convention)
W = V_emb + U_emb
```

## fastText: subword embeddings

Word2vec and GloVe treat each word as an atomic unit. This breaks on:

- **Rare words**: "antidisestablishmentarianism" has very few training occurrences.
- **Morphological variants**: "play," "plays," "playing" share a root but have separate
  embeddings with no guaranteed similarity.
- **Out-of-vocabulary (OOV)**: a word not in the training vocabulary gets no embedding.

**fastText** (Bojanowski et al., 2017) represents each word as the sum of its **character
n-gram** embeddings plus its full-word embedding.

For word $w$ with character n-grams $\mathcal{G}_w$ (for $n \in [3, 6]$):

$$
\mathbf{v}_w = \mathbf{v}_{[w]} + \sum_{g \in \mathcal{G}_w} \mathbf{z}_g,
$$

where $\mathbf{v}_{[w]}$ is the full-word embedding and $\mathbf{z}_g$ is the embedding
of n-gram $g$ (shared across all words containing that n-gram).

For example, "apple" (with $\langle$ and $\rangle$ as boundary markers) generates n-grams:
`<ap`, `app`, `ppl`, `ple`, `le>`, `<app`, `appl`, `pple`, `ple>`, `<appl`, `apple`, `pple>`,
`<apple>`, plus the whole-word special token `<apple>`.

### Key properties

**Morphology:** "play" and "playing" share n-grams `pla`, `lay`, `<pl`, etc., so their
embeddings are close by construction.

**OOV:** for a word not in the vocabulary, sum the embeddings of its character n-grams.
The resulting vector is meaningful even if the word was never seen.

**Rare words:** each character n-gram is shared across many words, so even rare words
receive informative updates from all words sharing the same substrings.

```python-static
# fastText is best used via the official library
# pip install fasttext  (or fasttext-wheel)
import fasttext

# Train on a corpus file
model = fasttext.train_unsupervised("corpus.txt", model="skipgram",
                                    dim=100, minCount=1, minn=3, maxn=6)

# Embedding of an unseen word
vec = model.get_word_vector("antidisestablishmentarianism")
print("Vector shape:", vec.shape)

# Nearest neighbors (works for OOV too)
model.get_nearest_neighbors("plays")
```

## GloVe vs word2vec vs fastText

| Property | word2vec (SGNS) | GloVe | fastText |
|----------|----------------|-------|----------|
| Training signal | Local windows | Global co-occurrence | Local windows + n-grams |
| OOV handling | None | None | Character n-grams |
| Morphology | None | None | Implicit via n-gram sharing |
| Training speed | Fast (streaming) | Slower (matrix factorization) | Fast |
| Typical use | General embeddings | General embeddings | Languages with rich morphology; OOV handling |

All three produce **static** embeddings -- one vector per word type. The next lesson
introduces RNNs, which produce a hidden state that reads the entire sequence and can be
used to build the first contextual representations.
