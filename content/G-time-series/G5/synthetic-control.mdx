One region raises its minimum wage; you want the effect on employment. No single
other region is a clean comparison: each differs in industry mix, demographics,
trend. The synthetic control method builds a comparison unit by combining many
control regions into a weighted average that matches the treated region's history.
That **synthetic** region is the counterfactual.

## The setup

There is one **treated unit** that receives the intervention at time $T_0$, and
$J$ **donor units** that never do. All are observed over a pre-period
($t \le T_0$) and a post-period ($t > T_0$). Let $Y_{1t}$ be the treated unit's
outcome and $Y_{jt}$ the donors' outcomes. The goal is to estimate what $Y_{1t}$
would have been after $T_0$ without the intervention.

## The synthetic control as a weighted donor average

The method forms the counterfactual as a weighted combination of donors<FN n="1" />:

$$
\hat{Y}_{1t}^{N} = \sum_{j=2}^{J+1} w_j\, Y_{jt},
$$

with weights constrained to be a **convex combination**:

$$
w_j \ge 0, \qquad \sum_j w_j = 1.
$$

The weights are chosen to make the synthetic unit track the treated unit as closely
as possible over the **pre-treatment** period:

$$
\mathbf{w}^\star = \arg\min_{\mathbf{w}} \sum_{t \le T_0} \Big(Y_{1t} - \sum_j w_j Y_{jt}\Big)^2 \quad \text{s.t. } w_j \ge 0,\; \textstyle\sum_j w_j = 1.
$$

This is a constrained least-squares problem (the least-squares lesson, with
simplex constraints). The treatment effect is then the post-period gap between the
treated unit and its synthetic counterpart:

$$
\hat{\phi}_t = Y_{1t} - \hat{Y}_{1t}^{N}, \qquad t > T_0.
$$

## Why the constraints matter

The non-negativity and sum-to-one constraints are the heart of the method, and
distinguish it from an ordinary regression counterfactual:

- **No extrapolation.** A convex combination stays within the range of the donor
  outcomes, so the synthetic unit is always an interpolation of real units, never
  an extrapolation beyond observed data. Unconstrained regression can place huge
  positive and negative weights that fit the pre-period perfectly but extrapolate
  wildly out of sample.
- **Sparsity and transparency.** The simplex constraint typically yields a sparse
  solution: only a few donors get nonzero weight, so the synthetic control is a
  named, interpretable blend ("70% region A, 30% region B").

A good pre-period fit is the credential: if the synthetic unit matches the treated
unit's pre-treatment path closely, the assumption that it continues to match
absent treatment is plausible.

## Inference by placebo

With one treated unit there is no classical standard error. Inference is done by
**placebo tests**: apply the method pretending each donor was treated, producing a
distribution of placebo gaps from units with no real effect. If the treated unit's
post-period gap is extreme relative to the placebo gaps, the effect is significant.
This is a permutation test, the same logic as the resampling lessons<FN n="2" />.

Synthetic control and CausalImpact answer the same counterfactual question with
different machinery: CausalImpact fits a Bayesian regression on controls, synthetic
control fits constrained weights on donor units. Both shine when a single unit is
treated and a pool of comparison series exists.

```python
import numpy as np

rng = np.random.default_rng(0)
n, T0, J = 120, 80, 6

# Donor units: distinct trend slopes and seasonal phases so the weights are
# identifiable.  Treated = blend of two donors + effect.
t = np.arange(n)
donors = np.stack([
    (5 + 0.02*j*t) + 3*np.sin(2*np.pi*(t/12 + j/J)) + np.cumsum(rng.normal(0,0.1,n))
    for j in range(J)
])
true_w = np.array([0.6, 0.4, 0, 0, 0, 0])
effect = np.where(t >= T0, 4.0, 0.0)
treated = true_w @ donors + effect + rng.normal(0, 0.3, n)

# Solve constrained least squares on the simplex via projected gradient descent (pre-period).
D = donors[:, :T0].T          # T0 x J
y = treated[:T0]
w = np.full(J, 1.0/J)
lr = 1.0 / np.linalg.norm(D, 2)**2            # step size from the Lipschitz constant
for _ in range(20000):
    grad = D.T @ (D @ w - y)
    w -= lr * grad
    w = np.maximum(w, 0)                          # project onto non-negative orthant
    w /= w.sum()                                   # ... and onto the simplex

synth = w @ donors
pre_rmse = np.sqrt(((treated[:T0] - synth[:T0])**2).mean())
post_gap = (treated[T0:] - synth[T0:]).mean()
print("recovered weights:", np.round(w, 2), " (true [0.6,0.4,0,...])")
print(f"pre-period fit RMSE: {pre_rmse:.2f}  (small => credible counterfactual)")
print(f"avg post-period gap (estimated effect): {post_gap:.2f}  (true 4.0)")
```

The constrained fit concentrates weight on the two donors that actually compose the
treated unit, matches the pre-period closely, and recovers the injected
post-treatment effect of 4, the synthetic-control estimate from a convex blend of
real units.

## Exercises

**Exercise 1.** Two donors have pre-period outcomes $Y_{A} = (2, 4)$ and
$Y_{B} = (6, 8)$ at two pre-period times; the treated unit is $Y_1 = (3, 5)$. With
convex weights $\mathbf{w} = (w, 1-w)$, find the $w$ that minimizes the pre-period
sum of squared errors, and report the resulting synthetic control.

<details>
<summary>Solution</summary>

**Step 1.** The synthetic outcome at each time is
$\hat{Y}_t = w Y_{A,t} + (1-w) Y_{B,t}$:

$$
\hat{Y}_1 = 2w + 6(1-w) = 6 - 4w, \qquad \hat{Y}_2 = 4w + 8(1-w) = 8 - 4w.
$$

**Step 2.** The squared error is

$$
f(w) = (3 - (6 - 4w))^2 + (5 - (8 - 4w))^2 = (4w - 3)^2 + (4w - 3)^2 = 2(4w - 3)^2.
$$

**Step 3.** Minimize: $f$ is smallest when $4w - 3 = 0$, so $w = 3/4$, which lies
inside $[0, 1]$ and respects the simplex. The weights are
$\mathbf{w} = (0.75, 0.25)$.

**Step 4.** The synthetic control is
$\hat{Y} = (6 - 3,\; 8 - 3) = (3, 5)$, an exact match to the treated unit's
pre-period, so the convex blend interpolates $Y_1$ perfectly here.

</details>

**Exercise 2.** Explain why the convex constraints ($w_j \ge 0$, $\sum_j w_j = 1$)
prevent the synthetic control from extrapolating, and give a two-donor example where
dropping the constraints lets unconstrained regression fit the pre-period exactly
yet produce an absurd post-period counterfactual.

<details>
<summary>Solution</summary>

**Step 1.** A convex combination is a weighted average with non-negative weights
summing to one, so at every time $\hat{Y}_{1t} = \sum_j w_j Y_{jt}$ lies between
$\min_j Y_{jt}$ and $\max_j Y_{jt}$. The synthetic unit can never exceed the range
spanned by the donors: it interpolates, never extrapolates.

**Step 2.** Drop the constraints. Let donor A be flat at $Y_A = 1$ for all $t$ and
donor B be flat at $Y_B = 1.01$ pre-period but jump to $100$ post-period. Suppose
the treated pre-period value is $5$. Unconstrained, weights like
$w_A = -399, w_B = 400$ give $-399 \cdot 1 + 400 \cdot 1.01 = 5$, a perfect
pre-period fit.

**Step 3.** Post-period those same weights give
$-399 \cdot 1 + 400 \cdot 100 = 39{,}601$, a wildly extrapolated counterfactual from
a tiny pre-period difference amplified by huge opposite-signed weights. The simplex
constraint forbids the $400$ and $-399$ weights, capping the counterfactual inside
$[1, 100]$ and keeping it credible.

</details>

**Exercise 3 (code).** Implement placebo inference. Treat each donor in turn as if
it were the treated unit, fit a synthetic control from the remaining donors on the
pre-period, and compare the real treated unit against the placebo distribution. Use
the ratio of the post-period gap to the pre-period RMSE as the test statistic (the
standard Abadie normalization, so a donor that fits its pre-period poorly is not
counted as a large effect), and assert the real ratio is the most extreme.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)
n, T0, J = 120, 80, 6
t = np.arange(n)
donors = np.stack([
    (5 + 0.02*j*t) + 3*np.sin(2*np.pi*(t/12 + j/J)) + np.cumsum(rng.normal(0,0.1,n))
    for j in range(J)
])
true_w = np.array([0.6, 0.4, 0, 0, 0, 0])
effect = np.where(t >= T0, 4.0, 0.0)
treated = true_w @ donors + effect + rng.normal(0, 0.3, n)

def gap_ratio(target, pool):
    D = pool[:, :T0].T
    y = target[:T0]
    w = np.full(pool.shape[0], 1.0/pool.shape[0])
    lr = 1.0 / np.linalg.norm(D, 2)**2
    for _ in range(20000):
        w -= lr * (D.T @ (D @ w - y))
        w = np.maximum(w, 0); w /= w.sum()
    synth = w @ pool
    pre_rmse = np.sqrt(((target[:T0] - synth[:T0])**2).mean())
    post_gap = abs((target[T0:] - synth[T0:]).mean())
    return post_gap / pre_rmse                 # large pre-misfit shrinks the ratio

real = gap_ratio(treated, donors)
placebo = [gap_ratio(donors[j], np.delete(donors, j, axis=0)) for j in range(J)]

assert real > max(placebo)      # treated effect is more extreme than any placebo
print(f"real ratio {real:.1f} vs max placebo {max(placebo):.1f}")
```

The real treated unit, which carries the injected effect, fits its pre-period
tightly yet diverges afterward, giving a far larger gap-to-fit ratio than any donor
pretending to be treated, so the permutation distribution places the real effect in
its extreme tail.

</details>
