ARIMA models the conditional mean and assumes the noise variance is constant.
Financial returns violate that assumption flagrantly: calm stretches are
interrupted by bursts of turbulence, and a big move today makes a big move tomorrow
likely. This is **volatility clustering**, and GARCH models it by making the
variance itself a time series.

## The stylized fact

Daily asset returns $r_t$ are close to uncorrelated: $\operatorname{Corr}(r_t, r_{t-h})$
is near zero, so the mean is essentially unpredictable. But the *squared* returns
$r_t^2$ are strongly autocorrelated. Large moves cluster in time. A model that
captures this must leave the mean roughly white while letting the conditional
variance persist.

## ARCH: variance from past shocks

Write the return as a time-varying standard deviation times a standard shock:

$$
r_t = \sigma_t z_t, \qquad z_t \sim \mathcal{N}(0, 1) \text{ i.i.d.}
$$

The **ARCH(q)** model (autoregressive conditional heteroskedasticity) makes the
conditional variance a linear function of recent squared returns<FN n="1" />:

$$
\sigma_t^2 = \omega + \alpha_1 r_{t-1}^2 + \dots + \alpha_q r_{t-q}^2,
$$

with $\omega > 0$ and $\alpha_i \ge 0$ to keep the variance positive. A large
$r_{t-1}^2$ raises $\sigma_t^2$, so the next return is drawn from a wider
distribution: clustering by construction.

## GARCH: adding variance persistence

ARCH needs many lags to capture slow-decaying volatility. **GARCH(1,1)** adds a
lag of the variance itself, giving long memory with two parameters<FN n="2" />:

$$
\sigma_t^2 = \omega + \alpha\, r_{t-1}^2 + \beta\, \sigma_{t-1}^2.
$$

The $\alpha r_{t-1}^2$ term reacts to the latest shock; the $\beta \sigma_{t-1}^2$
term carries forward yesterday's variance level. Together they make volatility
both responsive and persistent. Positivity needs $\omega > 0$, $\alpha, \beta \ge 0$.

**Unconditional variance.** Take the unconditional expectation of both sides. Since
$\mathbb{E}[r_{t-1}^2] = \mathbb{E}[\sigma_{t-1}^2] = \bar{\sigma}^2$ under
stationarity (the shock $z$ has unit variance, so $\mathbb{E}[r_t^2] = \mathbb{E}[\sigma_t^2]$),

$$
\bar{\sigma}^2 = \omega + \alpha \bar{\sigma}^2 + \beta \bar{\sigma}^2 \;\Rightarrow\; \bar{\sigma}^2 = \frac{\omega}{1 - \alpha - \beta}.
$$

This is finite and positive only when $\alpha + \beta < 1$, the **stationarity
condition**<FN n="3" />. The sum $\alpha + \beta$ measures persistence, and its grip is
clearest as a **half-life**: a deviation of $\sigma_t^2$ from $\bar{\sigma}^2$ decays
by $(\alpha+\beta)^h$ over $h$ steps, so it halves at $h = \ln(1/2)/\ln(\alpha+\beta)$.

- $\alpha + \beta = 0.95$ gives a half-life of about $13.5$ days: a volatility
  spike is mostly forgotten inside a trading month.
- $\alpha + \beta = 0.99$, the value common for daily equity returns, gives a
  half-life of about $69$ days: the same spike still echoes a full quarter later.

A change of $0.04$ in the persistence stretches the memory fivefold. When
$\alpha + \beta = 1$ the half-life is infinite and the unconditional variance
diverges, the IGARCH boundary.

## Forecasting volatility

The $h$-step variance forecast mean-reverts to $\bar{\sigma}^2$ at rate
$(\alpha+\beta)$:

$$
\mathbb{E}[\sigma_{t+h}^2] = \bar{\sigma}^2 + (\alpha + \beta)^{h-1}\big(\sigma_{t+1}^2 - \bar{\sigma}^2\big).
$$

High persistence makes the reversion slow, so a turbulent period forecasts elevated
volatility well into the future. Extensions handle asymmetry (EGARCH, GJR-GARCH),
where negative returns raise volatility more than positive ones, the leverage
effect.

Parameters are fit by maximum likelihood: with Gaussian $z_t$, the log-likelihood
sums $-\tfrac{1}{2}[\ln(2\pi\sigma_t^2) + r_t^2/\sigma_t^2]$ over $t$, recursing
$\sigma_t^2$ from the GARCH equation.

```python
import numpy as np

rng = np.random.default_rng(4)
n = 50_000
omega, alpha, beta = 0.05, 0.10, 0.85    # alpha+beta = 0.95 < 1, stationary

r = np.zeros(n); s2 = np.zeros(n)
s2[0] = omega / (1 - alpha - beta)        # start at unconditional variance
for t in range(1, n):
    s2[t] = omega + alpha*r[t-1]**2 + beta*s2[t-1]
    r[t]  = np.sqrt(s2[t]) * rng.normal()

# 1. Unconditional variance matches the closed form
print(f"sample var(r):       {r.var():.3f}")
print(f"omega/(1-a-b):       {omega/(1-alpha-beta):.3f}")

# 2. Returns are ~uncorrelated but squared returns are autocorrelated (clustering)
def acf1(x):
    x = x - x.mean()
    return (x[:-1]*x[1:]).mean() / (x*x).mean()
print(f"ACF(1) of returns:   {acf1(r):+.3f}  (near 0)")
print(f"ACF(1) of squared r: {acf1(r**2):+.3f}  (clearly positive => clustering)")
```

The sample variance matches $\omega/(1-\alpha-\beta)$, returns are nearly
uncorrelated, and squared returns show clear positive autocorrelation: the three
fingerprints of GARCH volatility clustering.

GARCH works in the time domain. The next lesson views a series in the frequency
domain, where periodicities that are invisible in the ACF stand out as spectral
peaks.
