Bagging and boosting combine many copies of the *same* learner. **Stacking**
combines *different* learners by training a **meta-learner** to weight their
predictions. With the right setup, it gives small but reliable gains over
any single model on a held-out set, and it is the standard way to win
machine-learning competitions.

## The pattern

You have $M$ base learners (logistic regression, random forest, gradient
boosting, k-NN, neural network: any mix). Train each on the training data.
For a query $x$:

$$
\hat y = g\big(f_1(x), f_2(x), \dots, f_M(x)\big),
$$

where $g$ is the **meta-learner** trained to combine the base predictions
into the final output.

The catch is **leakage**: if you train $g$ on the same data the base learners
were trained on, $g$ learns to trust the most overfitting base model. The
fix is **out-of-fold predictions**.

## Out-of-fold (OOF) construction

Use $k$-fold cross-validation to generate base-model predictions on data the
base model has not seen:

1. Split the training data into $k$ folds.
2. For each fold $i$: train each base learner on the other $k - 1$ folds,
   predict on fold $i$. Stack predictions across folds into an OOF matrix
   $\Phi \in \mathbb{R}^{n \times M}$, one column per base learner.
3. Train the meta-learner $g$ on $(\Phi, y)$.
4. For inference: retrain each base learner on the *full* training set,
   then predict with the meta-learner.

The OOF construction ensures the meta-learner sees base predictions on data
the base learners have not memorized.

## Choosing the meta-learner

A common choice: **logistic regression** (for classification) or **linear
regression** (for regression), with L2 regularization. The meta-learner is
deliberately simple to avoid over-weighting any one base model. Tree-based
meta-learners are also used but more prone to overfitting on the small
$\Phi$ matrix.

The simplest meta-learner is a **convex combination**: predict the weighted
average $\sum_m w_m f_m(x)$ with $w_m \ge 0$, $\sum_m w_m = 1$. Pick the
weights by minimizing held-out loss (a constrained least-squares problem).

## Blending

**Blending** is the lazy version of stacking: instead of $k$-fold OOF, hold
out a single validation set, train base learners on the rest, and predict on
the validation set to train the meta-learner. Cheaper but uses less data and
is more prone to overfitting on the small validation set.

## When stacking wins

- Base learners are **heterogeneous**: very different model families with
  different inductive biases. Two random forests with different
  hyperparameters contribute much less than a random forest plus a linear
  model.
- Base learners are **uncorrelated** in their errors. Check the OOF
  correlation matrix; weights on highly correlated learners cancel out.
- **Enough training data** to fit good base learners and have meaningful OOF
  predictions for the meta-learner.

## When it does not

- Single learner is already near-optimal. The marginal gain rarely justifies
  the engineering cost.
- Production constraints: stacking $M$ models means $M$ times the inference
  cost and $M$ times the deployment surface area. Often a single tuned
  gradient-boosted model is the better engineering choice.

## Check it on arrays

```python
import numpy as np

rng = np.random.default_rng(0)

# Synthetic 2-class problem
n = 600; d = 5
X = rng.normal(size=(n, d))
y = (X[:, 0] + X[:, 1]**2 - X[:, 2] * X[:, 3] > 0).astype(int)

# Two base learners with different biases:
# (1) logistic regression  (2) k-NN
def fit_logistic(X, y, n_iter=200, lr=0.1):
    X1 = np.column_stack([np.ones(len(X)), X])
    beta = np.zeros(X1.shape[1])
    for _ in range(n_iter):
        p = 1 / (1 + np.exp(-X1 @ beta))
        beta += lr * X1.T @ (y - p) / len(y)
    return beta

def logistic_predict_proba(beta, X):
    X1 = np.column_stack([np.ones(len(X)), X])
    return 1 / (1 + np.exp(-X1 @ beta))

def knn_predict_proba(X_train, y_train, X_query, k=15):
    d = np.sqrt(((X_query[:, None] - X_train[None, :])**2).sum(axis=2))
    nn = np.argsort(d, axis=1)[:, :k]
    return y_train[nn].mean(axis=1)

# 5-fold OOF
K = 5
folds = np.array_split(rng.permutation(n), K)
phi = np.zeros((n, 2))
for i, fold in enumerate(folds):
    train_idx = np.setdiff1d(np.arange(n), fold)
    beta = fit_logistic(X[train_idx], y[train_idx])
    phi[fold, 0] = logistic_predict_proba(beta, X[fold])
    phi[fold, 1] = knn_predict_proba(X[train_idx], y[train_idx], X[fold], k=15)

# Train a simple meta-learner: logistic regression on (phi, y)
beta_meta = fit_logistic(phi, y)
print(f"meta-learner coefficients: intercept={beta_meta[0]:.3f}, "
      f"w_logistic={beta_meta[1]:.3f}, w_knn={beta_meta[2]:.3f}")

# Evaluate: held-out fold accuracy from OOF
oof_pred = logistic_predict_proba(beta_meta, phi)
acc_stack = np.mean((oof_pred > 0.5) == y)
acc_logistic_alone = np.mean((phi[:, 0] > 0.5) == y)
acc_knn_alone = np.mean((phi[:, 1] > 0.5) == y)
print(f"OOF accuracy: logistic alone = {acc_logistic_alone:.3f}, "
      f"k-NN alone = {acc_knn_alone:.3f}, stacked = {acc_stack:.3f}")
```

The stacked predictor matches or beats the better single base learner; the
meta-coefficients tell you how the meta-learner weights each base model. The
next lesson covers cheap alternatives to true stacking: snapshot ensembles
and voting.
