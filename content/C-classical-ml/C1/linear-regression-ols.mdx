Linear regression is the simplest supervised learner: model a target as a linear
function of features plus noise, and fit the coefficients to minimize squared
error. The closed form falls out of the least-squares lesson, but interpreting it
as a projection is what makes the rest of the curriculum (ridge, LASSO, GLMs,
calibration) click into place.

## The model

Given $n$ examples with feature vectors $x_i \in \mathbb{R}^d$ and targets
$y_i \in \mathbb{R}$, the **linear regression model** assumes

$$
y_i = x_i^\top \beta + \varepsilon_i,
$$

where $\beta \in \mathbb{R}^d$ are the unknown coefficients and $\varepsilon_i$ is
zero-mean noise. Stacking rows, write $X \in \mathbb{R}^{n \times d}$ for the
**design matrix** and $\mathbf{y} \in \mathbb{R}^n$ for the target vector; the
model is

$$
\mathbf{y} = X\beta + \boldsymbol\varepsilon.
$$

A column of ones in $X$ absorbs the intercept, so the formulas below cover the
intercept case without extra notation.

## The OLS objective

**Ordinary least squares (OLS)** picks the coefficients that minimize the sum of
squared residuals:

$$
\hat\beta = \arg\min_\beta\; \lVert \mathbf{y} - X\beta \rVert_2^2.
$$

Squared error is convex in $\beta$ (Hessian $2X^\top X \succeq 0$), so the
minimum is wherever the gradient vanishes.

## The normal equations

Differentiating with respect to $\beta$ using matrix calculus,

$$
\nabla_\beta\, \lVert \mathbf{y} - X\beta \rVert^2 = -2 X^\top(\mathbf{y} - X\beta).
$$

Setting it to zero gives the **normal equations**

$$
X^\top X\, \hat\beta = X^\top \mathbf{y}.
$$

When $X$ has full column rank, $X^\top X$ is invertible and

$$
\hat\beta = (X^\top X)^{-1} X^\top \mathbf{y}.
$$

If columns of $X$ are collinear, $X^\top X$ is singular and the minimizer is not
unique; that is the gap ridge regression will close.

## Geometric reading: projection onto the column space

The fitted values are $\hat{\mathbf{y}} = X\hat\beta$. Substituting,

$$
\hat{\mathbf{y}} = X(X^\top X)^{-1} X^\top \mathbf{y} = P\,\mathbf{y},
$$

where $P = X(X^\top X)^{-1}X^\top$ is the **projection matrix** onto the column
space of $X$ (idempotent, $P^2 = P$, and symmetric). The residual
$\mathbf{r} = \mathbf{y} - \hat{\mathbf{y}}$ lives in the orthogonal complement:
$X^\top \mathbf{r} = 0$ (this is exactly the normal equations rewritten).

The geometric picture: $\hat{\mathbf{y}}$ is the closest point in
$\operatorname{col}(X)$ to $\mathbf{y}$, and OLS is least-squares projection. The
whole rest of the lesson chain is a refinement of this picture.

## Numerical route

Forming $X^\top X$ squares the condition number; the conditioning lesson explains
why. The numerically stable route uses the QR factorization $X = QR$:

$$
\hat\beta = R^{-1} Q^\top \mathbf{y},
$$

solved by back-substitution. Production code uses QR (numpy's `lstsq`) or the
SVD, not the explicit inverse.

## Check it on arrays

```python
import numpy as np

rng = np.random.default_rng(0)
n, d = 200, 4
X = rng.normal(size=(n, d))
X[:, 0] = 1.0                                  # intercept
beta_true = np.array([2.0, -1.5, 0.7, 0.3])
y = X @ beta_true + 0.2 * rng.normal(size=n)

# Closed form via the normal equations
beta_normal = np.linalg.solve(X.T @ X, X.T @ y)
print("normal-eq beta:", np.round(beta_normal, 4))

# Stable route: QR factorization
Q, R = np.linalg.qr(X)
beta_qr = np.linalg.solve(R, Q.T @ y)
print("QR beta:       ", np.round(beta_qr, 4))

# Reference: numpy's least-squares solver (SVD-based)
beta_lstsq, *_ = np.linalg.lstsq(X, y, rcond=None)
print("lstsq beta:    ", np.round(beta_lstsq, 4))
print("agree?", np.allclose(beta_qr, beta_lstsq))

# Residuals are orthogonal to every column of X
y_hat = X @ beta_qr
r = y - y_hat
print("X^T r (should be ~0):", np.round(X.T @ r, 6))

# Projection matrix: P y == y_hat, and P^2 == P
P = X @ np.linalg.solve(X.T @ X, X.T)
print("P y == y_hat:", np.allclose(P @ y, y_hat))
print("P^2 == P:    ", np.allclose(P @ P, P, atol=1e-10))
```

The three routes recover the same $\hat\beta$, the residual is numerically
orthogonal to every feature column, and $P$ is idempotent. The next lesson asks
where this estimator comes from probabilistically: it is the MLE under Gaussian
noise.
