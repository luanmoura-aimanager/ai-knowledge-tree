Logistic regression handles two classes. For $K > 2$ classes, the natural
generalization parameterizes one linear score per class and normalizes with the
**softmax**. Training minimizes cross-entropy, which (as the kl-cross-entropy
lesson shows) is maximum likelihood under the categorical distribution.

## The model

For an input $x \in \mathbb{R}^d$ and $K$ classes, the model has a coefficient
vector $\beta_k \in \mathbb{R}^d$ per class. The class probabilities are

$$
p_k(x) = \Pr(y = k \mid x) = \frac{\exp(x^\top \beta_k)}{\sum_{j=1}^K \exp(x^\top \beta_j)}.
$$

The denominator normalizes the scores into a probability distribution
($\sum_k p_k = 1$, every $p_k \ge 0$). This is the **softmax** of the score
vector $z = (x^\top \beta_1, \dots, x^\top \beta_K)$.

The model is **overparameterized**: adding a constant $c$ to every $\beta_k$
leaves the probabilities unchanged. A common fix is to set $\beta_K = 0$
(reduces to logistic regression when $K = 2$); production code keeps all $K$
parameter vectors and lets regularization tie down the redundancy.

## Cross-entropy loss

With one-hot true labels $\mathbf{y}_i \in \{e_1, \dots, e_K\}$, the negative
log-likelihood per example is the **cross-entropy**:

$$
-\log p_{y_i}(x_i) = -\log\frac{\exp(x_i^\top \beta_{y_i})}{\sum_j \exp(x_i^\top \beta_j)} = \log\!\sum_j\!\exp(x_i^\top \beta_j) - x_i^\top \beta_{y_i}.
$$

The log-sum-exp form is exactly the **stable softmax** of the numerical-methods
lesson; production code always shifts by the maximum before exponentiating.

## Gradient

The gradient with respect to $\beta_k$ has a clean form:

$$
\nabla_{\beta_k}\, L = \sum_i (p_k(x_i) - \mathbf{1}[y_i = k])\, x_i,
$$

the data residual between predicted probability and the true-class indicator,
weighted by features. The objective is convex (the Hessian is again of the form
$X^\top W X$ with $W$ positive semidefinite block matrix), so any local minimum
is global.

## Multi-class metrics shift

Predictions are now distributions over $K$ classes. The classification choice
is $\arg\max_k p_k$. Probability quality (calibration, log-loss) becomes the
right metric when downstream code consumes probabilities; classification
accuracy alone hides miscalibration.

## Check it on arrays

```python
import numpy as np

rng = np.random.default_rng(0)

# Synthetic 3-class problem
n_per_class, d = 200, 3
X = np.vstack([
    rng.normal(loc=[2, 0], size=(n_per_class, 2)),
    rng.normal(loc=[-2, 0], size=(n_per_class, 2)),
    rng.normal(loc=[0, 2], size=(n_per_class, 2)),
])
X = np.column_stack([np.ones(len(X)), X])              # intercept
y = np.array([0] * n_per_class + [1] * n_per_class + [2] * n_per_class)
K = 3

def softmax(Z):
    Z = Z - Z.max(axis=1, keepdims=True)              # stable shift
    e = np.exp(Z)
    return e / e.sum(axis=1, keepdims=True)

def fit(X, y, K, lr=0.5, steps=2000, lam=0.0):
    n, d = X.shape
    Y = np.eye(K)[y]                                  # one-hot
    B = np.zeros((d, K))
    for _ in range(steps):
        P = softmax(X @ B)
        grad = X.T @ (P - Y) / n + lam * B
        B -= lr * grad
    return B

B = fit(X, y, K, lr=1.0, steps=3000)

P = softmax(X @ B)
y_pred = P.argmax(axis=1)
acc = np.mean(y_pred == y)
log_loss = -np.mean(np.log(P[np.arange(len(y)), y] + 1e-12))
print(f"accuracy: {acc:.3f}")
print(f"log loss: {log_loss:.3f}")

# Sanity check: probabilities are valid
print(f"row sums (should be 1): {P.sum(axis=1)[:3]}")
print(f"all positive: {(P > 0).all()}")

# When K=2, softmax reduces to logistic on the difference of scores
B_binary = fit(X[:2 * n_per_class], y[:2 * n_per_class], K=2, lr=1.0)
diff = X[:2 * n_per_class] @ (B_binary[:, 1] - B_binary[:, 0])
p1 = 1 / (1 + np.exp(-diff))
print("softmax K=2 matches logistic:", np.allclose(p1, softmax(X[:2 * n_per_class] @ B_binary)[:, 1], atol=1e-6))
```

The classifier gets the three Gaussian blobs apart, probabilities normalize per
row, and the binary case reduces to logistic on the score difference. The next
lesson zooms out to the general framework that unifies linear, logistic, and
Poisson regression: GLMs.
