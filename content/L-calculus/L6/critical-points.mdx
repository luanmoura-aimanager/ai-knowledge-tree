Everything in this pillar was built to answer one question: where is a
function smallest? Training a model, fitting a curve, maximizing a
likelihood, all are this question about some scalar field. The strategy
is two-staged, and both stages are already paid for: the **gradient**
shortlists the candidates, and the **Hessian** interrogates them.

## The first-order condition

If $f$ has a local minimum or maximum at an interior point
$\mathbf{x}^*$ and is differentiable there, then

$$
\nabla f(\mathbf{x}^*) = \mathbf{0} .
$$

The proof is L2's Rolle argument run along every axis: each slice
function $t \mapsto f(\mathbf{x}^* + t \mathbf{e}_i)$ has an interior
extremum at $t = 0$, so each partial vanishes. Equivalently, if any
directional derivative were nonzero, walking that direction (or its
reverse) would improve $f$: not an extremum.

Points with $\nabla f = \mathbf{0}$ are **critical points**. The
condition is necessary, not sufficient: it shortlists, it does not
certify. The shortlist always contains all three species, minima,
maxima, and **saddle points** (critical points that are neither, like
the mountain pass between two peaks), so a second interrogation is
required.

**Worked example, stage one.** $f(x, y) = x^3 - 3x + y^2$. The
gradient is $\nabla f = (3x^2 - 3, \, 2y)$; setting it to zero gives
$x = \pm 1$, $y = 0$: two critical points, $(1, 0)$ and $(-1, 0)$.

## The second-derivative test

Near a critical point the linear term of the Taylor expansion (L4) is
gone, so the quadratic term *is* the local landscape:

$$
f(\mathbf{x}^* + \mathbf{h}) \approx f(\mathbf{x}^*) + \frac{1}{2} \mathbf{h}^\top H \mathbf{h} ,
$$

and the classification is the eigenvalue sign analysis from the Hessian
lesson, now with official names<FN n="1" />:

- all eigenvalues $\gt 0$ ($H$ positive definite): **local minimum**;
- all eigenvalues $\lt 0$: **local maximum**;
- both signs present: **saddle point**;
- some eigenvalue $= 0$ (and the rest one-signed): **the test is
  silent**; the quadratic term vanishes along the null direction and
  higher-order terms decide.

For $2 \times 2$ Hessians the determinant shortcut avoids computing
eigenvalues: $\det H = \lambda_1 \lambda_2$ and
$\operatorname{tr} H = \lambda_1 + \lambda_2$, so $\det H \lt 0$ means
saddle; $\det H \gt 0$ means same-signed eigenvalues, with the sign of
$f_{xx}$ (or the trace) picking min versus max; $\det H = 0$ is the
silent case.

**Worked example, stage two.** Continuing with
$H = \begin{pmatrix} 6x & 0 \\ 0 & 2 \end{pmatrix}$:

At $(1, 0)$: $H = \operatorname{diag}(6, 2)$, both positive: **local
minimum**, value $f(1,0) = -2$.

At $(-1, 0)$: $H = \operatorname{diag}(-6, 2)$, mixed: **saddle**. Along
$x$ the surface drops away; along $y$ it rises, the mountain-pass
geometry exactly.

![Contours of sin(x)sin(y) with its three critical species marked: a peak where both eigenvalues are negative, a basin where both are positive, and the pass between them where the signs mix.](/figures/L6/critical-points.svg)

The silent case is genuinely undecidable at second order:
$f = x^4 + y^4$, $g = -x^4 - y^4$, and $h = x^4 - y^4$ all have
$\nabla = \mathbf{0}$ and $H = 0$ at the origin, yet are a minimum, a
maximum, and a saddle respectively. When the quadratic lens is blank, it
is blank, and only higher derivatives (or direct inspection) answer.

## Local versus global, and the ML picture

Everything above is **local**: a certificate about a neighborhood. The
global minimum, what training actually wants, need not be at any
particular local minimum, and on a noncompact domain may not exist at
all ($f(x) = e^x$ has neither minimum nor critical point). What rescues
existence is the EVT (L1/L4): a continuous $f$ on a closed bounded set
attains its extremes, either at an interior critical point or **on the
boundary**, so the full recipe checks both lists. The named confusion of
this lesson: **"the gradient is zero" certifies a candidate, never the
champion.** Even "local minimum" requires the Hessian's testimony, and
"global" requires comparing values across all candidates.

The high-dimensional twist that matters for deep learning: with $n$
eigenvalues that each must be positive for a minimum, randomly-signed
curvature makes saddles combinatorially dominant; in large networks,
critical points with mixed signs vastly outnumber true minima, and much
of optimization's practical difficulty is saddle-escaping rather than
local-minimum trapping<FN n="2" />. The shortlist in a billion
dimensions is mostly passes, not basins.

## Check it on arrays

```python
import numpy as np

f = lambda p: p[0] ** 3 - 3 * p[0] + p[1] ** 2
grad = lambda p: np.array([3 * p[0] ** 2 - 3, 2 * p[1]])
hess = lambda p: np.array([[6 * p[0], 0.0], [0.0, 2.0]])

# Both critical points: gradient vanishes
for cp in [np.array([1.0, 0.0]), np.array([-1.0, 0.0])]:
    assert np.allclose(grad(cp), 0.0)

# Classification by eigenvalues
lam_min = np.linalg.eigvalsh(hess(np.array([1.0, 0.0])))
lam_sad = np.linalg.eigvalsh(hess(np.array([-1.0, 0.0])))
assert np.all(lam_min > 0)                       # minimum at (1, 0)
assert lam_sad[0] < 0 < lam_sad[1]               # saddle at (-1, 0)

# The minimum beats every nearby point; the saddle does not
rng = np.random.default_rng(0)
ball = rng.normal(0, 0.15, (4000, 2))
vals_min = np.array([f(np.array([1.0, 0.0]) + d) for d in ball])
vals_sad = np.array([f(np.array([-1.0, 0.0]) + d) for d in ball])
assert np.all(vals_min >= f(np.array([1.0, 0.0])) - 1e-12)
assert (vals_sad < f(np.array([-1.0, 0.0]))).any()
assert (vals_sad > f(np.array([-1.0, 0.0]))).any()
print("min value:", f(np.array([1.0, 0.0])),
      " saddle sees both higher and lower neighbors")

# Saddle dominance in high dimension: random symmetric Hessians
n, trials = 12, 2000
mins = 0
for _ in range(trials):
    A = rng.normal(size=(n, n))
    lam = np.linalg.eigvalsh((A + A.T) / 2)
    mins += np.all(lam > 0)
print(f"all-positive spectra in {trials} random 12x12 Hessians: {mins}")
assert mins < 5                                   # vanishingly rare
```

The two critical points classify as predicted, four thousand random
neighbors confirm the basin and expose the pass (the saddle has both
better and worse neighbors), and among two thousand random
12-dimensional Hessians essentially none is positive definite: in high
dimensions, a random critical point is a saddle almost surely.

## Exercises

**Exercise 1.** Find and classify all critical points of
$f(x, y) = x^3 + y^3 - 3xy$.

<details>
<summary>Solution</summary>

**Step 1 (shortlist).** $\nabla f = (3x^2 - 3y, \; 3y^2 - 3x) =
\mathbf{0}$ gives $y = x^2$ and $x = y^2$. Substituting:
$x = x^4$, so $x(x^3 - 1) = 0$: $x = 0$ or $x = 1$. Critical points:
$(0,0)$ and $(1,1)$.

**Step 2 (Hessian).**

$$
H = \begin{pmatrix} 6x & -3 \\ -3 & 6y \end{pmatrix} .
$$

**Step 3 (classify).** At $(0,0)$:
$\det H = 0 \cdot 0 - 9 = -9 \lt 0$: saddle. At $(1,1)$:
$\det H = 36 - 9 = 27 \gt 0$ and $f_{xx} = 6 \gt 0$: local minimum,
value $f(1,1) = -1$.

**Step 4 (global?).** Not global: along the line $y = 0$,
$f = x^3 \to -\infty$. A perfectly healthy local minimum in an unbounded
landscape, the local-versus-global gap on display.

</details>

**Exercise 2.** Show that
$f(x, y) = x^2 + y^4$ and $g(x, y) = x^2 + y^3$ both have a critical
point at the origin where the second-derivative test is silent, and
classify each by direct inspection.

<details>
<summary>Solution</summary>

**Step 1.** Both gradients, $(2x, 4y^3)$ and $(2x, 3y^2)$, vanish at the
origin. Both Hessians there equal
$\operatorname{diag}(2, 0)$: one positive eigenvalue, one zero, the
silent case for each.

**Step 2 ($f$).** $f = x^2 + y^4 \ge 0$ everywhere with equality only at
the origin: a genuine **local (indeed global) minimum**. The flat
$y$-direction at second order is rescued by the quartic.

**Step 3 ($g$).** Along the $y$-axis, $g(0, y) = y^3$ takes both signs
arbitrarily close to the origin: **neither min nor max** (a degenerate
saddle-like point). Identical Hessians, opposite verdicts: when the test
is silent, the quadratic model has run out of information, and only
higher-order terms (here $y^4$ versus $y^3$) decide.

</details>

**Exercise 3 (code).** The Himmelblau function
$f(x,y) = (x^2 + y - 11)^2 + (x + y^2 - 7)^2$ famously has four local
minima (all with value 0) and several other critical points. Starting
gradient descent (step $0.01$, 2000 iterations) from the four corners
$(\pm 4, \pm 4)$, show that different starts converge to *different*
minima, and verify each endpoint has near-zero gradient and
positive-definite Hessian.

<details>
<summary>Solution</summary>

```python
import numpy as np

f = lambda p: (p[0]**2 + p[1] - 11)**2 + (p[0] + p[1]**2 - 7)**2

def grad(p):
    a = p[0]**2 + p[1] - 11
    b = p[0] + p[1]**2 - 7
    return np.array([4*a*p[0] + 2*b, 2*a + 4*b*p[1]])

def hess(p):
    return np.array([[12*p[0]**2 + 4*p[1] - 42, 4*p[0] + 4*p[1]],
                     [4*p[0] + 4*p[1], 12*p[1]**2 + 4*p[0] - 26]])

ends = []
for sx in [4.0, -4.0]:
    for sy in [4.0, -4.0]:
        p = np.array([sx, sy])
        for _ in range(2000):
            p = p - 0.01 * grad(p)
        ends.append(p)
        assert np.linalg.norm(grad(p)) < 1e-6
        assert f(p) < 1e-10                       # all four minima have value 0
        assert np.all(np.linalg.eigvalsh(hess(p)) > 0)

ends = np.array(ends)
print(np.round(ends, 4))
# All four endpoints are distinct minima
from itertools import combinations
for i, j in combinations(range(4), 2):
    assert np.linalg.norm(ends[i] - ends[j]) > 0.5
```

Four starts, four different basins: each endpoint passes the full
two-stage audit (vanishing gradient, positive-definite Hessian, value
0), and no two coincide. Which minimum a descent finds is a property of
the *initialization*, not the algorithm, the simplest demonstration of
why initialization matters in nonconvex training.

</details>

The two-stage audit certifies local minima one at a time; the next
lesson identifies the class of functions, convex ones, where the audit
is unnecessary because any local minimum is automatically the global
one.
