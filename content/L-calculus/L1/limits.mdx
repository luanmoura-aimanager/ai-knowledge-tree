The derivative will be defined as a ratio evaluated where its denominator is
zero, and the integral as a sum of infinitely many infinitely small pieces.
Neither phrase means anything yet. The **limit** is the tool that makes both
precise: it describes the value a function approaches, which can exist even at
a point where the function itself has no value. All of calculus stands on this
one definition<FN n="1" />.

## The idea, numerically

Consider

$$
f(x) = \frac{\sin x}{x}.
$$

At $x = 0$ this is $0/0$, undefined. But tabulate it near $0$:

| $x$ | $\sin(x)/x$ |
|---|---|
| $0.5$ | $0.958851$ |
| $0.1$ | $0.998334$ |
| $0.01$ | $0.999983$ |
| $0.001$ | $0.99999983$ |

The same happens from the left, since the function is even. The outputs crowd
toward $1$, and nothing about the missing point at $0$ disturbs that crowding.
The claim "$f(x)$ approaches $1$ as $x$ approaches $0$" is written

$$
\lim_{x \to 0} \frac{\sin x}{x} = 1 .
$$

The confusion to name immediately: **the limit at $a$ and the value $f(a)$ are
different objects.** The limit asks what $f$ does *near* $a$, never *at* $a$.
Here $f(0)$ does not exist while the limit is $1$. The reverse mismatch also
happens: define $g(x) = 0$ for all $x$ except $g(0) = 7$. Then $g(0) = 7$ but
$\lim_{x \to 0} g(x) = 0$, because points near $0$ all output $0$. When the two
do agree, that is a special property with its own name, continuity, covered two
lessons from now.

## The epsilon-delta definition

"Approaches" is too soft to prove anything with. The fix, due to Cauchy and
Weierstrass<FN n="2" />, turns it into a guarantee about error tolerances:

$$
\lim_{x \to a} f(x) = L
$$

means: for every tolerance $\varepsilon \gt 0$ on the output, there exists a
window $\delta \gt 0$ on the input such that

$$
0 \lt \lvert x - a \rvert \lt \delta
\quad \Longrightarrow \quad
\lvert f(x) - L \rvert \lt \varepsilon .
$$

Reading it as a dialogue keeps the quantifiers straight. A skeptic names any
$\varepsilon$, however small: "get $f$ within $\varepsilon$ of $L$." You must
produce a $\delta$ such that every $x$ within $\delta$ of $a$ (except $a$
itself, that is the $0 \lt \lvert x - a \rvert$ clause) lands $f(x)$ within
$\varepsilon$ of $L$. If you can win this game for *every* $\varepsilon$, the
limit is $L$. The skeptic moves first; your $\delta$ is allowed to depend on
their $\varepsilon$.

![The epsilon-delta picture on sin(x)/x: the skeptic draws a horizontal epsilon-band around L = 1, and the delta-window around 0 keeps the entire graph inside it. The open dot marks that f(0) does not exist; the limit does not care.](/figures/L1/limits.svg)

## A verification from scratch

Claim: $\lim_{x \to 2} (3x - 1) = 5$.

**Step 1 (scratch work).** Connect the output error to the input error. The
quantity to control is

$$
\lvert f(x) - L \rvert = \lvert (3x - 1) - 5 \rvert = \lvert 3x - 6 \rvert = 3\,\lvert x - 2 \rvert .
$$

The output error is exactly three times the input error.

**Step 2 (choose delta).** To force $3 \lvert x - 2 \rvert \lt \varepsilon$,
it suffices that $\lvert x - 2 \rvert \lt \varepsilon / 3$. So choose
$\delta = \varepsilon / 3$.

**Step 3 (the proof, forwards).** Given $\varepsilon \gt 0$, set
$\delta = \varepsilon/3$. If $0 \lt \lvert x - 2 \rvert \lt \delta$, then

$$
\lvert (3x - 1) - 5 \rvert = 3 \lvert x - 2 \rvert \lt 3\delta = 3 \cdot \frac{\varepsilon}{3} = \varepsilon .
$$

Every $\varepsilon$ has been answered with a working $\delta$, so the limit is
$5$. The slope $3$ shows up as the exchange rate between input and output
tolerance; steeper functions need proportionally smaller windows, an idea that
returns as the derivative.

## One-sided limits and failure modes

Approaching from one side only gives the **one-sided limits**
$\lim_{x \to a^-} f(x)$ (from the left) and $\lim_{x \to a^+} f(x)$ (from the
right). The two-sided limit exists when both one-sided limits exist and agree.

Limits can fail to exist in three characteristic ways:

- **Disagreement.** The step function $f(x) = 0$ for $x \lt 0$, $f(x) = 1$ for
  $x \ge 0$ has left limit $0$ and right limit $1$ at the origin: no two-sided
  limit.
- **Blowup.** $1/x^2 \to \infty$ as $x \to 0$; the outputs leave every band.
  Writing $\lim = \infty$ records *how* it fails, not a value.
- **Oscillation.** $\sin(1/x)$ near $0$ swings through every value in
  $[-1, 1]$ infinitely often; the outputs never settle inside a small band
  around any candidate $L$.

## Check it on arrays

```python
import numpy as np

# Numerical limit: sin(x)/x as x -> 0, approached from both sides
h = 10.0 ** -np.arange(1, 9)                  # 0.1, 0.01, ..., 1e-8
right = np.sin(h) / h
left = np.sin(-h) / (-h)
print("from the right:", right[:4])
print("from the left :", left[:4])
assert np.allclose(right[-1], 1.0, atol=1e-12)
assert np.allclose(left[-1], 1.0, atol=1e-12)

# Epsilon-delta check for lim_{x->2} (3x - 1) = 5 with delta = eps/3
eps = 1e-4
delta = eps / 3
rng = np.random.default_rng(0)
x = 2 + rng.uniform(-delta, delta, 100_000)   # points inside the delta-window
x = x[np.abs(x - 2) > 0]                      # exclude x = a itself
assert np.all(np.abs((3 * x - 1) - 5) < eps)  # all land inside the eps-band
print("all", x.size, "sampled points satisfy the epsilon guarantee")
```

The table converges to $1$ from both sides, and every random point inside the
$\delta$-window lands inside the $\varepsilon$-band, which is the
epsilon-delta guarantee checked by brute force.

## Exercises

**Exercise 1.** Prove from the definition that
$\lim_{x \to 3} (5x + 2) = 17$: find the $\delta$ that answers an arbitrary
$\varepsilon$, and write the three-step argument.

<details>
<summary>Solution</summary>

**Step 1 (scratch).** Control the output error:

$$
\lvert (5x + 2) - 17 \rvert = \lvert 5x - 15 \rvert = 5 \, \lvert x - 3 \rvert .
$$

**Step 2 (choose).** Forcing $5 \lvert x - 3 \rvert \lt \varepsilon$ needs
$\lvert x - 3 \rvert \lt \varepsilon / 5$, so take $\delta = \varepsilon / 5$.

**Step 3 (prove).** Given $\varepsilon \gt 0$, set $\delta = \varepsilon / 5$.
If $0 \lt \lvert x - 3 \rvert \lt \delta$ then

$$
\lvert (5x + 2) - 17 \rvert = 5 \lvert x - 3 \rvert \lt 5 \cdot \frac{\varepsilon}{5} = \varepsilon .
$$

The exchange rate is the slope $5$: five times steeper than slope one, so the
input window is five times narrower than the output band.

</details>

**Exercise 2.** Let $g(x) = \dfrac{x^2 - 9}{x - 3}$. Show that
$\lim_{x \to 3} g(x) = 6$ even though $g(3)$ is undefined, and state which
property of limits makes the cancellation legitimate.

<details>
<summary>Solution</summary>

**Step 1.** Factor the numerator: $x^2 - 9 = (x - 3)(x + 3)$, so for every
$x \ne 3$,

$$
g(x) = \frac{(x-3)(x+3)}{x-3} = x + 3 .
$$

**Step 2.** The cancellation is legitimate because the limit only inspects
points with $0 \lt \lvert x - 3 \rvert$, where $x - 3 \ne 0$ and division by it
is allowed. The definition's exclusion of the point $x = a$ itself is doing
real work here.

**Step 3.** So $g$ agrees with the function $x + 3$ everywhere the limit
looks, and

$$
\lim_{x \to 3} g(x) = \lim_{x \to 3} (x + 3) = 6 .
$$

The graph of $g$ is the line $y = x + 3$ with a hole punched at $(3, 6)$; the
limit fills the hole.

</details>

**Exercise 3 (code).** For the limit $\lim_{x \to 2}(3x - 1) = 5$, compute
numerically the *largest* $\delta$ that works for each
$\varepsilon \in \lbrace 0.1, 0.01, 0.001 \rbrace$ by checking dense grids, and
verify the ratio $\delta / \varepsilon$ matches the theoretical $1/3$.

<details>
<summary>Solution</summary>

```python
import numpy as np

f = lambda x: 3 * x - 1
a, L = 2.0, 5.0

for eps in [0.1, 0.01, 0.001]:
    # Candidate deltas, descending; pick the first whose whole window works
    deltas = eps * np.linspace(1.0, 0.01, 400)
    best = None
    for d in deltas:
        x = a + np.linspace(-d, d, 2001)
        x = x[np.abs(x - a) > 0]
        if np.all(np.abs(f(x) - L) < eps):
            best = d
            break
    print(f"eps={eps}: largest working delta ~ {best:.6f}, ratio {best/eps:.3f}")
    assert np.isclose(best / eps, 1 / 3, atol=0.02)
```

Each $\varepsilon$ admits a largest workable $\delta$ of about
$\varepsilon / 3$: the slope of the line is the conversion factor between the
two tolerances, matching Step 2 of the worked verification.

</details>
