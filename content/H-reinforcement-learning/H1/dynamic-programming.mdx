The Bellman optimality equation characterizes $V^*$ but does not hand it to you:
the $\max$ makes it nonlinear, so there is no inverse to compute. The fix is to
treat the equation as a fixed point and iterate toward it. This lesson develops
the two classic **dynamic-programming** algorithms that do this when the MDP
$(P, R)$ is fully known, and proves they converge by showing the Bellman update
is a contraction<FN n="1" />.

## The Bellman operators

Bundle the right-hand side of each Bellman equation into an operator acting on a
value vector $V \in \mathbb{R}^{|\mathcal{S}|}$. The **expectation operator** for a
fixed policy $\pi$ is

$$
(T^\pi V)(s) = \sum_a \pi(a\mid s)\left[ R(s,a) + \gamma \sum_{s'} P(s'\mid s,a) V(s') \right],
$$

and the **optimality operator** is

$$
(T^* V)(s) = \max_a \left[ R(s,a) + \gamma \sum_{s'} P(s'\mid s,a) V(s') \right].
$$

With this notation the Bellman equations read $V^\pi = T^\pi V^\pi$ and
$V^* = T^* V^*$: the value functions are exactly the **fixed points** of their
operators. Iteration works because applying either operator pulls any two value
vectors closer together.

## Both operators are $\gamma$-contractions

A map $T$ is a **$\gamma$-contraction** in the max-norm
$\lVert V \rVert_\infty = \max_s |V(s)|$ if
$\lVert TU - TV \rVert_\infty \le \gamma \lVert U - V \rVert_\infty$ for all $U, V$.

**Proof for $T^*$.** Fix a state $s$. Let $a_U$ be an action attaining the max in
$(T^*U)(s)$. Then

$$
(T^*U)(s) - (T^*V)(s) \le \big[R(s,a_U) + \gamma \textstyle\sum_{s'} P(s'\mid s,a_U) U(s')\big] - \big[R(s,a_U) + \gamma \textstyle\sum_{s'} P(s'\mid s,a_U) V(s')\big],
$$

because replacing the maximizing action of $T^*V$ by the (possibly suboptimal)
$a_U$ can only lower the second bracket. The rewards cancel, leaving

$$
(T^*U)(s) - (T^*V)(s) \le \gamma \sum_{s'} P(s'\mid s,a_U)\,\big(U(s') - V(s')\big) \le \gamma \lVert U - V\rVert_\infty,
$$

where the last step uses $\sum_{s'} P(s'\mid s, a_U) = 1$ to bound the average by
its largest term. By symmetry the same bound holds for $(T^*V)(s) - (T^*U)(s)$,
so $|(T^*U)(s) - (T^*V)(s)| \le \gamma \lVert U - V\rVert_\infty$ for every $s$,
which is the contraction claim. The argument for $T^\pi$ is identical with the
$\max$ replaced by the policy average.

By the **Banach fixed-point theorem**, a $\gamma$-contraction on a complete space
has a unique fixed point, and iterating it from any start converges to that fixed
point geometrically. That gives both algorithms at once<FN n="2" />.

## Value iteration

**Value iteration** just iterates the optimality operator:

$$
V_{k+1} = T^* V_k, \qquad V_0 \text{ arbitrary}.
$$

Contraction gives $\lVert V_{k} - V^* \rVert_\infty \le \gamma^k \lVert V_0 - V^*\rVert_\infty$,
so the error shrinks by a factor $\gamma$ each sweep. Stop when the change
$\lVert V_{k+1} - V_k\rVert_\infty$ falls below a tolerance, then read off the
greedy policy $\pi(s) = \arg\max_a [R(s,a) + \gamma \sum_{s'} P(s'\mid s,a) V_k(s')]$.

That geometric rate sets how many sweeps a target accuracy costs, and it depends
sharply on $\gamma$. To cut the initial error by $10^{-3}$:

- At $\gamma = 0.9$, each sweep multiplies the error by $0.9$, and $0.9^{66}
  \approx 10^{-3}$, so about $66$ sweeps suffice.
- At $\gamma = 0.99$, each sweep multiplies by $0.99$, and reaching $10^{-3}$ takes
  about $688$ sweeps, roughly ten times as many.

The same decimal place that buys a tenfold-deeper horizon (from the MDP lesson)
costs a tenfold-longer convergence, the practical tax of planning far ahead.

## Policy iteration

**Policy iteration** alternates two steps until the policy stops changing:

1. **Policy evaluation.** Solve $V^\pi = T^\pi V^\pi$ for the current $\pi$,
   either by the matrix inverse $(I - \gamma P^\pi)^{-1} r^\pi$ or by iterating
   $T^\pi$ to its fixed point.
2. **Policy improvement.** Set the new policy greedy with respect to $V^\pi$:
   $\pi'(s) = \arg\max_a [R(s,a) + \gamma \sum_{s'} P(s'\mid s,a) V^\pi(s')]$.

**Why improvement helps: the policy improvement theorem.** By construction the
greedy action is at least as good as $\pi$'s own action at every state, so
$Q^\pi(s, \pi'(s)) \ge V^\pi(s)$. Expanding $V^\pi(s) \le Q^\pi(s,\pi'(s))$ and
repeatedly substituting this inequality (each step replaces $V^\pi$ on the right by
a $Q^\pi$ that follows $\pi'$ one more step) telescopes to $V^{\pi'}(s) \ge V^\pi(s)$
for all $s$. Each improvement step produces a policy at least as good, and since
there are finitely many deterministic policies, the process reaches one that is
its own greedy policy, which satisfies the Bellman optimality equation and is
therefore optimal.

The two algorithms trade off the same total work differently: value iteration
does one cheap $\max$-sweep per iteration but needs many; policy iteration does an
expensive full evaluation per iteration but converges in very few.

## Worked check: both converge to the same $V^*$

Build a known random MDP, run value iteration and policy iteration, and confirm
both reach the same optimal value vector, that the value-iteration error decays
like $\gamma^k$, and that the final value satisfies the optimality equation.

```python
import numpy as np

rng = np.random.default_rng(2)
nS, nA = 5, 3
gamma = 0.9
P = rng.dirichlet(np.ones(nS), size=(nS, nA))   # P[s,a] -> dist over s'
R = rng.normal(size=(nS, nA))

def greedy_values(V):
    # Q[s,a] = R[s,a] + gamma * sum_s' P[s,a,s'] V[s']
    return R + gamma * np.einsum("sap,p->sa", P, V)

# Value iteration.
V = np.zeros(nS)
for _ in range(1000):
    V_new = greedy_values(V).max(axis=1)
    if np.max(np.abs(V_new - V)) < 1e-12:
        break
    V = V_new
V_vi = V

# Policy iteration.
pi = np.zeros(nS, dtype=int)
for _ in range(100):
    # Evaluate pi exactly.
    r_pi = R[np.arange(nS), pi]
    P_pi = P[np.arange(nS), pi]
    V_pi = np.linalg.solve(np.eye(nS) - gamma * P_pi, r_pi)
    pi_new = greedy_values(V_pi).argmax(axis=1)
    if np.array_equal(pi_new, pi):
        break
    pi = pi_new

print("V from value iteration: ", np.round(V_vi, 4))
print("V from policy iteration:", np.round(V_pi, 4))
print("agree:", np.allclose(V_vi, V_pi, atol=1e-6))
print("optimality residual:", float(np.max(np.abs(V_vi - greedy_values(V_vi).max(axis=1)))))
```

The two algorithms land on the same value vector, and that vector leaves a
near-zero residual in the Bellman optimality equation, so both have found $V^*$.

## Exercises

**Exercise 1.** A deterministic two-state MDP with $\gamma = 0.5$. State $s_0$ has
two actions: "go" pays reward $2$ and moves to $s_1$; "stay" pays reward $0$ and
remains at $s_0$. State $s_1$ has one action paying reward $1$ and moving to
$s_0$. Starting from $V_0 = (0, 0)$, compute one value-iteration sweep
$V_1 = T^* V_0$ by hand, then a second sweep $V_2 = T^* V_1$.

<details>
<summary>Solution</summary>

**Step 1.** Apply $T^*$ at $s_0$, taking the max over its two actions with
$V_0 = (0,0)$:

$$
V_1(s_0) = \max\big(2 + 0.5 \cdot V_0(s_1),\ 0 + 0.5 \cdot V_0(s_0)\big) = \max(2, 0) = 2.
$$

At $s_1$ there is one action: $V_1(s_1) = 1 + 0.5 \cdot V_0(s_0) = 1$. So
$V_1 = (2, 1)$.

**Step 2.** Sweep again with $V_1 = (2, 1)$:

$$
V_2(s_0) = \max\big(2 + 0.5 \cdot 1,\ 0 + 0.5 \cdot 2\big) = \max(2.5, 1) = 2.5,
$$

and $V_2(s_1) = 1 + 0.5 \cdot 2 = 2$. So $V_2 = (2.5, 2)$. Each sweep propagates
value one step further back, and "go" stays the better action at $s_0$.

</details>

**Exercise 2.** Value iteration shrinks the error by a factor $\gamma$ per sweep.
For $\gamma = 0.95$, how many sweeps reduce the initial error
$\lVert V_0 - V^*\rVert_\infty$ by a factor of $10^{-3}$?

<details>
<summary>Solution</summary>

**Step 1.** After $k$ sweeps the error is at most $\gamma^k$ times the initial
error. Require $\gamma^k \le 10^{-3}$:

$$
0.95^k \le 10^{-3} \;\Longrightarrow\; k \ge \frac{\ln 10^{-3}}{\ln 0.95} = \frac{-6.908}{-0.0513} \approx 134.7.
$$

**Step 2.** Round up: $k = 135$ sweeps. This is the convergence tax of a high
discount; at $\gamma = 0.9$ the same target needs only about $66$ sweeps.

</details>

**Exercise 3 (code).** Build a random known MDP and confirm value iteration and
policy iteration converge to the same optimal value vector, and that this vector
leaves a near-zero residual in the Bellman optimality equation.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(8)
nS, nA, gamma = 4, 3, 0.9
P = rng.dirichlet(np.ones(nS), size=(nS, nA))      # P[s,a] over s'
R = rng.normal(size=(nS, nA))

def greedy_values(V):
    return R + gamma * np.einsum("sap,p->sa", P, V)  # Q[s,a]

V = np.zeros(nS)                                    # value iteration
for _ in range(2000):
    V_new = greedy_values(V).max(axis=1)
    if np.max(np.abs(V_new - V)) < 1e-12:
        break
    V = V_new
V_vi = V

pi = np.zeros(nS, dtype=int)                        # policy iteration
for _ in range(100):
    r_pi, P_pi = R[np.arange(nS), pi], P[np.arange(nS), pi]
    V_pi = np.linalg.solve(np.eye(nS) - gamma * P_pi, r_pi)
    pi_new = greedy_values(V_pi).argmax(axis=1)
    if np.array_equal(pi_new, pi):
        break
    pi = pi_new

assert np.allclose(V_vi, V_pi, atol=1e-6)
assert np.max(np.abs(V_vi - greedy_values(V_vi).max(axis=1))) < 1e-8
print("V*:", np.round(V_vi, 3))
```

Both algorithms reach the same vector, and that vector is its own optimality
backup, so it is $V^*$.

</details>
