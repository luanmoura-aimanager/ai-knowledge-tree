Every method so far has explored with $\varepsilon$-greedy: act randomly a fixed
fraction of the time. That is crude. The **multi-armed bandit** strips RL down to
exploration alone (one state, no transitions) so the question can be studied
cleanly: with a fixed budget of pulls, how should an agent balance trying arms it
is unsure about against pulling the arm it currently believes is best? The good
answers here, confidence bounds and posterior sampling, carry back into full RL<FN n="1" />.

## The bandit and regret

A **$K$-armed bandit** has $K$ arms, each arm $a$ paying a reward drawn from an
unknown distribution with mean $\mu_a$. At each step the agent pulls one arm and
sees its reward. There is no state and no transition, just a [degenerate
MDP](H1/mdp-formulation) with a single state.

Performance is measured by **regret**: the reward lost by not always pulling the
best arm $\mu^* = \max_a \mu_a$. After $T$ pulls of arms $a_1, \dots, a_T$,

$$
\text{Regret}(T) = T\mu^* - \sum_{t=1}^{T} \mu_{a_t} = \sum_{t=1}^{T} (\mu^* - \mu_{a_t}).
$$

The goal is **sublinear** regret: $\text{Regret}(T)/T \to 0$, meaning the agent's
average reward approaches the best arm's. A strategy with linear regret never stops
paying for its mistakes.

**Why fixed $\varepsilon$-greedy fails this bar.** Pulling a uniformly random arm
with probability $\varepsilon$ forever incurs a constant expected regret per step,
so its total regret grows *linearly*. Good strategies must explore less and less as
their estimates sharpen.

## UCB: optimism under uncertainty

The **upper confidence bound** strategy makes exploration automatic by being
optimistic. Keep the empirical mean $\hat{\mu}_a$ and pull count $n_a$. By a
concentration inequality (Hoeffding), the true mean lies below
$\hat{\mu}_a + \sqrt{2\ln t / n_a}$ with high probability, where $t$ is the total
number of pulls. UCB pulls the arm maximizing this optimistic estimate:

$$
a_t = \arg\max_a \left( \hat{\mu}_a + \sqrt{\frac{2 \ln t}{n_a}} \right).
$$

Read the two terms: $\hat{\mu}_a$ exploits, and the bonus $\sqrt{2\ln t / n_a}$
explores, large for rarely pulled arms ($n_a$ small) and slowly growing in $t$ so
neglected arms eventually get revisited. As an arm is pulled its bonus shrinks, so
exploration self-extinguishes. UCB achieves regret growing like $\ln T$, which is
sublinear and in fact optimal in its dependence on $T$<FN n="2" />.

## Thompson sampling: posterior matching

**Thompson sampling** is the Bayesian route. Keep a posterior over each arm's mean,
update it by [Bayes' rule](A2/bayes-rule) as rewards arrive, and pull each arm with
the probability that it is the best. That "probability of being best" is realized by
a single trick: **sample** one mean from each arm's posterior and pull the arm with
the largest sample.

For Bernoulli rewards the conjugate posterior is a Beta. Start each arm at
$\text{Beta}(1,1)$ (uniform); after $s_a$ successes and $f_a$ failures the posterior
is $\text{Beta}(1 + s_a,\, 1 + f_a)$. Each step:

$$
\theta_a \sim \text{Beta}(1 + s_a,\, 1 + f_a), \qquad a_t = \arg\max_a \theta_a.
$$

Arms with wide posteriors (few pulls) sometimes draw a high sample and get
explored; arms with narrow posteriors around a low mean rarely do. Exploration is
driven by posterior uncertainty and fades as posteriors concentrate. Thompson
sampling matches UCB's logarithmic regret and is often better in practice.

## Worked check: regret growth of the three strategies

Run $\varepsilon$-greedy, UCB, and Thompson sampling on a five-armed Bernoulli
bandit, averaging regret over many independent runs. Measure regret at an early
horizon and at one four times longer: $\varepsilon$-greedy should roughly triple
(growing near-linearly), while UCB and Thompson grow far less (sublinearly), with
Thompson lowest overall.

```python
import numpy as np
rng = np.random.default_rng(0)

true_p = np.array([0.1, 0.25, 0.3, 0.45, 0.8])    # arm 4 is clearly best
K, best, T, runs = len(true_p), 0.8, 3000, 80

def mean_regret(strategy):
    tot = np.zeros(T)
    for _ in range(runs):
        n = np.zeros(K); s = np.zeros(K); cum = 0.0      # pulls, successes
        for t in range(1, T + 1):
            if strategy == "eps":                        # 10% random forever
                a = rng.integers(K) if rng.random() < 0.1 else \
                    int(np.argmax(np.where(n > 0, s / np.maximum(n, 1), 1.0)))
            elif strategy == "ucb":
                a = int(np.argmin(n)) if (n == 0).any() else \
                    int(np.argmax(s / n + np.sqrt(2 * np.log(t) / n)))
            else:                                        # Thompson, Beta posteriors
                a = int(np.argmax(rng.beta(s + 1, n - s + 1)))
            r = rng.random() < true_p[a]
            n[a] += 1; s[a] += r
            cum += best - true_p[a]                      # instantaneous regret
            tot[t - 1] += cum
    return tot / runs

for strat in ["eps", "ucb", "ts"]:
    R = mean_regret(strat)
    print(f"{strat:>3}: regret t=750 -> {R[749]:5.1f}   t=3000 -> {R[2999]:5.1f}   growth x{R[2999]/R[749]:.2f}")
```

The $\varepsilon$-greedy regret grows about threefold over the four-times-longer
horizon, close to the linear growth its constant exploration forces, while UCB and
Thompson grow much more slowly and Thompson ends with the least regret by a wide
margin, the sublinear behavior the confidence bonus and posterior sampling buy.

## Exercises

**Exercise 1.** A three-armed bandit has been pulled $t = 100$ times total. The
arms have empirical means and counts $A$: $\hat{\mu} = 0.50$, $n = 80$; $B$:
$\hat{\mu} = 0.62$, $n = 15$; $C$: $\hat{\mu} = 0.70$, $n = 5$. Compute the UCB
index $\hat{\mu}_a + \sqrt{2 \ln t / n_a}$ for each arm and state which arm UCB
pulls next. Then describe what happens to the chosen arm's index after that pull,
assuming its observed reward leaves $\hat{\mu}$ unchanged.

<details>
<summary>Solution</summary>

**Step 1.** The bonus is $\sqrt{2 \ln 100 / n_a}$ with
$2 \ln 100 = 9.2103$.

**Step 2.** Arm $A$: $0.50 + \sqrt{9.2103/80} = 0.50 + \sqrt{0.11513}
= 0.50 + 0.3393 = 0.8393$.

**Step 3.** Arm $B$: $0.62 + \sqrt{9.2103/15} = 0.62 + \sqrt{0.61402}
= 0.62 + 0.7836 = 1.4036$.

**Step 4.** Arm $C$: $0.70 + \sqrt{9.2103/5} = 0.70 + \sqrt{1.84206}
= 0.70 + 1.3572 = 2.0572$.

**Step 5.** The indices are $A = 0.839$, $B = 1.404$, $C = 2.057$, so UCB pulls
arm $C$. It is the least-pulled arm, so its bonus dominates even though all three
empirical means are close. After the pull, $n_C$ rises from $5$ to $6$, $t$ from
$100$ to $101$; the bonus drops to
$\sqrt{2 \ln 101 / 6} = \sqrt{9.2302/6} = 1.2403$, shrinking arm $C$'s index
toward its mean. Each pull of an arm narrows its own confidence interval, so
exploration self-extinguishes.

</details>

**Exercise 2.** Prove that fixed $\varepsilon$-greedy (random arm with constant
probability $\varepsilon > 0$ at every step) has regret that grows at least
linearly in $T$. Then state in one line why UCB's $\ln T$ regret is sublinear.

<details>
<summary>Solution</summary>

**Step 1.** Let $\Delta_a = \mu^* - \mu_a \ge 0$ be the suboptimality gap of arm
$a$, and let $\bar{\Delta} = \frac{1}{K}\sum_a \Delta_a$ be the average gap over
all $K$ arms.

**Step 2.** On each of the $T$ steps, $\varepsilon$-greedy explores with
probability $\varepsilon$, and an exploration step picks a uniformly random arm.
The expected instantaneous regret contributed by exploration alone is at least
$\varepsilon \cdot \bar{\Delta}$, a constant independent of $t$ (the exploit step
contributes a further nonnegative regret while the means are still being
estimated).

**Step 3.** Summing over $T$ steps, expected regret is at least
$\varepsilon \bar{\Delta}\, T$, which is linear in $T$. Hence
$\text{Regret}(T)/T \ge \varepsilon \bar{\Delta} \not\to 0$: the per-step regret
never vanishes, because the exploration rate never decays.

**Step 4.** UCB achieves $\text{Regret}(T) = O(\ln T)$, so
$\text{Regret}(T)/T = O(\ln T / T) \to 0$. The average reward converges to the
best arm's mean precisely because the confidence bonus forces exploration to
taper as estimates sharpen, rather than holding it at a constant $\varepsilon$.

</details>

**Exercise 3 (code).** Implement UCB1 and a fixed-$\varepsilon$ greedy strategy
on a three-armed Bernoulli bandit, averaging cumulative regret over many runs.
Verify that at a long horizon UCB's regret is well below $\varepsilon$-greedy's,
confirming the linear-versus-logarithmic gap of Exercise 2.

<details>
<summary>Solution</summary>

```python
import numpy as np
rng = np.random.default_rng(0)

true_p = np.array([0.3, 0.5, 0.7])            # arm 2 is best
K, best, T, runs = len(true_p), 0.7, 4000, 100

def cum_regret(strategy, eps=0.2):
    total = 0.0
    for _ in range(runs):
        n = np.zeros(K); s = np.zeros(K); reg = 0.0
        for t in range(1, T + 1):
            if strategy == "ucb":
                a = int(np.argmin(n)) if (n == 0).any() else \
                    int(np.argmax(s / n + np.sqrt(2 * np.log(t) / n)))
            else:                              # eps-greedy
                mean = np.where(n > 0, s / np.maximum(n, 1), 1.0)
                a = rng.integers(K) if rng.random() < eps else int(np.argmax(mean))
            r = rng.random() < true_p[a]
            n[a] += 1; s[a] += r
            reg += best - true_p[a]            # instantaneous regret
        total += reg
    return total / runs

R_ucb = cum_regret("ucb")
R_eps = cum_regret("eps")
assert R_ucb < R_eps                          # UCB regret far below eps-greedy
assert R_ucb < 0.6 * R_eps                    # by a wide margin at T = 4000
print("UCB regret:", round(R_ucb, 1), "  eps-greedy regret:", round(R_eps, 1))
```

UCB ends with a fraction of $\varepsilon$-greedy's regret, because its bonus
stops exploring the weak arms once their confidence intervals separate, while
fixed $\varepsilon$-greedy keeps paying its constant exploration tax every step.

</details>

These strategies assume every pull gives an informative reward. In a sparse-reward
MDP the agent may wander for a long time seeing nothing, and undirected exploration
stalls. The next lesson adds **intrinsic** rewards that turn novelty itself into a
signal to explore.
