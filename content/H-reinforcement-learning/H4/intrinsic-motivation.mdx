Bandit strategies assume every action returns an informative reward. Many real
tasks are **sparse**: the agent sees reward zero for thousands of steps until it
stumbles on the goal (Montezuma's Revenge, a robot that is rewarded only on task
completion). Undirected $\varepsilon$-greedy exploration almost never reaches the
first reward, so there is nothing to learn from. **Intrinsic motivation** manufactures
a dense internal reward that pushes the agent toward novelty, so it explores
purposefully even when the environment is silent.

## Intrinsic reward

Augment the environment's **extrinsic** reward $r^e$ with an **intrinsic** bonus
$r^i$ that is large for unfamiliar states and small for familiar ones:

$$
r_t = r^e_t + \beta\, r^i_t.
$$

The agent then maximizes return as usual, but the bonus makes seeking out novel
states intrinsically valuable. Two principled ways to define "novel":

- **Count-based.** Visit a state often and it is no longer novel. The bonus
  $r^i(s) = 1/\sqrt{N(s)}$ (with $N(s)$ the visit count) is the tabular form,
  directly echoing the UCB confidence bonus $\sqrt{\ln t / n_a}$ from the last
  lesson. In large or continuous state spaces exact counts are unavailable, so
  pseudo-counts or the methods below approximate them<FN n="1" />.
- **Prediction-error.** Train a model to predict something about the next state; the
  bonus is the model's error. States the agent understands well are predicted
  accurately (low bonus); novel states surprise the model (high bonus). Curiosity
  methods use a learned forward dynamics model for this<FN n="2" />.

The hazard for forward-dynamics curiosity is the **noisy-TV problem**: inherently
unpredictable transitions (a screen of static, a random number generator) keep
prediction error high forever, so the agent fixates on noise. The next method
sidesteps it.

## Random network distillation

**Random network distillation** (RND) is a clean prediction-error bonus that avoids
the noisy-TV trap. It uses two networks over states:

- A **target** network $f^*$ with **fixed, random** weights, never trained.
- A **predictor** network $\hat{f}$, trained by gradient descent to match the
  target's output on the states the agent actually visits.

The intrinsic bonus is the predictor's error,

$$
r^i(s) = \lVert \hat{f}(s) - f^*(s) \rVert^2.
$$

On states visited often, the predictor has been trained to reproduce $f^*$, so the
error is near zero. On novel states the predictor has never been trained, so it
fails to match the random target and the error is large. Because the target is a
deterministic function of the state, environment stochasticity does not inflate the
bonus: revisiting the same novel state repeatedly drives its error down, which is
exactly what the noisy-TV problem broke. RND is what let agents finally explore
Montezuma's Revenge<FN n="3" />.

## Worked check: the bonus is high for novel states, near zero for visited ones

Implement RND in miniature: a fixed random target as a function of the state, and a
predictor trained to match it only on the states the agent has visited. Confirm the
prediction-error bonus collapses to zero on visited states while staying large on
states the predictor has never been trained on.

```python
import numpy as np
rng = np.random.default_rng(0)

# Fixed random target f*(s); a predictor f(s) distills it on visited states only.
D = 64
Wf = rng.normal(size=D) * 2.0
bf = rng.uniform(0, 2*np.pi, size=D)
def phi(s):                                   # random Fourier features of the state
    return np.cos(Wf * (s / 5.0) + bf)
a_star = rng.normal(size=D)                   # fixed random target weights
def target(s): return a_star @ phi(s)

states = np.arange(10)
visited = states[:5]                          # the agent only ever sees states 0..4
a, lr = np.zeros(D), 0.05
for _ in range(4000):
    s = rng.choice(visited)
    a += lr * (target(s) - a @ phi(s)) * phi(s)    # train predictor to match target

def bonus(s): return float((a @ phi(s) - target(s))**2)
b_visited = np.mean([bonus(s) for s in states[:5]])
b_novel   = np.mean([bonus(s) for s in states[5:]])
print("mean bonus on visited states 0-4:", round(b_visited, 4))
print("mean bonus on novel states 5-9:  ", round(b_novel, 4))
print("novelty bonus is much larger on unseen states:", b_novel > 20 * b_visited)
```

The predictor drives its error to zero on the visited states while the novel states
keep a large bonus, so an agent maximizing this intrinsic reward is pulled toward
exactly the states it has not yet explored.

## Exercises

**Exercise 1.** The count-based bonus is $r^i(s) = 1/\sqrt{N(s)}$. A gridworld
agent has visited state $X$ exactly $4$ times and state $Y$ exactly $100$ times.
Compute the intrinsic bonus for each, and the ratio. Then, with combination
weight $\beta = 0.5$ and an extrinsic reward of $r^e = 0$ at both states,
compute the total reward $r = r^e + \beta r^i$ the agent sees at each. Which
state does the bonus steer the agent toward?

<details>
<summary>Solution</summary>

**Step 1.** Bonus at $X$: $1/\sqrt{4} = 1/2 = 0.5$. Bonus at $Y$:
$1/\sqrt{100} = 1/10 = 0.1$.

**Step 2.** Ratio $r^i(X)/r^i(Y) = 0.5/0.1 = 5$. The rarely-visited state
carries five times the novelty bonus of the well-visited one.

**Step 3.** With $\beta = 0.5$ and $r^e = 0$: total at $X$ is
$0 + 0.5 \cdot 0.5 = 0.25$; total at $Y$ is $0 + 0.5 \cdot 0.1 = 0.05$.

**Step 4.** The agent sees $0.25$ at $X$ versus $0.05$ at $Y$, so maximizing
return steers it toward the less-visited state $X$. As $N(X)$ grows its bonus
decays like $1/\sqrt{N}$, eventually falling below other states' and shifting the
pull elsewhere, the self-extinguishing exploration the count bonus inherits from
the UCB $\sqrt{\ln t / n}$ form.

</details>

**Exercise 2.** The noisy-TV problem breaks forward-dynamics curiosity: a screen
of random static keeps prediction error high forever, so the agent fixates on it.
Random network distillation uses a *fixed deterministic* random target $f^*(s)$
instead. Explain precisely why this design makes the RND bonus collapse on a
repeatedly-visited noisy state, where forward-dynamics curiosity does not.

<details>
<summary>Solution</summary>

**Step 1.** Forward-dynamics curiosity predicts the *next state* from the
current state and action, and uses its prediction error as the bonus. For a
genuinely stochastic transition (static, a random number generator), the next
state is unpredictable in principle: no model can drive that error to zero,
because the target itself is random. The bonus stays high forever and the agent
fixates.

**Step 2.** RND's target $f^*(s)$ is a fixed function of the *current* state
only, with frozen random weights. It is deterministic: the same state always
maps to the same target vector. There is no stochastic next-state to predict.

**Step 3.** The predictor $\hat{f}$ is trained by gradient descent to match
$f^*$ on visited states. Revisiting the same noisy state repeatedly gives the
predictor the same input-output pair again and again, so it learns to reproduce
$f^*(s)$ and the error
$\lVert \hat{f}(s) - f^*(s) \rVert^2$ drives to zero.

**Step 4.** So environment stochasticity cannot inflate the RND bonus: the bonus
depends only on how often a state has been *seen*, not on how predictable its
dynamics are. That is what let RND explore Montezuma's Revenge where
forward-dynamics curiosity stalled on noise.

</details>

**Exercise 3 (code).** Implement count-based and RND novelty bonuses side by
side on a small discrete state space. Visit a subset of states many times, leave
the rest unvisited, and verify that both bonuses are near zero on visited states
and large on unvisited ones, and that revisiting a state monotonically lowers its
count-based bonus.

<details>
<summary>Solution</summary>

```python
import numpy as np
rng = np.random.default_rng(0)

n_states = 12
visited = np.arange(6)                          # states 0..5 get explored

# --- count-based bonus 1/sqrt(N(s)) ---
counts = np.zeros(n_states)
for _ in range(2000):
    counts[rng.choice(visited)] += 1
count_bonus = 1.0 / np.sqrt(np.maximum(counts, 1e-9))

# revisiting a state lowers its bonus monotonically
b1 = 1.0 / np.sqrt(10)
b2 = 1.0 / np.sqrt(50)
assert b2 < b1                                  # more visits -> smaller bonus

# --- RND bonus: distill a fixed random target on visited states only ---
D = 32
Wf = rng.normal(size=D); bf = rng.uniform(0, 2*np.pi, size=D)
a_star = rng.normal(size=D)
def phi(s): return np.cos(Wf * (s / 4.0) + bf)
def target(s): return a_star @ phi(s)
a, lr = np.zeros(D), 0.05
for _ in range(4000):
    s = rng.choice(visited)
    a += lr * (target(s) - a @ phi(s)) * phi(s)
def rnd_bonus(s): return float((a @ phi(s) - target(s))**2)

rnd_visited = np.mean([rnd_bonus(s) for s in range(6)])
rnd_novel   = np.mean([rnd_bonus(s) for s in range(6, 12)])
cb_visited  = count_bonus[:6].mean()
cb_novel    = count_bonus[6:].mean()

assert cb_novel > 10 * cb_visited               # count bonus large on unseen
assert rnd_novel > 10 * rnd_visited             # RND bonus large on unseen
print("count bonus  visited/novel:", round(cb_visited, 4), round(cb_novel, 4))
print("RND   bonus  visited/novel:", round(rnd_visited, 4), round(rnd_novel, 4))
```

Both novelty signals are near zero on the explored states and large on the unseen
ones, and the count bonus shrinks monotonically with visits, so an agent
maximizing either is drawn toward the states it has not yet reached.

</details>
