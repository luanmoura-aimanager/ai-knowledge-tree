Value-based methods learn $Q$ and act greedily. That has two limits: the
$\max_a Q(s,a)$ is an optimization problem when actions are continuous, and the
greedy policy is deterministic when the optimal policy is sometimes stochastic.
**Policy gradient** methods sidestep both by parameterizing the policy directly,
$\pi_\theta(a \mid s)$, and doing gradient ascent on the expected return. The only
obstacle is that the objective is an expectation over trajectories that the
parameters themselves control, so its gradient is not obvious. The policy gradient
theorem makes it computable.

## The objective and the log-derivative trick

Let a trajectory be $\tau = (s_0, a_0, s_1, a_1, \dots)$ with return $R(\tau)$, and
let $p_\theta(\tau)$ be its probability under policy $\pi_\theta$. The objective is
the expected return

$$
J(\theta) = \mathbb{E}_{\tau \sim p_\theta}[R(\tau)] = \sum_\tau p_\theta(\tau)\,R(\tau).
$$

Differentiating, the reward $R(\tau)$ does not depend on $\theta$, so

$$
\nabla_\theta J(\theta) = \sum_\tau \nabla_\theta p_\theta(\tau)\, R(\tau).
$$

This is not yet an expectation, because $\nabla_\theta p_\theta(\tau)$ is not a
probability-weighted quantity. The **log-derivative trick** fixes that using the
identity $\nabla_\theta p_\theta = p_\theta \nabla_\theta \log p_\theta$ (just the
chain rule on $\log$):

$$
\nabla_\theta J(\theta) = \sum_\tau p_\theta(\tau)\, \nabla_\theta \log p_\theta(\tau)\, R(\tau) = \mathbb{E}_{\tau \sim p_\theta}\big[ \nabla_\theta \log p_\theta(\tau)\, R(\tau) \big].
$$

Now it is an expectation, so it can be estimated by sampling trajectories. This
score-function estimator needs no model of the environment.

## Collapsing the trajectory log-probability

The trajectory probability factors into dynamics and policy terms:

$$
p_\theta(\tau) = \rho(s_0) \prod_t P(s_{t+1} \mid s_t, a_t)\, \pi_\theta(a_t \mid s_t).
$$

Taking $\log$ turns the product into a sum, and the only terms depending on
$\theta$ are the policy factors; the start distribution $\rho$ and the transitions
$P$ vanish under $\nabla_\theta$:

$$
\nabla_\theta \log p_\theta(\tau) = \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t).
$$

The unknown dynamics dropped out. Substituting back gives the **policy gradient
theorem**<FN ns="1, 2" />:

$$
\nabla_\theta J(\theta) = \mathbb{E}_{\tau}\Big[ \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, G_t \Big],
$$

where $G_t$ is the return from step $t$ (only rewards after an action can be caused
by it, so each $\nabla_\theta \log \pi_\theta(a_t\mid s_t)$ multiplies the
return-to-go $G_t$ rather than the full-episode return).

## REINFORCE

Estimating that expectation with sampled episodes and stepping uphill is the
**REINFORCE** algorithm<FN n="3" />. For each episode, compute returns-to-go $G_t$ and update

$$
\theta \leftarrow \theta + \alpha \sum_t G_t\, \nabla_\theta \log \pi_\theta(a_t \mid s_t).
$$

The update raises the log-probability of actions that led to high return and
lowers it for low return, weighted by $G_t$. It is a [stochastic-gradient](A3/sgd)
ascent on $J$.

## Baselines reduce variance for free

REINFORCE works but its gradient estimate has high variance, because $G_t$ swings
widely from episode to episode. Subtracting a **baseline** $b(s_t)$ from the return
leaves the gradient unbiased while shrinking its variance:

$$
\nabla_\theta J(\theta) = \mathbb{E}\Big[ \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\,(G_t - b(s_t)) \Big].
$$

**Why it stays unbiased.** The extra term has zero expectation, because for any
$b(s)$ not depending on the action,

$$
\mathbb{E}_{a \sim \pi_\theta}\big[\nabla_\theta \log \pi_\theta(a \mid s)\big] = \sum_a \pi_\theta(a\mid s) \frac{\nabla_\theta \pi_\theta(a\mid s)}{\pi_\theta(a\mid s)} = \nabla_\theta \sum_a \pi_\theta(a \mid s) = \nabla_\theta 1 = 0.
$$

So $\mathbb{E}[\nabla_\theta \log \pi_\theta(a\mid s)\, b(s)] = 0$ and the baseline
cannot bias the gradient. It does change the variance, and the variance-minimizing
choice is close to $b(s) = V(s)$, the expected return from $s$. Centering $G_t$
around the state's own value is the seed of actor-critic methods next lesson.

## Worked check: REINFORCE finds the best arm, the baseline cuts variance

Two claims to verify. First, REINFORCE on a three-armed bandit with a softmax
policy drives almost all probability onto the best arm. Second, at a fixed
reference policy, subtracting the expected-reward baseline lowers the gradient
estimator's second moment while leaving its mean (the true gradient) unchanged.

```python
import numpy as np
rng = np.random.default_rng(1)

true_means = np.array([0.0, 1.0, 2.0])     # arm 2 is best
K = 3
def softmax(th):
    z = th - th.max(); e = np.exp(z); return e / e.sum()

# Part A: REINFORCE (one-step episodes) learns the best arm.
th = np.zeros(K)
for _ in range(20000):
    p = softmax(th)
    a = rng.choice(K, p=p)
    r = true_means[a] + rng.normal()
    th += 0.025 * (np.eye(K)[a] - p) * r         # softmax score times reward
p_final = softmax(th)

# Part B: gradient variance at a FIXED policy, with vs without a baseline.
p_ref = np.array([0.2, 0.3, 0.5])
b_opt = true_means @ p_ref                       # baseline = expected reward
N = 200_000
g_nb = np.zeros((N, K)); g_b = np.zeros((N, K))
for i in range(N):
    a = rng.choice(K, p=p_ref)
    r = true_means[a] + rng.normal()
    score = np.eye(K)[a] - p_ref
    g_nb[i] = score * r
    g_b[i]  = score * (r - b_opt)

print("P(best arm) after REINFORCE:", round(p_final[2], 3))
print("E||grad||^2 without baseline:", round(np.mean((g_nb**2).sum(1)), 3))
print("E||grad||^2 with baseline:   ", round(np.mean((g_b**2).sum(1)), 3))
print("gradient means agree (unbiased):", np.allclose(g_nb.mean(0), g_b.mean(0), atol=0.02))
```

REINFORCE puts essentially all mass on the best arm, and the baseline lowers the
gradient's second moment while the two gradient means agree, confirming it reduces
variance without introducing bias.

## Exercises

**Exercise 1.** A softmax policy over two actions has logits $\theta = (\theta_0, \theta_1)$
and probabilities $\pi = \mathrm{softmax}(\theta)$. Derive the score
$\nabla_\theta \log \pi_\theta(a)$ for the sampled action $a$, and show it equals
$e_a - \pi$, where $e_a$ is the one-hot indicator of $a$. Evaluate it at
$\theta = (0, 0)$ for $a = 1$.

<details>
<summary>Solution</summary>

**Step 1.** Write the log-probability of action $a$:
$\log \pi_\theta(a) = \theta_a - \log \sum_k e^{\theta_k}$.

**Step 2.** Differentiate with respect to component $\theta_j$. The first term
contributes $\mathbb{1}[j = a]$. The second is the log-partition, whose derivative
is the softmax probability:

$$
\frac{\partial}{\partial \theta_j} \log \sum_k e^{\theta_k} = \frac{e^{\theta_j}}{\sum_k e^{\theta_k}} = \pi_j.
$$

**Step 3.** Combining, $\dfrac{\partial \log \pi_\theta(a)}{\partial \theta_j} = \mathbb{1}[j = a] - \pi_j$,
which stacked over $j$ is the vector $e_a - \pi$.

**Step 4.** At $\theta = (0, 0)$, $\pi = (0.5, 0.5)$, and for $a = 1$ the one-hot
is $e_1 = (0, 1)$, so the score is $(0, 1) - (0.5, 0.5) = (-0.5, 0.5)$.

This $e_a - \pi$ score is exactly the `np.eye(K)[a] - p` factor in the worked code.

</details>

**Exercise 2.** Show that adding a baseline $b(s)$ that depends on the state but
not the action leaves the policy gradient unbiased, and explain why a baseline
that depended on the action $a$ would in general bias it.

<details>
<summary>Solution</summary>

**Step 1.** The extra term added to the estimator is
$\nabla_\theta \log \pi_\theta(a \mid s)\, b(s)$. Take its expectation over
$a \sim \pi_\theta(\cdot \mid s)$ at fixed $s$:

$$
\mathbb{E}_{a}\big[\nabla_\theta \log \pi_\theta(a \mid s)\, b(s)\big] = b(s) \sum_a \pi_\theta(a \mid s)\, \nabla_\theta \log \pi_\theta(a \mid s),
$$

pulling $b(s)$ out because it does not depend on $a$.

**Step 2.** Use $\pi_\theta \nabla_\theta \log \pi_\theta = \nabla_\theta \pi_\theta$
and that probabilities sum to one:

$$
\sum_a \nabla_\theta \pi_\theta(a \mid s) = \nabla_\theta \sum_a \pi_\theta(a \mid s) = \nabla_\theta 1 = 0.
$$

So the added term has zero expectation and the gradient is unchanged.

**Step 3.** Step 1 required factoring $b(s)$ out of the sum over $a$. A baseline
$b(s, a)$ that varied with the action cannot be pulled out, so the sum no longer
collapses to $\nabla_\theta 1 = 0$; the leftover term is generally nonzero and
shifts the gradient, introducing bias. Only action-independent baselines are safe.

</details>

**Exercise 3 (code).** On the three-armed bandit, confirm two facts at a fixed
reference policy: the per-sample REINFORCE gradient is unbiased (its mean matches
the analytic policy gradient $\sum_a \pi(a)(e_a - \pi)\,\mu_a$), and subtracting
the expected-reward baseline lowers the gradient's variance.

<details>
<summary>Solution</summary>

```python
import numpy as np
rng = np.random.default_rng(1)

true_means = np.array([0.0, 1.0, 2.0])
p = np.array([0.2, 0.3, 0.5])               # fixed reference policy
K = 3

# Analytic policy gradient: E_a[ (e_a - p) * mu_a ].
scores = np.eye(K) - p                       # row a is the score e_a - p
analytic = (p[:, None] * scores * true_means[:, None]).sum(0)

b = true_means @ p                           # expected-reward baseline
N = 300_000
g_nb = np.zeros((N, K)); g_b = np.zeros((N, K))
for i in range(N):
    a = rng.choice(K, p=p)
    r = true_means[a] + rng.normal()
    score = np.eye(K)[a] - p
    g_nb[i] = score * r
    g_b[i]  = score * (r - b)

assert np.allclose(g_nb.mean(0), analytic, atol=0.02)     # unbiased
assert np.allclose(g_b.mean(0),  analytic, atol=0.02)     # still unbiased
var_nb = (g_nb ** 2).sum(1).mean()
var_b  = (g_b  ** 2).sum(1).mean()
assert var_b < var_nb                                     # baseline cuts variance
print("analytic grad:", np.round(analytic, 3))
print("E||g||^2 no baseline:", round(var_nb, 3), " with:", round(var_b, 3))
```

The sampled gradient means match the analytic policy gradient with and without the
baseline, and the second moment drops once the baseline is subtracted, the
variance reduction the math promised for free.

</details>

The baseline that best reduces variance is the state value $V(s)$, which is not
known in advance. Learning it with a second network and using it both as the
baseline and to bootstrap the return gives the actor-critic methods of the next
lesson.
