Neighborhood CF works on observed ratings, item by item<FN n="2" />. **Matrix
factorization** models the rating matrix as a product of two low-rank
factors, $R \approx U V^\top$, where each user and item gets a $k$-
dimensional latent vector. The factor model generalizes across sparse
entries, dramatically improves accuracy, and is the foundation of every
modern recommendation system<FN n="1" />.

## The model

User $u$ has embedding $\mathbf{u}_u \in \mathbb{R}^k$, item $i$ has
embedding $\mathbf{v}_i \in \mathbb{R}^k$. The predicted rating is the dot
product:

$$
\hat R_{ui} = \mathbf{u}_u^\top \mathbf{v}_i.
$$

The dot product captures matched preferences: if user and item embeddings
align in the same direction in the latent space, the predicted rating is
high. Take a 2-factor space where factor 1 is "action" and factor 2 is
"romance", and a user who loves action and dislikes romance,
$\mathbf{u}_u = (1.5, -1.0)$. The same user, scored against three items that
differ only in where they sit in that space:

- **An action film** $\mathbf{v} = (1.2, -0.8)$, pointing the same way as the
  user: $\hat R = 1.5(1.2) + (-1.0)(-0.8) = 2.6$. Strong recommendation.
- **A neutral item** $\mathbf{v} = (0.8, 1.2)$, orthogonal to the user:
  $\hat R = 1.5(0.8) + (-1.0)(1.2) = 0.0$. The two factors cancel; no signal.
- **A romance film** $\mathbf{v} = (-0.6, 1.0)$, pointing the opposite way:
  $\hat R = 1.5(-0.6) + (-1.0)(1.0) = -1.9$. Pushed to the bottom.

The user vector is fixed across all three; only the alignment of the item
vector moves the score from $+2.6$ to $-1.9$, which is the whole content of the
dot-product model.

For most production systems, add per-user and per-item bias terms (plus a
global mean) to absorb constant offsets:

$$
\hat R_{ui} = \mu + b_u + b_i + \mathbf{u}_u^\top \mathbf{v}_i.
$$

## Loss with regularization

Train on observed ratings only. Minimize

$$
L = \sum_{(u, i) \in \Omega}(R_{ui} - \hat R_{ui})^2 + \lambda\left(\sum_u \lVert\mathbf{u}_u\rVert^2 + \sum_i \lVert\mathbf{v}_i\rVert^2\right),
$$

where $\Omega$ is the set of observed entries. The L2 penalty is essential
to prevent embeddings from blowing up on sparse data.

## Alternating least squares (ALS)

The loss is non-convex jointly in $U$ and $V$, but **convex if either is
fixed**. Alternate:

**Fix $V$, solve for $U$.** Each $\mathbf{u}_u$ is independent and has a
closed-form ridge solution over the items user $u$ rated:

$$
\mathbf{u}_u = \left(\sum_{i \in I_u}\mathbf{v}_i \mathbf{v}_i^\top + \lambda I\right)^{-1}\sum_{i \in I_u} R_{ui} \mathbf{v}_i.
$$

**Fix $U$, solve for $V$** symmetrically. Iterate until convergence.

Each ALS step decreases the loss, so the algorithm converges to a local
minimum. The closed-form per-user update makes ALS embarrassingly parallel
(each user solved independently), which is what makes it scale.

## Stochastic gradient descent (SGD)

Alternative: iterate over rated $(u, i)$ pairs, computing the gradient and
updating both $\mathbf{u}_u$ and $\mathbf{v}_i$:

$$
\mathbf{u}_u \leftarrow \mathbf{u}_u + \eta\,(e_{ui} \mathbf{v}_i - \lambda \mathbf{u}_u), \quad \mathbf{v}_i \leftarrow \mathbf{v}_i + \eta\,(e_{ui} \mathbf{u}_u - \lambda \mathbf{v}_i),
$$

with $e_{ui} = R_{ui} - \hat R_{ui}$. SGD is simpler but harder to
parallelize and sensitive to learning-rate schedules. ALS dominates in
production for explicit-feedback MF.

## Connection to the SVD

When the rating matrix is **fully observed** and there is no regularization,
the optimal rank-$k$ factorization is the truncated SVD (the Eckart-Young
theorem)<FN n="1" />. MF generalizes this to sparse matrices and adds regularization.
The "SVD" in the Netflix-prize literature is actually MF with SGD, not the
classical algebraic SVD.

## Why it works on sparse data

Each user's $\mathbf{u}_u$ is fit from their ratings, but it lives in a
shared $k$-dimensional space, so ratings on one item indirectly inform
ratings on every other item. Pooling structure across users and items
gives MF its dramatic improvement over neighborhood CF in sparse regimes.

## Check it on arrays

```python
import numpy as np

rng = np.random.default_rng(0)

# Synthetic low-rank rating matrix + noise + sparsity
n_u, n_i, k_true = 80, 50, 4
U_true = rng.normal(size=(n_u, k_true))
V_true = rng.normal(size=(n_i, k_true))
R_full = U_true @ V_true.T + 0.1 * rng.normal(size=(n_u, n_i))

# Sparsify: observe ~20% of entries
mask = rng.random((n_u, n_i)) < 0.2
R_obs = R_full * mask

def als(R, mask, k=4, lam=0.1, n_iter=20):
    n_u, n_i = R.shape
    U = rng.normal(scale=0.1, size=(n_u, k))
    V = rng.normal(scale=0.1, size=(n_i, k))
    for _ in range(n_iter):
        # Update U: per-user ridge over rated items
        for u in range(n_u):
            rated = np.where(mask[u])[0]
            if len(rated) == 0: continue
            Vr = V[rated]
            A = Vr.T @ Vr + lam * np.eye(k)
            b = Vr.T @ R[u, rated]
            U[u] = np.linalg.solve(A, b)
        # Update V symmetrically
        for i in range(n_i):
            rated = np.where(mask[:, i])[0]
            if len(rated) == 0: continue
            Ur = U[rated]
            A = Ur.T @ Ur + lam * np.eye(k)
            b = Ur.T @ R[rated, i]
            V[i] = np.linalg.solve(A, b)
    return U, V

U_hat, V_hat = als(R_obs, mask, k=4, lam=0.1, n_iter=30)

# Reconstruction quality on observed and missing cells
R_hat = U_hat @ V_hat.T
err_obs = np.sqrt(np.mean((R_hat[mask] - R_full[mask])**2))
err_mis = np.sqrt(np.mean((R_hat[~mask] - R_full[~mask])**2))
print(f"observed RMSE: {err_obs:.3f}")
print(f"held-out RMSE: {err_mis:.3f}")
print(f"true ratings range: [{R_full.min():.2f}, {R_full.max():.2f}]")
```

ALS recovers the true low-rank structure from a 20% sample, with held-out
RMSE close to the noise level.

## Exercises

**Exercise 1.** A user has embedding $\mathbf{u}_u = (2, -1, 0.5)$. Three items
have embeddings $\mathbf{v}_a = (1, 0, 1)$, $\mathbf{v}_b = (0, 1, 0)$, and
$\mathbf{v}_c = (1, -1, 1)$. Compute the three predicted ratings
$\hat R_{ui} = \mathbf{u}_u^\top \mathbf{v}_i$ and rank the items for this user.

<details>
<summary>Solution</summary>

**Step 1.** The predicted rating is the dot product of the two embeddings.

**Step 2.** Compute each:

$$
\hat R_{ua} = 2(1) + (-1)(0) + 0.5(1) = 2.5,
$$
$$
\hat R_{ub} = 2(0) + (-1)(1) + 0.5(0) = -1.0,
$$
$$
\hat R_{uc} = 2(1) + (-1)(-1) + 0.5(1) = 3.5.
$$

**Step 3.** Rank by descending score: $c$ ($3.5$), then $a$ ($2.5$), then $b$
($-1.0$). Item $c$ aligns best with the user's positive first factor and
negative second factor; item $b$ loads only on the factor the user dislikes, so
it lands at the bottom.

</details>

**Exercise 2.** Derive the closed-form ALS update for a single user embedding
$\mathbf{u}_u$ with $V$ fixed. Start from the regularized squared loss restricted
to that user's rated items $I_u$ and show that the minimizer is
$\mathbf{u}_u = (\sum_{i \in I_u}\mathbf{v}_i\mathbf{v}_i^\top + \lambda I)^{-1}\sum_{i \in I_u} R_{ui}\mathbf{v}_i$.

<details>
<summary>Solution</summary>

**Step 1.** With $V$ fixed, the only terms of the loss involving $\mathbf{u}_u$
are

$$
L_u = \sum_{i \in I_u}(R_{ui} - \mathbf{u}_u^\top \mathbf{v}_i)^2 + \lambda \lVert \mathbf{u}_u\rVert^2.
$$

This is a ridge regression of the targets $R_{ui}$ on the design rows
$\mathbf{v}_i^\top$.

**Step 2.** Take the gradient with respect to $\mathbf{u}_u$. Each squared term
$(R_{ui} - \mathbf{u}_u^\top \mathbf{v}_i)^2$ differentiates to
$-2(R_{ui} - \mathbf{u}_u^\top \mathbf{v}_i)\mathbf{v}_i$, and the penalty to
$2\lambda \mathbf{u}_u$:

$$
\nabla_{\mathbf{u}_u} L_u = -2\sum_{i \in I_u}(R_{ui} - \mathbf{u}_u^\top \mathbf{v}_i)\mathbf{v}_i + 2\lambda \mathbf{u}_u.
$$

**Step 3.** Set the gradient to zero and collect $\mathbf{u}_u$. Using
$\mathbf{u}_u^\top \mathbf{v}_i = \mathbf{v}_i^\top \mathbf{u}_u$, the term
$\sum_i \mathbf{v}_i(\mathbf{v}_i^\top \mathbf{u}_u) = (\sum_i \mathbf{v}_i\mathbf{v}_i^\top)\mathbf{u}_u$:

$$
\left(\sum_{i \in I_u}\mathbf{v}_i\mathbf{v}_i^\top + \lambda I\right)\mathbf{u}_u = \sum_{i \in I_u} R_{ui}\mathbf{v}_i.
$$

**Step 4.** The matrix on the left is positive definite (the $\lambda I$ term
guarantees invertibility), so

$$
\mathbf{u}_u = \left(\sum_{i \in I_u}\mathbf{v}_i\mathbf{v}_i^\top + \lambda I\right)^{-1}\sum_{i \in I_u} R_{ui}\mathbf{v}_i.
$$

This is the per-user ridge solution the ALS step computes, independently for
each user.

</details>

**Exercise 3 (code).** Implement one ALS half-step (the $U$ update with $V$
fixed) directly and verify it matches the per-user ridge formula from Exercise 2
on a small fully observed matrix. Assert the two routes agree.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(1)

n_u, n_i, k = 5, 7, 3
R = rng.normal(size=(n_u, n_i))
V = rng.normal(size=(n_i, k))
lam = 0.2

# Route A: batched update (all items rated, so I_u = all items)
A = V.T @ V + lam * np.eye(k)
U_batched = np.linalg.solve(A, (R @ V).T).T          # (n_u, k)

# Route B: explicit per-user ridge sum from Exercise 2
U_loop = np.zeros((n_u, k))
for u in range(n_u):
    G = sum(np.outer(V[i], V[i]) for i in range(n_i)) + lam * np.eye(k)
    rhs = sum(R[u, i] * V[i] for i in range(n_i))
    U_loop[u] = np.linalg.solve(G, rhs)

assert np.allclose(U_batched, U_loop)
print("max abs difference:", np.abs(U_batched - U_loop).max())
```

The closed-form sum-of-outer-products update and the batched matrix solve
produce identical embeddings, confirming the derivation of the ALS step.

</details>
