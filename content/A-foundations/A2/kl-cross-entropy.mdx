Training a classifier means making a predicted distribution match a true one. The
gap between two distributions is measured by the **KL divergence**, and the quantity
actually minimized in practice, **cross-entropy**, differs from it only by a constant.
Minimizing cross-entropy turns out to be exactly maximum likelihood.

## Cross-entropy

The **cross-entropy** of a distribution $q$ relative to $p$ is the expected surprise
of outcomes drawn from $p$ but scored with $q$:

$$
H(p, q) = -\sum_x p(x) \log q(x) = \mathbb{E}_{x \sim p}[-\log q(x)].
$$

It is the average number of bits to encode samples from the true $p$ using a code
optimized for the model $q$. If $q = p$ it reduces to the entropy $H(p)$. Using the
wrong code costs extra bits, and that excess is the KL divergence.

## KL divergence

The **Kullback-Leibler divergence** from $p$ to $q$ is the cross-entropy minus the
entropy<FN ns="1, 2" />:

$$
D_{\mathrm{KL}}(p \,\|\, q) = H(p, q) - H(p) = \sum_x p(x)\log\frac{p(x)}{q(x)}.
$$

It is the expected log-ratio under $p$. It quantifies the penalty for modeling $p$
with $q$ instead of the truth.

## Nonnegativity (Gibbs' inequality)

**Theorem.** $D_{\mathrm{KL}}(p \,\|\, q) \ge 0$, with equality if and only if
$p = q$<FN n="3" />.

*Proof.* Write the divergence with a sign flip and apply Jensen to the concave
logarithm:

$$
-D_{\mathrm{KL}}(p \,\|\, q) = \sum_x p(x)\log\frac{q(x)}{p(x)} = \mathbb{E}_{p}\!\left[\log\frac{q(X)}{p(X)}\right] \le \log \mathbb{E}_p\!\left[\frac{q(X)}{p(X)}\right].
$$

The expectation inside is $\sum_x p(x)\frac{q(x)}{p(x)} = \sum_x q(x) = 1$, so the
bound is $\log 1 = 0$. Therefore $-D_{\mathrm{KL}} \le 0$, i.e.
$D_{\mathrm{KL}} \ge 0$. Jensen is tight only when $q(X)/p(X)$ is constant, which with
both summing to 1 forces $p = q$. $\qquad\blacksquare$

## Asymmetry

KL is **not** symmetric: $D_{\mathrm{KL}}(p \,\|\, q) \neq D_{\mathrm{KL}}(q \,\|\, p)$
in general, so it is not a distance. The two directions behave differently.
$D_{\mathrm{KL}}(p \,\|\, q)$ is "mean-seeking": it is huge where $p$ has mass but $q$
does not, so minimizing it forces $q$ to cover all of $p$'s support.
$D_{\mathrm{KL}}(q \,\|\, p)$ is "mode-seeking": it lets $q$ concentrate on one mode.
Variational inference minimizes the second; maximum likelihood, the first.

## Cross-entropy loss is maximum likelihood

For classification, $p$ is the one-hot true label and $q_\theta$ the model's
predicted class probabilities. The per-example cross-entropy is
$H(p, q_\theta) = -\log q_\theta(\text{true class})$. Averaged over a dataset,

$$
\frac{1}{n}\sum_{i=1}^n -\log q_\theta(y_i \mid x_i) = -\frac{1}{n}\,\ell(\theta),
$$

which is the negative average log-likelihood. Minimizing cross-entropy is maximizing
likelihood. Since $H(p)$ is fixed by the data, minimizing cross-entropy also
minimizes $D_{\mathrm{KL}}(p \,\|\, q_\theta)$: the model is pushed toward the true
label distribution.

## Check it on arrays

```python
import numpy as np

rng = np.random.default_rng(14)

def kl(p, q):
    p, q = np.asarray(p, float), np.asarray(q, float)
    mask = p > 0
    return np.sum(p[mask] * np.log(p[mask] / q[mask]))

def cross_entropy(p, q):
    p, q = np.asarray(p, float), np.asarray(q, float)
    mask = p > 0
    return -np.sum(p[mask] * np.log(q[mask]))

def entropy(p):
    p = np.asarray(p, float)
    mask = p > 0
    return -np.sum(p[mask] * np.log(p[mask]))

p = np.array([0.5, 0.3, 0.2])
q = np.array([0.4, 0.4, 0.2])

print("KL(p||q):", round(kl(p, q), 4), " >= 0")
print("KL(p||p):", round(kl(p, p), 4), " == 0")
print("H(p,q) - H(p):", round(cross_entropy(p, q) - entropy(p), 4),
      " == KL(p||q):", round(kl(p, q), 4))
print("asymmetry: KL(q||p) =", round(kl(q, p), 4), "!= KL(p||q)")

# Cross-entropy loss == negative log-likelihood on one-hot labels
logits = rng.normal(size=(5, 3))
probs = np.exp(logits) / np.exp(logits).sum(axis=1, keepdims=True)
labels = rng.integers(0, 3, size=5)
ce = -np.log(probs[np.arange(5), labels]).mean()
print("mean cross-entropy loss:", round(ce, 4))
```

KL is nonnegative and zero only against itself, the cross-entropy minus entropy
identity holds, the two KL directions disagree, and the classification loss is the
mean negative log-likelihood. The next lesson uses KL to measure how much two
variables tell you about each other: mutual information.
