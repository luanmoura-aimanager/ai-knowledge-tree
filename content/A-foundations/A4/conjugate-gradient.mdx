For a large symmetric positive-definite system $Ax = b$, direct factorization costs
$O(n^3)$ and stores a dense factor. **Conjugate gradient (CG)** solves it iteratively
using only matrix-vector products, finishing in at most $n$ steps in exact arithmetic
and far fewer in practice<FN n="1" />. It is the workhorse for sparse SPD systems and the
template for Krylov methods.

## CG as minimizing a quadratic

For SPD $A$, solving $Ax = b$ is equivalent to minimizing the quadratic

$$
\phi(x) = \tfrac{1}{2} x^\top A x - b^\top x,
$$

whose gradient is $\nabla \phi = Ax - b$ (zero exactly at the solution). CG generates
iterates $x_0, x_1, \dots$ each of which is the **exact minimizer of $\phi$ over a
growing Krylov subspace**, using only the gradients (residuals) $r_k = b - A x_k$.

## $A$-conjugate directions

Two directions $p$ and $q$ are **conjugate** with respect to $A$ if $p^\top A q = 0$,
the $A$-inner-product orthogonality. CG builds an $A$-conjugate set of search
directions: each $p_k$ is $A$-orthogonal to all previous ones.

The payoff: minimizing $\phi$ along $A$-conjugate directions one at a time is the same
as minimizing it over their span. There is no need to revisit a previous direction
once you have stepped along it. After $k$ steps, $x_k$ is the exact minimizer in the
$k$-dimensional subspace spanned by the first $k$ directions.

## The CG update

Starting from $x_0$ with $r_0 = b - A x_0$ and $p_0 = r_0$, each step does:

1. **Step length** along the current direction $p_k$ that minimizes $\phi$:
   $$
   \alpha_k = \frac{r_k^\top r_k}{p_k^\top A p_k}.
   $$
2. **Update** $x_{k+1} = x_k + \alpha_k p_k$ and $r_{k+1} = r_k - \alpha_k A p_k$.
3. **New direction** $A$-conjugate to all previous:
   $$
   \beta_k = \frac{r_{k+1}^\top r_{k+1}}{r_k^\top r_k}, \qquad p_{k+1} = r_{k+1} + \beta_k p_k.
   $$

The cost per iteration is one matrix-vector product $A p_k$ and a handful of
vector operations: $O(n)$ memory plus the cost of multiplying by $A$, which for sparse
$A$ scales with the number of nonzeros.

## Krylov subspaces and finite termination

The space spanned by $\{r_0, A r_0, A^2 r_0, \dots, A^{k-1} r_0\}$ is the **Krylov
subspace** $\mathcal{K}_k$. CG's $x_k$ minimizes $\phi$ over $x_0 + \mathcal{K}_k$. In
exact arithmetic, the dimension of the Krylov subspace grows by one each step until it
contains the true solution, so CG terminates in at most $n$ steps with $x_n = x^\star$<FN n="2" />.

## Convergence rate

In practice CG converges much faster than $n$ when the eigenvalues of $A$ cluster.
With condition number $\kappa = \lambda_{\max}/\lambda_{\min}$, the error satisfies

$$
\lVert x_k - x^\star\rVert_A \le 2\left(\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}\right)^k\, \lVert x_0 - x^\star\rVert_A,
$$

a rate of $\sqrt\kappa$ like Nesterov's acceleration. **Preconditioning** (solving
$M^{-1}A x = M^{-1}b$ for a cheap $M \approx A$) shrinks the effective condition
number and is what makes CG practical for ill-conditioned systems<FN n="3" />.

## Check it on arrays

```python
import numpy as np

rng = np.random.default_rng(0)

# Random SPD system of moderate condition number.
n = 200
B = rng.normal(size=(n, n))
A = B @ B.T + 0.5 * np.eye(n)                              # SPD
b = rng.normal(size=n)

def cg(A, b, tol=1e-10, max_iter=None):
    x = np.zeros_like(b)
    r = b - A @ x
    p = r.copy()
    rs_old = r @ r
    history = []
    for k in range(max_iter or len(b) + 5):
        Ap = A @ p
        alpha = rs_old / (p @ Ap)
        x = x + alpha * p
        r = r - alpha * Ap
        rs_new = r @ r
        history.append(np.sqrt(rs_new))
        if rs_new < tol**2:
            break
        beta = rs_new / rs_old
        p = r + beta * p
        rs_old = rs_new
    return x, history

x_cg, hist = cg(A, b)
x_true = np.linalg.solve(A, b)
print(f"CG converged in {len(hist)} iterations")
print(f"final residual: {hist[-1]:.2e}")
print(f"error vs direct solve: {np.linalg.norm(x_cg - x_true):.2e}")
print(f"finite-termination bound: <= n = {n}")
```

CG reaches the solution in fewer iterations than the dimension when the spectrum is
favorable, with residual decaying geometrically. The next lesson generalizes Krylov
solvers to nonsymmetric systems with GMRES.
